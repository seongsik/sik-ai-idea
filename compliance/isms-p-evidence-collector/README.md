# ISMS-P 증적 자동 수집·매핑

> 한 줄 요약: ISMS-P 인증 심사에 필요한 증적을 사내 시스템에서 자동으로 모아 통제항목별로 매핑하고, 누락·만료 항목을 알려준다.

- 카테고리: compliance
- 상태: 아이디어
- 작성일: 2026-10-27
- 구현 리포지터리: -

## 배경 / 문제

- ISMS-P는 관리체계·보호대책·개인정보 처리 단계 요구사항 등 100여 개 통제항목을 갖고, 매년 사후/갱신 심사가 있다.
- 심사 시기마다 정책 문서, 회의록, 교육 결과, 시스템 설정 화면, 로그 검토 기록 등을 사람이 찾아 모으고 항목별 폴더에 정리한다.
- 증적이 언제 마지막으로 갱신됐는지, 어떤 항목이 비어 있는지 한눈에 보기 어렵다.

## 목표

- 통제항목별 필요 증적 목록을 정의하고, 사내 저장소에서 자동으로 후보 증적을 찾아 매핑한다.
- 관리 콘솔 설정처럼 화면으로만 존재하는 증적은 브라우저 자동화로 캡처한다.
- 누락·기한 경과 항목 대시보드와 담당자 알림을 제공한다.

## 범위 밖 (Non-goals)

- 인증 심사 대응 판단 자체(적합/결함 판정)를 AI가 확정하지 않는다.

## 사용자 / 사용 시나리오

1. 담당자가 통제항목 ↔ 증적 요구사항 ↔ 주기(월/분기/연) ↔ 담당자를 매핑해 둔다.
2. 주기적으로 수집기가 문서 저장소(SharePoint, Google Drive, Confluence 등)와 티켓 시스템을 검색해 후보 증적을 찾고, AI가 항목 적합성을 판단해 매핑한다.
3. 콘솔 증적(예: 방화벽 정책, 계정 잠금 정책, 백업 설정)은 브라우저 자동화로 로그인 후 캡처, 일시 워터마크를 넣어 저장한다.
4. 심사 전 "항목별 증적 현황표"와 증적 패키지(zip)를 내보낸다.

## 핵심 기능

- [ ] 통제항목·증적 요구사항 마스터 관리
- [ ] 문서 저장소 커넥터와 AI 기반 증적 분류/매핑
- [ ] 브라우저 자동화 기반 설정 화면 캡처 (캡처 시각·URL 기록)
- [ ] 누락·만료 대시보드, 담당자 알림
- [ ] 심사용 현황표·증적 패키지 내보내기

## 기술 구상

- 수집: 각 저장소 API 커넥터, 브라우저 자동화(Playwright 또는 Claude 브라우저 탐색 기능)
- 분류: Claude API로 문서 요약 → 통제항목 매핑, 신뢰도 낮으면 검토 대기
- 저장: 증적 메타데이터 DB(항목, 출처, 수집일, 유효기한, 해시)

## 구현 단계 (MVP → 확장)

1. MVP: 통제항목 마스터 + 수동 업로드 증적 매핑 + 누락 현황표.
2. 문서 저장소 자동 검색·AI 매핑.
3. 설정 화면 자동 캡처.
4. 연간 증적 캘린더, 담당자별 리마인더, 이전 심사 결함 추적.

## 열린 질문 / 리스크

- 콘솔 자동 로그인 계정 관리(최소 권한, MFA 처리).
- 증적 원본 무결성(해시, 수집 시각) 보장 방식.
- ISMS-P 인증기준 개정 시 마스터 갱신 절차.
