# 부서 맞춤형 모의 훈련 시나리오 생성

> 한 줄 요약: 부서별 업무 맥락에 맞는 모의 피싱 메일·사회공학 시나리오와 훈련 후 교육 자료를 AI로 생성한다.

- 카테고리: security-awareness
- 상태: 아이디어
- 작성일: 2026-10-27
- 구현 리포지터리: -

## 배경 / 문제

- 매번 같은 유형의 모의 피싱(택배, 비밀번호 만료)만 반복해 훈련 효과가 떨어진다.
- 실제 공격은 부서 업무(회계-송금 요청, 인사-이력서 첨부, 영업-견적 요청)를 노리는데, 이에 맞춘 시나리오 제작은 손이 많이 간다.

## 목표

- 부서·직무별 현실적인 모의 훈련 메일과 랜딩 페이지 문구를 생성한다.
- 훈련 결과에 따라 개인·부서별 맞춤 교육 자료(짧은 설명, 퀴즈)를 만든다.

## 범위 밖 (Non-goals)

- 실제 악성 페이로드 제작. 모든 링크·첨부는 훈련용 추적만 수행한다.
- 메일 발송 플랫폼 자체 개발 (기존 훈련 플랫폼 또는 GoPhish 등 활용).

## 사용자 / 사용 시나리오

1. 담당자가 부서, 난이도, 최근 실제 공격 동향을 입력한다.
2. AI가 메일 제목·본문·발신자 설정·랜딩 페이지 문구와 "알아챌 수 있는 단서" 목록을 생성한다.
3. 훈련 후 클릭/입력/신고 결과를 넣으면 부서별 결과 보고서와 교육 자료가 생성된다.

## 핵심 기능

- [ ] 부서·난이도·테마별 시나리오 생성
- [ ] 단서(red flag) 목록과 교육용 해설 자동 생성
- [ ] 훈련 결과 분석 보고서
- [ ] 개인 맞춤 마이크로 교육(퀴즈 포함)

## 기술 구상

- AI: Claude API로 시나리오·교육 자료 생성
- 발송: GoPhish 또는 사내 훈련 플랫폼 템플릿 내보내기

## 구현 단계 (MVP → 확장)

1. MVP: 시나리오 + 단서 해설 생성기.
2. 훈련 플랫폼 템플릿 내보내기, 결과 보고서.
3. 개인 맞춤 교육과 반복 훈련 난이도 자동 조절.

## 열린 질문 / 리스크

- 훈련 수위(실제 사내 인물 사칭 등)에 대한 사내 합의.
- 직원 반감 최소화를 위한 사후 안내 방식.
