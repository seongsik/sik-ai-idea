# 사내 보안 정책 Q&A 봇

> 한 줄 요약: 직원의 반복적인 보안·개인정보 질문에 사내 정책 문서 조항을 인용해 답하고, 답할 수 없는 질문은 보안팀 티켓으로 넘긴다.

- 카테고리: security-awareness
- 상태: 아이디어
- 작성일: 2026-10-27
- 구현 리포지터리: -

## 배경 / 문제

- "개인정보를 외부 메일로 보내도 되나요?", "USB 써도 되나요?" 같은 질문이 반복적으로 보안팀에 온다.
- 정책 문서는 길고 찾기 어려워 직원들이 읽지 않는다.

## 목표

- 사내 메신저에서 즉시 답변하고, 근거 조항과 문서 링크를 함께 제시한다.
- 자주 묻는 질문 통계로 정책·교육 개선 포인트를 찾는다.

## 범위 밖 (Non-goals)

- 예외 승인 처리 (승인 요청 티켓 생성까지만).

## 사용자 / 사용 시나리오

1. 직원이 메신저 봇에 질문한다.
2. 봇이 정책 문서를 검색해 조항을 인용하며 답한다. ("정보보호 지침 제12조에 따라 암호화 후 전송해야 합니다…")
3. 근거를 찾지 못하거나 예외 요청이면 보안팀 티켓을 만들고 직원에게 안내한다.

## 핵심 기능

- [ ] 정책 문서 인덱싱(조항 단위)
- [ ] 근거 인용 필수 답변 (근거 없으면 답하지 않음)
- [ ] 메신저 연동(Slack/Teams 등)
- [ ] 미해결 질문 티켓 생성
- [ ] 질문 통계·FAQ 자동 갱신

## 기술 구상

- 검색: 조항 단위 청크 + 벡터/키워드 하이브리드 검색
- AI: Claude API, 인용 강제 프롬프트
- 문서 동기화: 정책 문서 저장소 변경 시 재인덱싱

## 구현 단계 (MVP → 확장)

1. MVP: 정책 문서 3~5개 대상 웹 Q&A.
2. 메신저 봇, 티켓 연동.
3. 통계 대시보드, 정책 개정 시 관련 FAQ 자동 갱신.

## 열린 질문 / 리스크

- 잘못된 답변의 책임 → "참고용" 고지와 근거 인용으로 완화.
- 질문 내용에 개인정보가 포함될 때 로그 처리.

## 참고 자료

- 사내 정보보호 정책·지침 (구현 시 별도 제공)
