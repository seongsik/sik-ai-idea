# 스테이지 기반 전략 게임 기본 골격

> 한 줄 요약: 가로 도트 쿼터뷰 RPG의 공통 규칙. 연결·확장하는 하나의 사냥 월드에서 핵앤슬래시, 리젠 몬스터와 소량 경험치·무기 제외 장신구를 즐긴다. 스토리는 미니맵 왼쪽 버튼으로 여는 별도 선택 화면에서 12장×턴제10개=120개로 진행하며, 각 장10번은 핵심 장수의 고난도 보스 스테이지다. 테마 데이터는 게임별로 주입한다.
>
> 최종 수정: 2026-11-02 (game-guidelines-v21: 확장 사냥 월드·12장120개 스토리·유니크 장신구)

- 카테고리: game
- 문서 유형: 공통 지침 (개별 아이디어가 아님)
- 작성일: 2026-11-01
- 적용 대상: 개별 게임 기획서가 "스테이지 기반 전략 게임 기본 골격을 따른다"고 명시한 모든 게임

## 이 지침의 사용법

게임 관련 공통 지침은 세 개이고, 함께 쓴다.

| 지침 | 정하는 것 | 이 아이디어 리포지터리의 경로 |
|---|---|---|
| **스테이지 기반 전략 게임 기본 골격** (이 문서) | 게임 규칙: 구조, 필드, 전투, 캐릭터, 장비, 성장, 화면 | `game/stage-strategy-framework/README.md` |
| **게임 개발 공통 과금 지침** | 돈: 재화, 가격, 뽑기, 광고, 환불, 스팀판 과금 | `game/monetization-guideline/README.md` |
| **게임 개발·출시 공통 지침** | 만들고 내는 방법: 엔진, 코드 구조, 서버, 다국어, 개발 도구, 아트 파이프라인, 출시 체크리스트, 개발 단계 | `game/dev-release-guideline/README.md` |

- 개별 게임 기획서에는 지침 내용을 다시 쓰지 않는다. 각 지침의 "게임별로 정의할 항목"(테마 데이터)과 그 게임만의 고유 내용만 적는다.
- 구현은 별도 리포지터리에서 하고, 이 아이디어 리포지터리의 공통 지침 세 개와 게임 기획서를 **참조**해 개발한다. 이 리포지터리에는 아이디어와 지침만 기록하고 구현물은 두지 않는다.
- 지침과 게임 기획서가 충돌하면 지침이 우선한다. 예외가 필요하면 게임 기획서에 "지침 예외"로 명시하고 이유를 적는다.
- 게임 내 명칭은 **캐주얼하고 직관적인 이름**을 쓴다. 세계관 색이 강한 고유 용어는 캐릭터 이름, 상징 장비 이름, 스토리에만 쓴다.
- "(제안)"이 붙은 수치와 방식은 초기 설계값이다. 구조는 유지하고, **난이도와 밸런스에 관련된 제안값(지형 수치, 피해 공식, 회피율, 난이도 계수, 보급기지 회복량, 드롭 확률, 챔피언 리젠 간격, 인연 보너스 재화·버프 크기 등)은 플레이테스트로 확정한다**. 확정 전까지는 원격 설정으로 바꿀 수 있게 둔다.

## 1. 게임 구조

- **가로 화면 도트 쿼터뷰 RPG**다. 메인 화면은 필드이고, 게임을 켜면 마지막으로 저장한 필드 위치에서 시작한다.
- 사냥 월드와 스토리 전투를 분리한다.

| 모드 | 언제 | 방식 |
|---|---|---|
| 사냥 월드 | 평소 | 연결 지역 탐험, 선택 퍼즐/NPC, 리젠 적·챔피언 핵앤슬래시 (§3~§5) |
| 스토리 턴제 | 미니맵 왼쪽 스토리 진행 버튼 → 노드 선택 | 별도 격자 전투와 전후 이야기, 출전 최대3명 (§2, §6) |

```
사냥 월드 ── 일반 적·챔피언 ──> 그 자리에서 액션 전투
     ├─ 스토리 진행 버튼 ──> 장/노드 선택 ──> 직접/AI 턴제 ──> 결과·이야기 ──> 선택 화면
     │                                                              └─ 닫기: 필드 상태 복원
     ├─ 봉화대 ──> 발견한 봉화대로 워프
     └─ 선택 NPC·퍼즐·상자·연결 지역 이동(저장)
```

- 스토리 **스테이지**는 별도 선택 화면의 턴제 전투를 뜻한다. 기존 보스룸은 사냥 월드의 챔피언 구역이며 스토리 진입점이 아니다.
- 필드 구성은 「젤다의 전설: 꿈꾸는 섬」을 오마주한다. 참고하는 것은 필드 구성과 조작감(지역 연결, 퍼즐, 트릭, 숨은 길, 도구로 길 열기)뿐이다. 닌텐도의 그래픽, 음악, 맵 배치, 아이템 디자인과 이름, "젤다" 명칭은 쓰지 않고 홍보 문구에도 쓰지 않는다.
- 전투 조작은 콘솔판 「디아블로 II: 레저렉션」의 직접 이동·버튼 즉시 시전·방향 기반 타깃 보조를 참고한다. 피처폰 RPG의 도트 표현과 파티 3명 전환은 유지한다. 참고 범위는 조작과 전투 감각이며, 해당 작품의 에셋·UI 디자인·명칭·음악·세계관은 사용하지 않는다. 스태미나·마나·온라인 협동을 함께 도입한다는 뜻이 아니다.
- 스태미나는 두지 않는다. 필드 탐험과 스테이지는 언제든 제한 없이 할 수 있다.
- **테마 고유 시스템**: 게임마다 테마에서 나온 고유 시스템을 **2개 이상** 둔다. 같은 골격의 게임이 그림만 바꾼 것으로 보이지 않게 하고, 스토어 심사(개발·출시 지침 "시리즈 출시 원칙")를 통과하기 위해서다.
  - 골격 규칙을 바꾸지 않고 **위에 얹는** 형태로 만든다(예: 특정 지형 효과, 필드의 고유 이동 방식, 특별한 장 형식). 골격 규칙을 바꿔야 하면 지침 예외로 적는다.
  - 최소 두 개를 **초기 사냥 구역과 스토리 턴제**에서 경험하게 한다. 자동 전투 선택자도 선택 탐험에서 체험할 수 있게 하되 필드 체험을 스토리 선행 조건으로 만들지 않는다. 스토리 첫 1~2장과 초기 월드에서 소개한다.
  - 과금과 연결하지 않는다(고유 시스템을 쓰려고 돈을 내야 하는 구조 금지).

### 저작권·상표 준수 (절대 규칙)

모든 게임이 반드시 지킨다. **지침 예외로 풀 수 없다.**

1. **원전만 쓴다.** 저작권이 끝난 원전(신화, 전설, 역사 기록, 고전 문학)의 인물 이름과 줄거리는 쓸 수 있다. 같은 원전을 다룬 **현대 작품**(소설, 영화, 드라마, 만화, 애니메이션, 게임)의 캐릭터 디자인, 각색 설정, 창작 인물, 고유 명칭, 대사, 줄거리는 쓰지 않는다.
2. **저작권이 살아 있는 작품은 통째로 피한다.** 현대 소설 등 보호 기간이 남은 작품의 인물, 세계관, 고유 기술·아이템 이름, 줄거리를 쓰지 않는다. 원전이 없는 테마(창작 세계관)는 모두 새로 만든다.
3. **고유 명칭과 상표를 쓰지 않는다.** 특정 작품이 만든 종족·괴물·아이템·조직 이름, 상표로 등록된 명칭은 쓰지 않는다. 장르에서 오래 함께 써 온 일반 명칭(엘프, 드래곤, 좀비, 소림 등)만 쓴다.
4. **닮게 만들지 않는다.** 색, 머리 모양, 의상, 무기, 상징의 조합으로 특정 작품의 캐릭터나 디자인을 떠올리게 하지 않는다. 하나하나는 흔한 요소라도 조합이 특정 캐릭터를 가리키면 쓰지 않는다.
5. **AI 생성에 작품명을 넣지 않는다.** 아트·문장 생성 지시(프롬프트)에 다른 작품, 작가, 캐릭터, 스튜디오 이름을 넣지 않는다.
6. **홍보에도 쓰지 않는다.** 스토어 설명, 광고, 공지에 다른 작품 이름이나 "~풍", "~ 같은 게임"을 쓰지 않는다. 오마주한 게임(위 필드 구성)도 마찬가지다.
7. **게임마다 목록을 둔다.** 게임 기획서에 "저작권 준수" 항목을 두고, 테마 원전의 상태와 닮게 하면 안 되는 작품·요소를 적는다. 아트와 문구는 만들 때와 출시 전(개발·출시 지침 체크리스트)에 이 목록과 대조한다. 의심되면 쓰지 않는다.

- **기본 범위 밖** (모든 게임 공통, 1차 출시 기준): 실시간 PvP, 길드 같은 온라인 경쟁 요소, 내정·외교 같은 대전략 요소. 넣으려면 게임 기획서에 "지침 예외"로 적는다.
- **도박 미니게임 금지** (예외 불가): 카드, 주사위, 슬롯처럼 도박을 흉내 내는 미니게임은 넣지 않는다. 도박사·살룬·주점은 이야기 소재로만 쓴다. 넣으면 연령 등급이 크게 오른다(예: 호주 R18+).

## 2. 진행 구조

- **사냥 월드와 스토리 캠페인을 분리한다.** 장은 이야기와 턴제 스테이지의 묶음이며 장마다 별도 필드 맵을 제작하지 않는다. 하나의 연결 사냥 월드에 인접 지역을 추가 업데이트한다. 이 연결은 지역 경계 전환을 허용하며 모든 지역의 무로딩 동시 실행을 뜻하지 않는다.
- **메인 스토리12장, 장당 턴제10개·총120개**. 번호는1-1~12-10. 각 장10번은 다른 노드보다 어려운 턴제 보스 스테이지이며 스토리상 중요한 적 장수가 등장한다. 기존72턴제+24필수 액션 보스룸/총96 구조를 대체한다. 기존 보스룸의 주요 사건은 해당 장의 턴제/전후 대화에 편입하고 이야기를 삭제하지 않는다.
- **스토리 진행 버튼은 필드 미니맵 왼쪽**에 둔다. 누르면 별도 스테이지 선택 화면으로 이동한다. 필드 구조물·좌표·필드 퍼즐·챔피언 처치는 스토리 입장의 조건이 아니다. 전투 중에도 버튼을 사용할 수 있게 필드 상태를 보존/일시정지하며, 복귀가 회복·쿨다운 초기화나 즉시 리젠 수단이 되지 않게 한다.
- 선택 화면에는 장 선택, 연결 경로와 스테이지 노드, 잠김/도전 가능/클리어,10번 보스, 선택 노드의 이야기·권장 성장·보상·입장 버튼을 표시한다. 기본 순차 해금이며 분기 조건은 명시적인 스토리 데이터로 판정한다. 미제작 노드는 잠긴 콘텐츠로 구분하고 같은 맵 반복을120개 제작 완료로 세지 않는다.
- **스토리는 이 화면에서 선택한 턴제와 전후 대화·이야기 선택에서만 진행**한다. 장의 필수 경로와 마지막 이야기 완료로 다음 장·장 보상·결말을 해금한다. 필드 탐험과 선택 챔피언은 메인 완료 조건이 아니다. 필드 사냥이나 희귀 드롭을 하지 않아도 기본·장 보상 편성으로 진행할 수 있어야 한다.
- 입장 전에 광고 없는 직접 전투 또는 기존 광고 보상 AI 한 판을 고른다. AI도 같은 규칙으로 실제 싸우며 패배 가능, 승리할 때만 동일 진행/보상을 지급한다. 실패·포기·결과 확인은 스테이지 선택 화면으로 돌아간다. 필수 대사/선택을 광고 자동 전투가 건너뛰지 않는다. 선택 화면을 닫으면 보존한 필드 상태로 복귀한다.
- **보상 기록**: 스테이지 최초/반복/난이도/회차 보상, 장 캐릭터 보상, 필드 처치 보상, 계정당1회 유니크 장신구를 서로 다른 ID로 관리한다. 저장 복구·광고 중복 콜백·재입장으로 같은 완료 보상을 다시 지급하지 않는다.
- **난이도** 기본/어려움을 유지한다. 같은 스테이지 기본 클리어로 어려움이 열리고 최초 보상은 별도다. 기존 직접/AI·거점·되감기·포로·턴 제한 규칙은 유지한다. 각 장10번도 일반 턴제와 같은 규칙/입력으로 진행하며 난이도·적 장수·목표/배치로 보스전을 만든다.
- **어려움+**는 기본 난이도의12장 필수 스토리 경로 완료로 해금한다. 별도 스토리 진행 칸에서1장부터 시작하며 기존 이야기 기록을 지우지 않는다. 사냥 월드 탐험·도구·봉화대·장신구 보유·유니크 수령 기록은 회차 공통으로 유지한다. 캐릭터·장비·레벨·강화·스킨·재화·계정·구매품도 유지한다. 난이도는 어려움 이상, 스테이지 첫 보상3배와 재클리어 규칙은 과금 지침을 따른다. 어려움+는 한 회차이며 완료 후 재도전 가능하다.
- 분기와 주요 NPC 선택은 스테이지의 대화/이벤트 안에서 처리한다. 다른 경로는 이후 다시 플레이할 수 있다. 선택 특수 전투는 방어·호위·if 스토리 등을 제공하며120개 기본 캠페인과 별도로 센다.
- 전투 기록/난이도/회차 전환은 스테이지 선택 화면에 통합한다. 참고 이미지의 연결 노드 구성만 참고하며 그림·캐릭터·진 엔딩/헬 모드 명칭을 그대로 도입하지 않는다.
- **출시 기준**:12장120개 스토리 스테이지를 완성한 뒤 출시한다. 사냥 월드는 검수된 초기 구역으로 시작하고 업데이트마다 연결 지역을 확장할 수 있다. 장당 야외5~6/던전3~4, 필수 액션 보스2개, 메인2~3시간·탐험3~5시간 제작 할당은 폐지한다. 턴제 한 판5~15분은 검수 목표로 유지하고 직접/AI 및 필드 체류 시간은 따로 측정한다.

## 3. 필드

- **크기 단위**: 하나의 월드가 여러 야외·실내·동굴·지하미로·미니 구역을 잇는다. 지역ID/연결을 유지하며 인접 구역을 확장한다. 장별 필드 복제는 하지 않는다. 논리 지도 크기와 화면 표시를 분리하고 지역 내부는 추적 카메라로 탐험한다. 기존16×9는 과거 샘플 규격이며 정식 지역 상한이 아니다. 지역 크기·통행·출입구·상하층 연결·저장 ID를 데이터로 정의한다. 초기 야외96×96칸 전후(64×64~128×96), 던전층48×48~64×64는 제안이며 조우 밀도·이동시간·실기기 성능으로 조정한다.
- **조립형 랜드마크**: 넓은 지역마다 여러 파츠로 구성한 대형 건축물 또는 자연경관을 둔다. 성문·성벽·누각·회랑·안뜰·본전과 절벽·거목·계곡·동굴 등 테마에 맞는 요소를 연결하고, 실제 통행·전투 가능한 구역과 장식 영역을 구분한다. 건물은 출입구와 내부 동선을 제공하고 지붕/전경 가림을 처리한다. 실내·동굴·지하미로·세계관 단편/숨은 구역을 별도 지역으로 연결할 수 있다. 이동·투사체 차폐·카메라/가림 레이어·발 위치를 같은 파츠 데이터로 검수한다.
- **전 모드 쿼터뷰**: 필드·던전·보스룸·턴제 맵에 같은 투영 기준을 쓴다. HUD·대화·메뉴는 읽기 쉬운 평면 UI다. 지면 위치·깊이 정렬·발 위치와 공격 범위를 일치시키며 앞쪽 물체에 가려진 캐릭터/목표를 식별할 수 있게 한다. 이동 스틱은 화면 방향대로 움직이고 클릭/터치는 역투영으로 판정한다.
- 넓이보다 **화면당 밀도**를 우선한다. 화면마다 퍼즐, 숨은 길, 적 배치, NPC, 상자 중 하나 이상을 둔다.
- 조작하는 캐릭터는 **출전 파티 3명 중 리더**다. 필드에서 전투 중에도 파티 안에서 바꿔 조작할 수 있다. 전환은 각자의 HP·두 스킬 쿨다운을 유지하며 회복·쿨다운 초기화 수단이 아니다. 피격·공격 후딜을 전환 연타로 무효화하지 않도록 전환 가능한 시점과 입력 예약을 명시한다.
- 필드에서 하는 일:
  - 간단한 퍼즐 (스위치, 열쇠, 블록 밀기·당기기 같은 트릭). 퍼즐이 풀 수 없는 상태로 꼬이지 않도록, 구역을 나갔다 들어오면 초기화한다.
  - NPC와 선택 탐험 대화하기. 메인 스토리 분기/장 해금은 바꾸지 않는다.
  - 상자, 숨은 길 찾기.
  - 일반 적(잡몹)과 액션 전투 (§4).
- **필드 도구**: 스토리 진행으로 **3~4개**를 얻고, 도구를 얻으면 이전에 갈 수 없던 길이 열린다. 이름과 디자인은 게임별로 독자적으로 만든다.

| 기본형 | 하는 일 |
|---|---|
| 밀기·당기기 | 무거운 블록과 바위를 밀고 당긴다 |
| 뛰어넘기 | 구멍이나 낮은 물을 건넌다 |
| 끌어당기기 | 멀리 있는 지점으로 몸을 끌어당겨 건넌다 |
| 부수기 | 금 간 벽이나 막힌 길을 부순다 |

- **웨이포인트**: 디아블로의 웨이포인트 방식을 차용한다. 웨이포인트를 밟으면 발견 처리되고, 발견한 웨이포인트 사이를 지도 메뉴에서 바로 워프한다. 밟으면 파티 전원의 체력이 최대로 회복된다. 이름과 디자인은 게임별로 정한다.
- **일반 적 보상**: 리젠 몬스터 처치로 소량 캐릭터 경험치와 무기 제외 장신구를 얻는다. 기존 확률 재화1/회복 아이템 규칙은 유지하되 리젠 도입 후 분당 재화 수급을 재검수하며 확률·가격을 자동 변경하지 않는다. 메인 진행에 필요한 기능은 스토리에서 확정 지급한다.
- **리젠**: 일반 적은 처치 후 지역별 데이터 시간에 다시 생성된다. 생성점이 캐릭터/생존 적/벽으로 막히면 지연하고 겹쳐 생성하지 않는다. 활성 사냥 시간으로 타이머를 진행하며 메뉴·스토리 전투·앱 종료는 일시정지한다. 구역 이동/재접속으로 즉시 리젠하거나 소급 처치 보상을 주지 않는다. 출현 주기별 처치 ID로 경험치/드롭을 한 번만 지급한다. 시간·밀도는 검수값이다.
- **유니크 챔피언 조우**: 기존 보스룸을 선택 사냥 조우 장소로 재사용한다. 특수 스킬·오라·부하를 가진 챔피언을 두며 지정 유니크 장신구를 첫 유효 처치/조우 완료에 확정 지급하는 안을 쓴다. 각 유니크 보상ID는 계정 전체에서1회, 캐릭터·기기·난이도·스토리 회차와 무관하다. 재처치의 소량 경험치/일반 드롭은 별도다. 장신구 삭제·분해·재접속으로 수령 기록을 초기화하지 않는다. 인벤토리와 수령권을 함께 저장하며 실패 시 수령권만 소모하지 않는다. 실제 계정간/기기간 보장은 추후 서버 저장 검증 대상이다.
- **필드 사망**: 조작 캐릭터의 체력이 0이 되면 현재 필드 지역의 시작 지점에서 최대 체력으로 부활한다. 재화나 경험치를 잃는 등의 페널티는 없다. 파티의 다른 캐릭터로 바꾸지 않고 바로 부활한다.
- **길 안내**:
  - **미니맵**: 필드 화면 오른쪽 위에 작게 상시 표시한다. 지금 있는 화면 주변과, 가 본 화면만 보여 준다(안 가 본 곳은 가려짐). 웨이포인트, 선택 챔피언 조우, 지역 출구를 아이콘으로 표시한다. 스토리 버튼은 미니맵 왼쪽 별도 조작이다. 누르면 월드맵이 열린다.
  - **월드맵**: 지도 메뉴(§11)에서 연다. 사냥 지역들의 위치와 연결, 발견한 웨이포인트(워프), 선택 탐험 목적지를 보여 준다.
  - **목표 화살표**: 조작 캐릭터 주위에, 플레이어가 지정한 필드 탐험 목적지 방향을 가리키는 화살표를 표시한다. 화살표는 캐릭터를 중심으로 360도 돌아가며 목표까지의 **직선 방향**을 가리킨다.
    - 목표: 선택한 봉화대/출구/발견한 탐험 지점. 스토리 다음 노드는 별도 스테이지 화면에서 안내하며 필드 구조물을 가리키지 않는다. 다른 지역이면 지금 지역의 출구를 가리킨다.
    - 목표가 가까워지면(같은 화면 안) 화살표가 흐려지고 목표 지점에 표시가 나타난다.
    - 직선 방향이라 벽이나 퍼즐 때문에 바로 갈 수 없을 수 있다. 길 찾기는 플레이어 몫으로 남겨 탐험의 재미를 지킨다.
    - 숨은 길, 상자, 선택 콘텐츠는 가리키지 않는다.
    - 설정에서 끌 수 있다(기본은 켜짐).
  - **경로 힌트**: 목표 화살표만으로 길을 찾기 어려울 때 쓰는 도움 기능이다.
    - 쓰면 **1분 동안** 조작 캐릭터 위치에서 목표 화살표의 목표까지 **최단 경로**를 바닥에 빛나는 선으로 보여 준다. 캐릭터가 움직이면 경로도 따라 갱신된다.
    - 퍼즐로 치워야 하는 장애물(밀어야 하는 블록, 잠긴 문, 부숴야 하는 벽, 필드 도구가 필요한 곳)이 길을 막고 있어도 **관통해서** 경로를 그린다. 그 장애물 위치는 경로 위에 따로 표시해, 어디서 무엇을 풀어야 하는지 알 수 있게 한다. 벽, 절벽, 물처럼 원래 지나갈 수 없는 지형은 관통하지 않는다.
    - 횟수: 최대 **3회**까지 쌓이고, **5분에 1회**씩 충전된다. 게임을 꺼 둔 동안에도 충전된다.
    - 재화나 광고로 충전하지 않는다.
    - 버튼 위치는 미니맵 바로 아래이고, 남은 횟수와 다음 충전까지 남은 시간을 표시한다.
- **자동 저장**: 필드 구역(화면)을 이동할 때마다 자동 저장한다. 퍼즐 진행, 상자, NPC 선택, 발견한 웨이포인트도 저장 대상이다.

## 4. 액션 전투 (필드, 보스룸 공통)

- 조작:

| 위치 | 구성 |
|---|---|
| 왼쪽 | 가상 조이스틱 (이동) |
| 오른쪽 | 공격 버튼, 회피 버튼, 일반스킬 버튼, 궁극기 버튼 |

- PC(스팀)는 키보드·마우스와 게임패드로 같은 명령을 낸다(§12).
- 캐릭터마다 **일반스킬 1개 + 궁극기 1개, 총 2개**를 가진다. 지원형을 포함해 이 중 적에게 피해를 주는 공격 스킬을 적어도1개 가진다. 기본 공격만으로 이 조건을 충족하지 않는다. 기본 공격·회피·필드 도구는 이 두 스킬에 포함하지 않는다. 세 번째 캐릭터 스킬 슬롯을 만들지 않는다.
- **일반스킬과 궁극기 모두 쿨다운**으로 운용한다. 궁극기는 일반스킬보다 긴 재사용 대기시간을 갖는 강한 스킬이며, 피해·처치 충전 게이지를 없앤다. 기본 공격·회피와 별도 버튼으로 직접 시전한다.
- 캐릭터별 두 스킬 ID·이름은 필드·대결·턴제에서 같다. 범위·효과·위력·액션 초 단위/턴제 턴 단위 쿨다운은 모드별 데이터로 정의한다. 수치는 게임별 플레이 검수 대상이다.
- **자원 운용 제안**: 첫 필드 진입 시 두 스킬 사용 가능. 필드에서 시간이 흐르면 파티 대기 캐릭터의 쿨다운도 감소한다. 일시정지·오프라인에는 감소하지 않으며 전환·구역 이동·저장 복구로 초기화하지 않는다. 대결/턴제는 독립 자원으로 시작하고 종료 시 진입 전 필드의 남은 쿨다운을 복원한다. 대결 재시작도 동일 초기 조건이다.
- **직접 조작**: 스틱/방향키로 이동하고 공격·스킬 버튼으로 즉시 시전한다. 방향·거리·시야를 고려한 타깃 보조와 선택 대상 표시를 두되, 보조가 이동 의도를 덮어쓰지 않는다. 적이 없어도 방향 시전이 가능하며 범위 미리보기와 실제 판정을 일치시킨다.

- **화살 비관통**: 일반공격과 스킬의 화살 한 발은 처음 닿은 살아 있는 전투 몸체 또는 차폐물에서 멈춘다. 아군 몸체도 막되 아군 피해는 주지 않는다(초기 계약). 회피/무적 대상에 피해가0이어도 접촉한 화살이 뒤로 관통하지 않는다. 멀티플샷은 서로 다른 방향의 여러 비관통 화살이며 기본 한 시전의 같은 대상 중복 피해는 허용하지 않는 안으로 검수한다. 에너지볼 등 다른 투사체는 별도 데이터다.

### 몰이사냥과 타격감

- 필드 사냥은 **여러 적을 유인해 모으고 범위 공격·일반스킬·궁극기로 처리하는 Hack & Slash** 구조다. 단일 적만 하나씩 배치한 전투로 대체하지 않는다.
- 기본 공격의 범위·차폐·대상 수, 스킬의 밀치기·끌어모으기·경직과 적의 추격·공격 예고·회복 틈을 데이터로 정한다. 근접은 다수 처리와 공간 확보, 원거리는 거리·직선 사격이라는 장점과 빈틈을 모두 갖게 한다.
- 약한 일반 적, 접근을 압박하는 적, 원거리 견제 적, 경직 저항이 있는 정예를 조합한다. 살아 있는 조작 캐릭터와 적 모두 서로의 물리 충돌 영역이 겹치거나 통과하지 않아야 한다. 생성·추격·돌진·넉백·코너·저장 복원에서도 유지하고, 공간이 없으면 멈추거나 우회한다. 밀집은 허용하지만 중첩을 허용하지 않는다. 발밑 점유 폭은 논리칸의1/2 또는1/3(외접 영역 면적1/4 또는1/9) 규모이며 기본1/2는 초기 제안이다. 스프라이트 장식과 발밑 충돌은 구분한다. 회피·돌진도 몸을 통과하지 못하고 포위되어 길이 막히면 실제로 탈출하지 못할 수 있다. 넉백은 빈 공간까지만 적용한다. 임의 순간이동/겹침 해제로 탈출시키지 않는다. 크기별 반경·통행·길찾기·구저장 복원 검사를 일치시킨다. 같은 프레임에 일제 공격하지 않게 하고, 화면 끝 탈출로 무상 처치·보상 복제를 반복할 수 없게 한다.
- 몰이 규모는 화면 크기·충돌·가독성·실기기 성능을 보고 정하는 **제안값**이다. 쿼터뷰의 초기 16×9 논리 구역 시험에서 동시 적 8~12마리를 검증하되, 측정 없이 출시 성능 목표로 확정하지 않는다.
- 보스룸은 부하·복수 장수를 허용한다(§5). 필드/보스룸 적의 공격반경 바닥 표시와 공격 준비 게이지는 표시하지 않는다. 준비 자세·공격 동작·소리와 공격 후 회복/재공격 간격으로 대응 기회를 주며 일반 적/정예/보스별 지연을 데이터로 조정한다. 즉발 피해·동시 일제 공격·무한 경직으로 대응을 없애지 않는다. 턴제의 조작용 이동/공격 범위 표시는 유지한다.
- 공격 판정·다중 피격·경직·넉백·처치 이벤트를 렌더링과 분리한다. 방향별 도트 동작, 준비·타격·후딜, 피격 섬광·효과음·짧은 타격 정지의 표현을 이후 에셋으로 교체할 수 있어야 한다. 최종 화풍·버튼 배치·타격감은 플레이 가능한 미리보기로 사람이 검수한다.
- 기본 공격은 캐릭터마다 세 유형 중 하나다.

| 공격 유형 | 방식 | 예 |
|---|---|---|
| 휘두르기 | 근접. 앞쪽 부채꼴 범위를 벤다 | 칼, 창, 도끼 |
| 화살 | 원거리 직선 투사체. 첫 몸체/차폐물에서 소멸, 비관통 | 활, 쇠뇌 |
| 에너지볼 | 원거리. 느리지만 강하거나 범위 효과가 있는 투사체 | 술법, 기공, 부채 |

- 능력치 반영 (능력치는 §7):

| 능력치 | 액션 전투에서의 효과 |
|---|---|
| 공격력 | 기본 공격과 스킬의 피해 |
| 방어력 | 받는 피해 감소, 회피 |
| 통솔력 | 캐릭터별 최대 체력. `최대 체력 = 50 + 통솔력 × 5` (제안, 턴제 병력의 1/10) |
| 기동력 | 이동 속도 |

- 체력은 캐릭터마다 따로 관리한다. 조작 캐릭터를 바꾸면 그 캐릭터의 남은 체력으로 싸운다.
- 체력 회복: 웨이포인트(파티 전원 최대), 회복 아이템(일부), 필드 사망 후 부활(최대). 챔피언 구역 진입 및 스토리 화면 왕복은 필드 회복/쿨다운 초기화 수단이 아니다.
- **액션 보조 모드**: 설정에서 켜면 공격 범위 안의 적을 자동으로 공격한다. 자동 조준과 받는 피해 감소도 함께 쓸 수 있다. 보상에는 영향을 주지 않는다.

## 5. 챔피언 사냥 구역 (기존 보스룸)

- 기존 보스룸의 지형·실내 공간·적 스킬을 재사용하되 **일반 사냥 월드의 선택 챔피언 구역**으로 편입한다. 별도 스토리 입장·전투 결과 화면·필수 승리 조건은 두지 않는다. 지역을 오가는 문/동굴 입구는 사냥 월드 이동으로만 작동한다.
- 특수 스킬·오라·부하가 있는 지정 챔피언을 처치하면 §3의 지정 유니크 장신구 계정1회 지급을 시도한다. 챔피언 재등장은 지역 리젠 데이터로 조절하며 재처치로 같은 유니크를 다시 얻을 수 없다. 장당2개/전체24개 할당과 메인 장 해금 의무는 폐지한다.
- 필드와 동일한 직접 조작·3인 전환·HP/두CD·사망 복귀를 사용한다. 진입 회복/독립 쿨다운·보스룸 전원전멸/웨이브 승리 체계는 이 선택 사냥 구역에 적용하지 않는다. 기존 duel 완료/보상 기록은 보존·이관하고, 옛 승리만으로 신규 유니크를 자동 지급하거나120스토리를 완료시키지 않는다.
- 부하/챔피언은 빈 위치에서만 생성하고 중첩·비통과·화살 차폐를 유지한다. 적 공격반경·준비 게이지는 없으며 준비/타격/회복 동작과 재공격 간격으로 대응한다. 일반 사냥 조우이므로 처치/입퇴장마다 스테이지 종료 광고를 붙이지 않는다.

### 챔피언과 특수 오라

- 필드·보스룸에 스킬 또는 특수 오라가 있는 챔피언몹을 둘 수 있다. 스토리 역할(장수 등), 전투 등급, 능력 modifier를 분리하여 다른 테마에서도 재사용한다.
- 공격 강화 오라·이동 강화·다중 투사체 등부터 검수한다. 오라 대상·반경·수치·중첩·해제 조건을 데이터로 정의하고 주체 사망/거리 이탈 시 제거한다. 동일 오라 최댓값 적용, 첫 장 특성1개, 완전 면역/불가피한 제어 조합 제외는 초기 제안이다.
- 이름·외형·스킬/오라의 실제 연출로 식별한다. 오라 자체의 지속 효과 표현은 허용하되 적 공격범위/준비 게이지를 다시 넣는 수단으로 사용하지 않는다.

## 6. 턴제 전투

### 기본 규칙

- 격자(사각형 칸) 맵에서 진행한다. 맵 크기는 출전 인원에 맞춰 작게 잡는다(제안: 작은 맵 8×10, 큰 맵 10×14). 큰 맵은 스크롤과 확대·축소를 지원한다.
- 출전 인원은 **최대 3명**이다. 특수 스테이지는 1~2명으로 제한할 수 있다.
- 승리 조건 기본형: **살아 있는 적 전투 유닛을 전멸시키면 즉시 승리**한다. 남은 적 성·막사를 모두 파괴할 필요는 없다. 거점은 주변 공격 버프를 제공하는 전략 목표다. 거점 파괴만으로 즉시 승리하지 않는다. 특정 적 격파·버티기·탈출 같은 특수 목표는 스테이지 데이터와 입장 안내에 명시한다.
- 턴 제한이 있다. 화면 상단에 `N턴째 / 제한 M턴`을 항상 표시하고, 남은 턴이 3 이하가 되면 강조한다. 턴 단위의 게임 내 이름(예: "일")은 게임별로 정한다.
- 제한 턴 산정: `제한 턴 = 기준 클리어 턴 × 난이도 계수`(제안: 기본 1.4, 어려움 1.1)를 맵 규모로 보정하고, **15~50턴 범위**로 자른다. 기준 클리어 턴은 뽑기 강화와 계정 성장 해금이 전혀 없는 편성으로 측정한 평균값이다.

| 스테이지 규모 | 제한 턴 기준 범위 |
|---|---|
| 작은 맵 (8×10 안팎), 장 초반 | 15~25 |
| 큰 맵 (10×14 안팎), 보스전 | 25~40 |
| 대규모 전투, 방어전 같은 특수 스테이지 | 40~50 |

  - 같은 스테이지는 어려움 난이도의 제한 턴이 기본보다 적다. 어떤 경우에도 15턴 미만이나 50턴 초과는 두지 않는다.

### 턴 진행

- **페이즈제**를 유지한다. 한 턴은 양쪽 진영의 페이즈로 이뤄진다. 가위바위보 선공 UI와 무작위 재선택을 없앤다. **선공 제안**: 스테이지 데이터로 정하며 기본은 아군 선공, 예외는 시작 전에 표시한다.
- **출전 배치**: 전투 시작부터 아군 막사를 배치한다. 복수 막사일 때 스테이지가 지정한 출발 막사 주변 8칸의 빈 통행 가능 칸에 최대 3명을 무작위 배치한다. 빈칸 부족은 잘못된 맵 데이터로 검사한다.
- **행동 예산**: 자기 페이즈에 각 캐릭터는 **이동 1회 + 공격행위 1회**를 각각 가진다(사용자 확인). 공격행위는 일반공격·일반스킬·궁극기 중 하나다. 이동하지 않고 공격할 수도 있다.
- **순서 제안**: 이동→공격과 공격→이동 모두 허용하되, 이동을 나눠 여러 번 하거나 두 번 공격할 수 없다. 이동 전 경로/도착점을 미리 보고 취소할 수 있으며, 확정된 공격 결과·난수를 취소 이동으로 되돌리지 않는다. 대기는 남은 행동 예산을 종료한다.
- **이동 스킬 보완안**: 시전자 위치를 바꾸는 돌진/순간이동 스킬은 공격행위와 이동 슬롯을 함께 소비한다. 이미 이동한 턴에는 해당 이동 스킬을 쓸 수 없다. 적에게 밀려나는 강제 이동은 자기 이동 횟수와 구분한다.
- 구출과 지형 장치 사용은 공격행위 슬롯을 소비하는 보조 행동이다. 이동 횟수와 공격행위 횟수는 별도로 저장하며 되감기로 함께 복원한다.
- 일반스킬·궁극기는 **전투당 1회 제한을 없애고 턴 단위 쿨다운**으로 재사용한다. **운용 제안**: 시작 시 사용 가능, 사용한 자기 페이즈 T에서 쿨다운 N을 설정하면 T+N 자기 페이즈 시작에 다시 사용 가능. 상대 페이즈에는 감소하지 않으며 포로여도 자기 진영 페이즈 시계는 동일하다. 필드의 초 단위 자원과 분리한다.

### 범위 공격과 스킬

- 적 칸으로 이동해 교전을 여는 방식을 없앤다. **자기 위치에서 범위에 들어온 적을 직접 공격**한다. 살아 있는 적과 포로의 칸은 이동할 수 없다.
- 공격/스킬/방어/퇴각의 동시 선택, 4×4 결과표, 적 페이즈 방어 선택 창을 없앤다. **초기안은 자동 반격도 없다**. 상대는 자기 페이즈에 공격하며, 추가 반격이 필요하면 별도 효과로 정의·검수한다.
- 일반공격은 아래 **전체 차폐 뒤를 제외한 범위 안의 유효한 적을 한 번에** 친다. 방향 하나나 적 한 명을 선택해 범위를 줄이는 방식이 아니다. `x,y`는 쿼터뷰 화면 좌표가 아닌 논리 격자다.

| 병과 | 자신의 칸 기준 일반공격 범위 | 최대 대상 칸 수 |
|---|---|---|
| 보병 | (±1,0), (0,±1): 상하좌우 인접 | 4 |
| 기병 | 주변 8방향 인접, 자신 제외 | 8 |
| 궁병 | (±1,0), (±2,0), (0,±1), (0,±2): 네 직선 길이2 | 8 |

- 궁병 대각선은 범위가 아니다. 인접 칸도 사거리1로 포함하며, 이전 인접 적 사격금지·전용0.75 계수는 새 전투에 자동 승계하지 않는다.
- **스킬은 일반공격 범위와 독립**이다. 캐릭터마다 일반스킬·궁극기 각각 대상 지정 방식(자신/방향/지점/유닛), 시전 거리, 효과 범위(직선/십자/부채꼴/주변 등), 대상 진영, 피해·회복·밀치기·상태 효과, 차폐/관통 조건을 정의한다. 고유 범위와 효과가 실제 차이를 만들도록 설계한다. 스킬에는 병과 상성이나 별도 속성 상성을 적용하지 않는다. 향후 상태이상을 효과 데이터로 추가할 수 있게 한다.
- **판정 제안**: 살아 있는 적 유닛과 파괴되지 않은 적 거점을 일반공격 대상으로 삼고 아군·포로·사체·파괴된 거점은 제외한다. 맵 밖은 잘라낸다. 차폐 지형 뒤는 일반공격 불가, 궁병은 같은 직선의 첫 차폐 지형 뒤 칸을 제외한다. 궁병의 각 직선은 앞에서부터 검사하며 첫 살아 있는 유닛(아군/포로 포함) 또는 파괴되지 않은 거점(양 진영)에서 막힌다. 유효한 적이면 그 대상만 타격하고, 아군/포로에는 피해를 주지 않는다. 앞 대상이 같은 시전에 죽거나 파괴돼도 그 시전은 뒤 대상으로 이어지지 않는다. 사체와 파괴된 거점은 막지 않는다. 네 방향은 독립적으로 검사한다. 화살형 스킬도 비관통 차폐를 따르며, 다른 유형 스킬의 관통/아군 효과는 데이터로 명시한다.
- 다중 대상은 시전 시작 상태로 고정해 대상 순서가 피해량을 바꾸지 않게 한다. 같은 대상은 한 시전에 한 번만 처리한다(명시적 다단히트 스킬은 타격 횟수대로). 이동 효과는 피해와 별도 순서로 결정하고 막힌 칸/다른 유닛 칸에 겹쳐 놓지 않는다.
- 실제 판정·예상 피해·범위 표시·AI는 같은 범위/효과 계산을 사용한다. 적 페이즈에는 결과를 자동 재생하며 플레이어의 대응 선택을 기다리지 않는다.

### 병과 균형 검수

- 병과는 일반공격 모양과 위치 선정의 차이를 만든다. 일반공격에만 기존 **기병 > 보병 > 궁병 > 기병** 상성을 유지한다(유리1.2배, 불리0.8배, 같은 병과1배). 일반스킬·궁극기는 이 배율과 별도 스킬 상성을 모두 적용하지 않는다. 스킬의 범위·효과·쿨다운으로 다른 선택을 만들고, 상태이상은 향후 확장할 수 있다.
- 같은 능력치·병력으로 1명/밀집 다수, 십자/대각선, 열린 평지/다리/차폐 지형을 대조한다. 궁병의 긴 범위뿐 아니라 기병8칸과 보병4칸의 처리량·위험·스킬 조합을 함께 측정한다. 실제 기본 편성의 무강화 클리어·턴 수·손실도 별도로 보고한다.
- 위력·쿨다운·적 배치로 보정하되 이전 교전용 배율을 근거 없이 이식하지 않는다. 약한 병졸1~2턴 처치와 범위를 잘 맞췄을 때의 다중 격파를 검수한다.

### 지형 (기본형, 제안)

| 지형 | 이동 비용 | 방어 보정 |
|---|---|---|
| 평지 | 1 | 0% |
| 숲 | 2 | +20% |
| 산 | 3 | +40% |
| 강 | 통과 불가 (다리는 1) | -10% |
| 성채·관문 | 1 | +30% |
| 성·막사 거점 | 생존 중 점유 불가(초기안), 파괴 후 바닥 비용 | 주변 같은 진영 공격 버프. 체력은 유닛 병력과 별도이며 아래 규칙을 따름 |
| 보급기지 | 1 | +10%. 병력 회복 (아래) |

- 지형 이름과 그림은 테마에 맞게 바꿀 수 있다. 수치 구조는 유지한다.
- **보급기지**: 맵 중간중간에 보급기지를 둔다. 아군이 보급기지 칸에 도달하면(그 칸에서 이동을 마치면) **병력이 회복**된다.
  - 회복량은 최대 병력의 50%(제안), 보급기지마다 전투당 1회 사용(제안).
  - 아군 전용이다. 적은 쓰지 않는다(제안).
  - 맵마다 1~2개를 두고, 위치는 스테이지 데이터로 정한다. 턴제 전투에서 병력을 회복하는 수단은 보급기지, 구출, 회복 스킬뿐이다.

### 성·막사 거점

- 맵 크기와 전선 배치에 맞춰 **적 성 또는 적 막사 1개 이상**, **아군 막사 1개 이상**을 전투 시작 시 배치한다. 거점마다 고유 ID·종류·진영·위치·최대/현재 체력·버프 영역을 가진다. 개수와 위치는 스테이지 데이터이며 전역 단일 요새 체력으로 공유하지 않는다.
- 살아 있는 거점은 주변의 **같은 진영 유닛**에 공격 버프를 제공한다. 아군 막사와 적 성/막사는 같은 효과 규칙을 사용한다. 이동해 영역을 벗어나거나 거점이 파괴되면 즉시 그 효과를 잃는다. 거점 자체의 공격·병력 생산·점령·자동 부활은 기본 규칙에 추가하지 않는다.
- **초기 검수안**: 논리 격자 맨해튼 거리2 이내, 공격 피해 ×1.2. 일반공격과 피해형 스킬에 적용하고 회복/제어에는 적용하지 않는다. 복수 거점이 겹쳐도 같은 거점 버프는 가장 큰 값 하나만 적용한다. 병과 상성은 여전히 일반공격에만 적용한다. 다른 버프와의 계산 순서는 구현 데이터로 명시한다.
- 일반공격·피해형 스킬의 유효 범위에 적 거점이 들어오면 공격할 수 있다. 거점에는 병과 상성·유닛 회피·포로·유닛 전용 상태이상을 적용하지 않는다(초기안). 복수 거점·유닛을 한 범위로 맞힐 수 있고, 시전 시작 스냅샷으로 계산하므로 거점 파괴 처리 순서가 같은 시전의 다른 피해를 바꾸지 않는다. 다음 행동부터 파괴된 거점의 버프는 사라진다.
- 거점 체력은 낮게 잡아 공성만 하다가 턴을 소진하지 않게 한다. **내구도 검수안**: 해당 구간 무강화·건강한 기본 편성의 일반공격 1~2회 명중으로 거점 하나를 파괴할 수 있는 수준부터 비교한다. 옛 요새의 일률적인 50% 피해 경감을 자동 승계하지 않는다. 성장한 부대의 1회 파괴는 허용한다. 체력·버프 수치·반경·개수 기준은 게임별 검수 후 확정한다.
- **배치 검수안**: 8×10은 진영별 1개, 10×14는 진영별 2개부터 시험한다. 개수만 늘리지 말고 접근 거리·차폐·공격 가능 위치와 거점을 무시한 전멸 경로를 검사한다. 생존 거점은 점유와 공격 시야를 막고, 파괴 후 잔해 바닥은 통행 가능하게 한다(초기안). 버프는 반경 내 지역 효과이며 시야 차폐로 끊지 않는다.
- 아군 막사를 잃어도 버프만 사라지며 기본 전투의 즉시 패배 조건은 아니다. 거점과 버프는 되감기로 함께 복원한다. 화면에 각 거점 체력·진영·효과 범위와 유닛의 현재 버프를 표시한다.

### 병력과 이동

- 병력(턴제 전투의 체력): `최대 병력 = 500 + 통솔력 × 50`. 매 전투 시작 시 가득 찬다.
- 이동 칸 수: `기본 3칸 + 기동력 5포인트당 1칸`, 최대 8칸.
- 적의 상하좌우 인접 칸(ZOC, 지배 영역)에 들어가면 그 이동 경로의 남은 이동이 끝난다. 이후 남아 있는 공격행위는 사용할 수 있다. 적 칸 진입 예외는 없다. ZOC는 이동 제한이며 일반공격 범위와 별도다.

### 병종

- 병종(병과)은 캐릭터가 인솔하는 보병·기병·궁병으로 캐릭터마다 고정이며, 필드의 무기/기본 공격 유형과 별개다.
- 병과별 일반공격 범위는 위 표를 따른다. 일반공격에만 위 순환 상성을 적용하고, 두 스킬에는 상성을 적용하지 않는다. 테마별 명칭이 달라도 공용 범위 판정 계약을 따른다.

### 전투 계산

- 직접 공격 한 번에 범위 안 대상별 피해·회피·상태 효과를 계산한다. 맞았다고 동시에 반격하지 않는다.
- 초기 피해식(제안): `피해 = 시전 시작 공격자 병력 × 계수 × (공격력+20)/(대상 방어력+20) × 능력 위력 × 일반공격 병과 보정 × (1−지형 방어 보정)`. 일반공격 병과 보정은 유리1.2/불리0.8/동일1, 스킬 시전에서는 항상1이다. 스킬 전용 상성표는 만들지 않는다.
- 피해 계수·방어 무시·회피 수치는 게임별 검수 대상이다. 회피는 대상별 결정적 난수로 처리하고, 예상값에는 확률을 표시한다. 범위 표시를 보는 것만으로 난수·쿨다운·행동이 소비되지 않는다.
- 거점 공격 버프는 위 거점 규칙을 적용하고 예상 피해·실제 피해·AI가 같은 계산을 쓴다. 병력이 줄면 이후 공격력이 줄어드는 구조는 유지한다. 아군은 상대 페이즈의 공격으로 손실을 입는다.

### 적 AI

적의 행동은 아래 순서로 정한다. 수치는 플레이테스트로 조정할 수 있다.

1. **행동 순서**: 적 페이즈가 오면, 아군과 가까운 적부터 한 명씩 행동한다.
2. **활성화**: 적은 처음에 대기 상태다. 아군이 **감지 범위**(이동 칸 수 + 2타일) 안에 들어오거나, 같은 무리의 적이 공격받거나, 스테이지 이벤트가 일어나면 활성화된다. 대기 상태의 적은 움직이지 않는다. (맵 전체의 적이 한꺼번에 몰려오지 않게 하기 위함)
3. **이동 가능 타일 계산**: 지형 이동 비용과 아군의 지배 영역(ZOC)을 반영한 최단거리 탐색(다익스트라)으로, 이번 턴에 갈 수 있는 타일을 모두 구한다.
4. **행동 후보 만들기**: 갈 수 있는 타일마다 그 위치에서 일반공격·사용 가능한 두 스킬의 타깃/범위·대기·공격 후 이동을 후보로 만든다. 적 칸 진입과 동시 대응 선택 후보는 만들지 않는다.
5. **점수 매기기**: 후보마다 아래 점수를 더한다. 역할마다 가중치가 다르다.

| 점수 요소 | 내용 |
|---|---|
| 예상 공격 이득 | 범위 내 모든 대상의 피해·회복·제어 이득. 일반공격에만 병과 상성과 지형 보정, 스킬에는 그 효과와 지형 보정, 다음 상대 페이즈의 위협 반영 |
| 마무리 | 이 공격으로 아군을 포로로 만들 수 있으면 큰 가산점 |
| 위험 | 다음 아군 페이즈에 이 타일을 공격할 수 있는 아군 수만큼 감점 |
| 지형 | 이 타일의 방어 보정만큼 가산 |
| 목표 거리 | 역할의 목표(아래)까지 가까워질수록 가산. 유닛 격파와 적 거점 버프 제거, 자신의 거점 버프 유지 이득을 비교 |
| 겹침 방지 | 이미 다른 적이 노린 아군을 또 노리면 감점 (한 명에게 몰리는 것을 줄임) |

6. **가장 점수가 높은 후보**를 실행한다.

| 역할 | 목표 | 성향 |
|---|---|---|
| 수비 | 요새 또는 지정 지점 | 지정 지점에서 일정 거리(3타일) 밖으로 나가지 않는다. 그 안에 들어온 아군만 노린다 |
| 요격 | 병력이 가장 적은 아군, 또는 일반공격 병과 상성이 유리한 아군 | 마무리와 상성 점수를 크게 본다 |
| 진격 | 아군 캠프 또는 가장 가까운 아군 | 목표 거리 점수를 크게 보고, 위험 점수는 작게 본다 |

- 스킬은 다중 타격·마무리·아군 회복·위치 제어 가치와 남은 쿨다운을 비교해 쓴다. 무효 대상·차폐 뒤 공격·끝없는 왕복을 최선 행동으로 고르지 않는다. 동점은 고정 순서로 해소해 재현 가능하게 한다.
- **난이도별 차이**: 기본은 현재 공격 이득 위주, 어려움은 다음 상대 페이즈의 위협·위치·장기 쿨다운 기회비용을 더 고려한다. 적 병력 배율은 별도 데이터다.

- 적은 보급기지를 쓰지 않고, 포로를 공격하지 않는다.

### 적 장수

- 턴제 전투의 적 중 일부는 **적 장수**다. 일반 적과 달리 이름과 일러스트가 있다.
- 적 장수의 특징:
  - **처음 공격을 주고받기 전 짧은 대화**(1~2줄)를 대화 화면 형식(§11)으로 보여 준다. 처음 한 번만 보여 주고, 같은 전투의 이후 공격에서는 생략한다.
  - **일반스킬·궁극기를 쓸 수 있다**. 아군과 같이 §6 턴 진행의 사용 제한을 따른다. 일반 적은 스킬이 없다.
- 일러스트: 적 장수마다 따로 그리지 않고, **공용 적장 일러스트 몇 종을 돌려가며** 쓴다(이름과 대사만 다르게). 표현 모드(§7)에 맞춰 오리지널·재해석 두 벌을 둔다. 몇 종을 둘지는 게임별로 정한다(기본 8종).
- 스토리 보스(§7 획득)는 적 장수와 별개로, 자기 전용 일러스트를 쓴다.
- 적 장수도 병력이 0이 되면 전장에서 사라진다. 적 장수를 쓰러뜨려도 별도 보상은 없다.

### 포로와 구출

- 병력이 0이 된 아군은 **그 자리에서 포로 상태**가 된다. 포로는 행동할 수 없다.
- 다른 아군이 포로와 **맞닿은 칸**에서 **구출** 행동을 하면 포로가 부활한다.
  - 구출하는 캐릭터는 그 턴의 공격행위 슬롯을 쓰고, **자기 현재 병력의 절반**을 포로에게 넘겨준다.
  - 부활한 캐릭터는 다음 아군 페이즈부터 행동한다.
- 포로가 있는 칸은 아무도 지나가거나 멈출 수 없고, 적은 포로를 공격하지 않는다.
- 적군은 병력이 0이 되면 포로가 되지 않고 전장에서 사라진다.
- 아군 전원이 포로가 되면 **전멸**이다.
- 포로가 된 캐릭터도 전투가 끝나면 페널티 없이 돌아온다.

### 승패와 보상

- **적 전멸 승리**: 기본 전투에서는 적 전투 유닛이 모두 쓰러지면 거점이 남아도 즉시 승리한다. 마지막 허용 턴의 공격으로 전멸시켰으면 턴 소진보다 승리를 먼저 판정한다. 거점만 파괴하고 적이 남았으면 계속 싸운다. 증원이 있는 특수 전투는 도착 예정 병력·종료 조건을 데이터로 명시한다.
- **보상**: 필수 턴제 승리는 재화·경험치·전투 기록과 연결된 메인 목표를 완료한다. 직접/자동 전투의 보상은 같다. 장 보상 캐릭터는 모든 필수 목표를 포함한 메인 장 완료에서 한 번 지급한다(§7).
- **경험치**: 출전한 캐릭터 전원(포로가 됐던 캐릭터 포함)이 받는다.
- **전투 중 이벤트**: 특정 턴 도달, 특정 지역 진입, 특정 캐릭터 포로·지정 위치 이탈 시 대사, 적 증원, 승리 조건 변경을 스테이지 데이터로 지정할 수 있다. 대사는 대화 화면(§11) 형식을 쓴다.

### 조작 편의

- 행동 확정 전 이동 취소.
- 이동·공격 범위를 다른 색/무늬로 표시한다. 일반공격/일반스킬/궁극기를 선택하면 유효한 모든 대상과 예상 피해·회피율·상태 효과·남은 쿨다운을 보여 준다. 과거4×4 선택 결과표는 표시하지 않는다.
- 적 이동 범위 보기.
- 적 페이즈 2배속과 건너뛰기.
- **한 판 자동 전투**: 입장 전에 플레이어가 선택한다. 아군의 이동·일반공격·두 스킬·구출·대기와 페이즈 종료를 AI가 같은 합법 행동으로 실행한다. 유닛 능력치·피해·난수·턴 제한·승패를 유리하게 바꾸지 않는다. 승리 보장이 아니며, 필드 사냥·퍼즐·보스룸까지 자동화하지 않는다.
- 광고 보상 한 번은 해당 도전 한 판에만 사용한다. 승리·패배·포기하면 끝나고 다음 판이나 자동 재도전으로 이어지지 않는다. 일시정지와 수동 전환을 지원하며 같은 판의 재개가 새 권리 소비나 광고 재시청을 요구하지 않게 한다. 실패 시 AI가 광고/되감기를 자동 실행하지 않는다. 되감기 선택과 횟수는 기존 규칙을 따르고, 되감기 후에는 직접 조작한다(초기안).

### 재도전(되감기)과 실패

- 실패 조건과 재도전 혜택 기본형:

| 실패 조건 | 재도전 혜택 |
|---|---|
| 아군 전멸 | 5턴 전으로 되감기 |
| 제한 턴 소진 | 10턴 전으로 되감기 |

  - 전투가 시작된 지 5턴(또는 10턴)이 지나지 않았으면 1턴째로 되돌아간다.
- 횟수: 스테이지 1회 도전당 **기본 최대 3회, 어려움 최대 1회**. 전멸과 소진을 합산한다. 광고 제거 여부와 관계없이 모든 플레이어가 같다.
- 광고 제거가 적용되지 않았으면 재도전할 때마다 보상형 광고를 1회 보고, 적용 중이면 광고 없이 쓴다.
- 재도전을 다 썼거나 포기하면 스테이지가 실패로 끝나고 짧은 광고가 나온다(광고 제거 적용 중이면 없음).
- 재도전 혜택의 게임 내 이름은 게임별로 정한다.

## 7. 캐릭터

### 획득

- 기본 획득 경로:
  - **기본 제공**: 처음에 3명. 세 명이 **병종 셋(기병·보병·궁병)을 하나씩** 맡고, 기본 공격은 **근접과 원거리를 섞어**, 초반부터 병종 상성과 캐릭터 교체 조작을 익히게 한다.
  - **장 보상**: **장마다 1명**. 그 장의 스토리에서 가장 중요한 캐릭터(장의 보스, 또는 그 장에서 합류하는 인물) 한 명을 그 장의 필수 턴제 경로와 마지막 이야기 목표를 처음 완료할 때 준다. 이미 가지고 있으면 강화 단계가 1 오르고, 최대 단계면 대신 재화 30을 준다. 12장이면 장 보상은 12명이다. **지급 범위 제안**: 계정·장별 최초 1회이며 어려움+에서는 캐릭터를 재지급하지 않는다. 난이도별 스테이지 재화 보상은 과금 지침대로 별도다.
  - **뽑기**: 모바일판에서 기본 제공과 장 보상 외의 캐릭터는 **뽑기로만** 얻는다. 모든 캐릭터가 처음부터 뽑기 풀에 있다(과금 지침). 개별 보스룸 상대나 턴제 보스 자체가 추가 캐릭터 보상을 주지는 않는다. 장의 메인 완료 보상은 별도로 지급한다.
- **인기 캐릭터**: 게임마다 테마에서 인기가 높을 캐릭터를 **4~6명** 지정한다(그중 최상위 2명 포함). 인기 캐릭터는 **장 보상으로 주지 않고 뽑기 전용**이다. 스토리의 핵심 인물이어도 장 보상은 그 장의 다른 관련 인물로 정하고, 인기 캐릭터는 게스트로 출전한다.
  - **최상위 인기 2명**은 계정당 **한 번씩** 상점에서 직접 살 수 있다(과금 지침 "최상위 인기 캐릭터 1회 구매").
- **게스트 출전**: 스토리에 동료로 나오지만 아직 보유하지 않은 캐릭터는, 스토리상 필요한 스테이지에서만 **게스트**로 출전한다(스토리상 함께 싸우는 턴제 전투). 게스트는 그 스테이지 전용의 고정 능력치로 나오고, 스테이지가 끝나면 빠진다. 보유한 캐릭터라면 게스트 대신 플레이어의 캐릭터가 나온다. 써 보고 마음에 들면 뽑기로 얻게 하는 판매 동선이기도 하다.
- 모든 캐릭터에 **스토리 획득 목표**를 데이터로 지정한다. 목표에는 메인 경로의 장·퍼즐·사냥·필수 턴제·대결 완료 ID를 쓴다. 모바일판에서는 장 보상 12명만 이 데이터로 지급하고, 뽑기가 없는 스팀판은 이 데이터로 모든 캐릭터를 무상 지급한다(과금 지침 "스팀(PC)판").
- 캐릭터에는 등급이 없다.
- **성인 설정** (예외 불가): 모든 플레이 캐릭터는 **성인(18세 이상)**으로 설정하고 성인으로 디자인한다. 원전에서 어린 나이인 인물(소년 왕, 소년 영웅 등)도 성인 시점으로 그린다. 소개 문구에 "소년", "소녀" 같은 미성년 표현을 쓰지 않는다. 재해석 모드와 스킨이 미성년자를 성적으로 그린다는 비판과 스토어 정책 위반을 막기 위해서다.
- **캐릭터 명단**: 게임마다 **30명 이상**. 병종은 **보병과 기병이 궁병보다 많게** 짠다(책사·군주처럼 원거리 이미지인 인물도 보병·기병에 배치할 수 있다. 병종과 기본 공격 유형은 따로 정한다).

### 스토리 속 퇴장과 보스 획득

- **스토리에서 죽거나 퇴장한 캐릭터도 편성에서는 계속 쓴다.** 원전대로 스토리에서 퇴장하더라도(예: 삼국지의 관우), 그 캐릭터는 보유 목록에 남고 이후 스테이지에 출전할 수 있다. 키우고 과금으로 강화한 캐릭터를 잃지 않게 하기 위해서다.
  - 퇴장 이후의 스토리 대화에는 나오지 않는다. 출전 중인 전투에서는 전투 대사만 한다.
  - 원하는 게임은 퇴장을 피하는 if 결말을 분기나 특수 스테이지로 둘 수 있다.
- **획득은 스토리와 별개다.** 원전에서 죽거나 끝까지 적으로 남는 인물도 장 보상이나 뽑기로 얻으면 캐릭터 명단에 오른다. 스토리에서 그 인물이 아군이 되었다고 바꾸지 않는다.
- 장의 보스가 사람이 아니면(괴물 등) 그 장에서 구하거나 되돌린 인물을 장 보상으로 정한다.

### 능력치

| 능력치 | 턴제 전투 | 액션 전투 (필드, 보스룸) |
|---|---|---|
| 공격력 | 피해량 | 기본 공격과 스킬 피해 |
| 방어력 | 받는 피해 감소, 회피 | 받는 피해 감소, 회피 |
| 통솔력 | 최대 병력 | 최대 체력 |
| 기동력 | 이동 칸 수 | 이동 속도 |

### 성향

- 캐릭터와 장비에는 성향이 있다: **지휘관형, 암습형, 돌격형, 방어형**.
- 성향은 상성에 쓰지 않는다. **장비를 통해 능력치에 가점을 주는 역할**만 한다(§8).

### 성장

- 처음 얻은 캐릭터는 1레벨이며, 능력치 포인트 **20**이 그 캐릭터의 특성에 맞게 네 능력치에 나눠져 있다.
- 레벨은 스토리 턴제 스테이지 경험치를 주 성장원으로 올린다. 필드 사냥·선택 챔피언에서도 매우 적은 경험치로 성장 가능하다. 필드 보상은 출전 파티3명에게 지급한다. 무강화 기본·장 보상 편성, 희귀 장신구/반복 사냥/광고 자동 전투 없이 스토리 경로를 검증한다.
  - 경험치량·필요량은 장/적/목표별 데이터로 조절하는 제안값이다. 종전 스테이지 승리마다 무조건 +1레벨, 패배 1/10 규칙을 대체한다. 스토리는 최초/반복 보상, 필드는 출현 주기별 처치 보상을 구분한다. 처치당 경험치와 같은 성장대의 실측 분당 경험치 모두 스테이지 대비 매우 낮게 검수한다. 필드/스테이지/필요 경험치의 비율과 상한은 초기 검수값이며 무한 사냥이 필수 성장원이 되지 않게 한다.
  - 필드 사냥 경험치는 출전 파티 3명에게 지급해 리더 교체가 성장을 손해 보게 하지 않는다. 실패·구역 이동·저장 복구에서 동일 처치나 목표 경험치를 중복 지급하지 않는다.
  - 최대 레벨은 **50**이다. 50레벨의 능력치 총합은 20 + 49×3 = 167이다.
- 레벨이 오를 때마다 능력치 포인트 **3**을 얻고, 플레이어가 네 능력치 중 원하는 곳에 하나씩 투자한다.
- 능력치 초기화: 캐릭터별 **첫 1회 무료**, 이후 **재화 100**.
- 중복 강화: 같은 캐릭터를 다시 얻으면(뽑기, 장 보상) 강화 단계가 1 오르고 **보너스 능력치 포인트 +5**를 얻는다. 최대 **+5단계(보너스 +25)**다. 최대 단계면 뽑기 풀에서 빠진다.
  - +25는 50레벨 총 포인트(167)의 약 15%로, 체감은 되지만 전략을 대신하지 않는 수준이다.
  - 스팀판은 뽑기가 없으므로 재화 300으로 1단계씩 강화한다(과금 지침 "스팀(PC)판").
  - 강화 단계는 초상화 테두리와 발밑 오라로 눈에 보이게 표시한다(아래 "강화 단계 표시").

### 강화 단계 표시

- **강화 단계마다** 눈에 보이는 표시가 붙는다. 두 표현 모드 모두에서 보인다.
  - **초상화 효과**: 필드 왼쪽 위 캐릭터 상태, 대화 화면, 캐릭터 상세의 초상화 테두리가 단계마다 바뀐다.
  - **발밑 오라**: 필드에서 조작하는 캐릭터의 발밑에 단계별 오라가 생긴다. 보스룸과 턴제 전투의 유닛에도 같은 오라를 보여 준다.

| 강화 단계 | 초상화 효과 | 발밑 오라 |
|---|---|---|
| +0 | 기본 테두리 | 없음 |
| +1 | 동색 테두리 | 옅은 동색 원 |
| +2 | 은색 테두리 | 은색 원 |
| +3 | 금색 테두리 | 금색 원, 은은한 반짝임 |
| +4 | 금색 테두리 + 빛나는 모서리 | 금색 원 + 위로 오르는 빛 입자 |
| +5 (각성) | 각성 전용 테두리(움직이는 빛) | 각성 오라(캐릭터 성향 색, 바닥 문양과 빛 기둥) |

- 오라는 도트 그래픽에 맞는 단순한 효과로 만들고, 저사양 기기에서는 입자 수를 줄인다.
- 최대 강화 때는 비매품 각성 스킨도 준다(과금 지침 "각성 스킨").

### 표현 모드

- 캐릭터 디자인을 **오리지널**과 **재해석**(게임별 컨셉) 중에서 고를 수 있다. 처음 실행할 때 고르고, 설정에서 언제든 바꾼다.
- 바꾸면 일러스트(초상화, 스탠딩, 컷인)와 도트 스프라이트가 모두 바뀐다. 두 모드 모두 일러스트와 도트를 한 벌씩 만든다. 게임 규칙과 능력치는 같다.
- 출시 후 스킨은 재해석 모드 전용으로만 만든다(과금 지침).
- **대사 두 벌**: 스토리 대사, 캐릭터 대사, 전투 대사는 모드별로 **따로** 쓴다. 재해석 모드는 여성 캐릭터끼리의 대화이므로 말투와 분위기를 바꾼다.
  - **성격과 사건은 오리지널을 따른다.** 같은 장면, 같은 선택지, 같은 결과다. 바뀌는 것은 말투, 호칭(예: 의형제 → 의자매, 형님 → 언니), 리액션이다.
  - 재해석 대사는 **외모에 어울리는 말투**로 쓰고, **가벼운 개그**를 넣는다(티격태격, 허당 리액션, 캐릭터 버릇을 살린 농담 등). 개그는 장면당 한두 마디로, 이야기 흐름을 끊지 않게 한다.
  - 개그를 넣지 않는 장면: 죽음·퇴장·비극 장면, 마지막 결전 직전, 공포 연출 중.
  - 개그 금지: 성적인 농담, 외모·몸매 평가, 특정 집단 비하, 실존 인물·신앙 대상을 우스개로 만드는 것. 게임별로 **개그 제외 인물**(국가적으로 존경받는 인물, 신앙 대상, 성직자)을 정해 그 인물은 재해석에서도 품위 있는 말투만 쓴다(본인이 개그를 하지 않을 뿐, 다른 인물의 개그에 반응할 수는 있다).
  - **연애·혼인 관계**: 재해석 모드는 모든 캐릭터가 여성이므로, 원작의 연애·혼인 관계(부부, 연인, 짝사랑)는 재해석에서 **"평생의 맹세", "충성 서약" 같은 깊은 신뢰 관계**로 바꾼다. 배신, 갈등, 이별, 비극 같은 **사건은 그대로** 둔다. 캐릭터 설명의 관계 표기(아내, 연인)도 재해석 화면에서는 맹세 관계로 표시한다(예: "토르의 아내" → "토르와 평생을 맹세한 전우"). 시장마다 다른 동성 관계 표현 규제와 반발을 피하고, 이야기 구조는 원작대로 지키기 위해서다.
  - 대사가 없는 쪽 모드로 빠지지 않게, 스토리 대사는 모든 줄을 두 벌 다 만든다. 시스템 문구(메뉴, 튜토리얼 안내)는 한 벌을 같이 쓴다.
- **성직자 캐릭터** (승려, 비구니, 사제, 성녀, 무녀, 수녀 등 종교인): 두 모드 모두 **노출 없는 디자인**으로만 만들고, 노출이 있는 스킨을 만들지 않는다.

## 8. 장비

### 기능성 보조장비

- **필드 도구**, **보조장비**, **페어 장비**를 구분한다. 도구는 새 길과 퍼즐 조작을 열고, 보조장비는 사냥·회피·지형 대응 등 플레이 방식을 보완하며, 페어 장비는 기존 능력치 가점·강화를 담당한다.
- 보조장비는 퍼즐·사냥 목표·보스 보상으로 얻는다. **스토리에 필수인 기능은 스토리 경로에서 확정 획득**하며, 유료 구매·뽑기·광고 시청·희귀 확률 드롭이 진행 조건이 되지 않는다. 필요한 캐릭터 기능도 기본·장 보상·해당 구간 게스트 또는 도구로 해결할 수 있게 한다.
- **슬롯 제안**: 캐릭터당 보조장비 1칸을 페어 장비 1칸과 별도로 둔다. 필수 통행 능력은 획득 후 해금 기록으로 남겨 장비 교체로 길에 갇히지 않게 한다. 효과·중첩·교체 허용 시점은 데이터와 테스트로 정한다.
- 보조장비는 기존 페어 장비 뽑기 풀·중복 강화 상품에 넣지 않는다. 보조장비 획득·장착·기능 해금 기록은 저장 대상이다.

### 필드 장신구

- 필드 획득 장비는 목걸이·반지·부적 같은 장신구류이며 무기를 드롭하지 않는다. 기존 페어 장비의 무기/장비 뽑기 체계를 삭제하는 결정은 아니다.
- 일반 장신구는 반복 드롭, 지정 유니크는 챔피언별 계정1회 보상이다. 캐릭터당 보조장비1칸에 장착하는 초기안을 사용하고 기존 기능성 보조장비와 교체한다. 별도 추가 스킬 슬롯은 만들지 않는다. 유니크 표시는 획득 희소성으로, 기존 페어 장비의 등급/강화 규칙을 바꾸지 않는다.
- 유료 뽑기 풀·중복 강화 상품에 넣지 않는다. 기존 보조장비는 삭제하지 않고 보유/효과를 유지한다. 유니크 미보유로 스토리 길이 막히지 않게 한다.

### 페어 장비

- 장비에는 등급이 없다.
- **캐릭터 하나에 상징 장비 하나를 페어로 함께 출시한다.** 새 캐릭터를 추가하면 그 페어 장비도 장비 뽑기 풀에 함께 추가된다.
- 페어 장비는 장비 뽑기로 얻는다. 기본 제공 캐릭터 3명의 페어 장비는 **튜토리얼 보상으로 지급**한다.
- 장비는 최대 강화에 도달하기 전까지 뽑기 풀에 남는다. 이미 가진 장비(튜토리얼로 받은 장비 포함)가 다시 나오면 강화된다.
- 캐릭터 한 명은 페어 장비 **1개**를 장착한다(보조장비 슬롯은 별도). 장비는 전용이 아니어서 누구나 장착할 수 있다.
- 장비의 효과는 **능력치 가점**뿐이다. 장비 하나당 가점 합계는 **+10**이고, 네 능력치에 장비마다 다르게 배분한다.
- 성향 보너스 (두 조건을 모두 만족하면 **높은 쪽 하나만**):

| 조건 | 장비 가점 보너스 | 예: 가점 +10 장비 |
|---|---|---|
| 성향 불일치 | 없음 | +10 |
| 캐릭터와 장비의 성향이 같음 | **+10%** | +11 |
| 캐릭터와 그 페어 장비 | **+30%** | +13 |

- 중복 강화: 같은 장비를 다시 얻으면 강화 단계가 1 오르고, 단계마다 가점이 +10% 오른다. 최대 +5단계다. 강화 보너스와 성향 보너스는 곱한다.

## 9. 계정 성장

- 계정 경험치: 스테이지 **첫 클리어 100**(난이도별 따로), **재클리어 20**. 메인 퍼즐·사냥 목표도 계정 경험치 획득처로 두고 첫 완료/반복량을 데이터로 정한다(수치 제안). 계정 성장 획득처를 턴제 하나로 제한하지 않는다.
- **성장** 메뉴에서 계정 **5레벨마다** 해금 단계가 하나씩 열린다. 단계마다 **재화 100**을 써서 해금한다.
- 해금 효과: 단계마다 **전체 캐릭터의 능력치 1종 +2**. 순서는 공격력 → 방어력 → 통솔력 → 기동력을 반복한다.
- 해금하지 않아도 클리어할 수 있는 작은 폭으로 둔다. 기준 난이도는 해금이 전혀 없는 상태로 검증한다.

## 10. 도전과제

| 종류 | 내용 | 보상 |
|---|---|---|
| 업적 | 1회성 목표 (예: 1장 클리어, 캐릭터 10명 모으기) | 재화 20~100 |
| 일일 과제 | 매일 초기화되는 목표 (예: 스테이지 3회 클리어, 필드 적 20마리 처치) | 과제당 재화 10 |

- 일일 과제는 하루 3개다(하루 최대 재화 30).
- 업적 보상 총량은 게임별로 정하고, 과금 지침의 무료 획득 속도에 맞춰 관리한다.
- **어려움+ 전용 업적**: 어려움+ 장 클리어, 힌트 없이 장 클리어, 재도전 없이 보스 클리어 등. 보상은 같은 종류 기본 업적의 3배다(§2 어려움+).

### 인연 도전과제 (캐릭터 수집)

키우지 않는 캐릭터도 가지고 있는 것만으로 의미가 있게 하는 수집 도전과제다.

- 스토리의 중요한 장면마다 **관련 캐릭터 3명으로 된 "인연"**을 하나씩 정한다(예: 의형제를 맺는 장면의 세 사람).
- 세 명을 모두 **보유**하면(출전하거나 키우지 않아도 됨) 인연이 완성된다.
  - 그 장면의 **장면 일러스트**가 인연 도감에서 열린다(모든 나라 공통). 표현 모드에 맞춰 두 벌을 둔다.
  - **1회 보너스 재화**를 준다(제안: 인연마다 50).
  - **특정 상황에서만 켜지는 전투 버프**가 영구히 적용된다. 버프는 계정 전체에 적용되고, 그 세 명이 출전하지 않아도 켜진다.
- 버프의 상황 유형:

| 상황 유형 | 예 |
|---|---|
| 장 | 그 장면이 나오는 장의 스테이지에서 |
| 지형 | 특정 지형(강, 다리, 숲 등)에서 공격할 때 |
| 상대 병종 | 특정 병종을 공격하거나 그 공격을 받을 때 |
| 모드 | 보스룸에서, 또는 필드 전투에서 |
| 행동 | 스킬을 쓸 때, 방어를 고를 때 |

- 버프 크기는 작게 둔다(제안: 인연 하나당 해당 능력치 또는 피해 +5%). 같은 상황에 여러 인연이 겹치면 합계 최대 +15%(제안).
- 기준 난이도 검증은 인연 버프가 하나도 없는 상태로 한다(과금 지침 "난이도 설계 규칙").
- **첫 인연은 기본 제공 캐릭터 3명**으로 구성해, 게임을 시작하자마자 완성되게 한다. 인연 기능과 도감을 처음 보여 주는 튜토리얼로 쓴다.
- 장면 일러스트는 여러 캐릭터가 한 그림에 나오므로, 캐릭터별 얼굴과 의상을 맞추는 데 시간이 더 든다. 수직 슬라이스에서 첫 인연의 장면 일러스트로 제작 방식을 먼저 시험한다(개발·출시 지침 §8).
- 성장 메뉴에 **인연 도감**을 두어, 인연 목록, 모은 캐릭터, 완성 여부와 버프 내용을 보여 준다. 아직 없는 캐릭터는 실루엣으로 보여 주고 얻는 방법(스토리, 주간 직접 판매, 뽑기)을 알려 준다.
- **일본**: 경품표시법의 "콤프가챠" 규제(유료 뽑기로 특정 조합을 모으면 보상을 주는 구조 금지) 때문에, 일본에서는 인연이 캐릭터 보유와 연결되지 않게 한다. 인연 장면 일러스트는 **캐릭터 보유가 아니라 스토리 진행**(그 장면이 나오는 장을 클리어)으로 열리고, 보너스 재화와 전투 버프는 주지 않는다. 일본 출시 전 법무 확인을 받는다.
- **한국 등**: 캐릭터를 모아 보상을 받는 구조는 한국 게임산업법상 "컴플리트형" 확률형 아이템 표시 대상일 수 있다. 확률 공개 화면에 인연 보상 구조를 함께 안내한다(과금 지침 "법규·스토어 준수").
- 인연 구성 규칙: 모든 인연은 가능하면 뽑기 없이도 완성할 수 있게 짠다(스토리 획득 또는 주간 직접 판매). 일본 외 지역에서도 "뽑기로만 모을 수 있는 조합"이라는 인상을 줄이기 위해서다.

## 11. 화면과 UI

- 아트: 필드와 전투는 **도트 그래픽 쿼터뷰**, 캐릭터는 **일러스트**(대화, 상세 화면, 획득 연출, 컷인).
- 화면 방향: **가로**, 양손 조작.
- 필드 화면 배치:

| 위치 | 구성 |
|---|---|
| 왼쪽 위 | 캐릭터 상태(조작 중인 캐릭터 초상화, 체력, 파티 교체). 누르면 메뉴 |
| 오른쪽 위 | 미니맵(누르면 사냥 월드맵), **미니맵 왼쪽 스토리 진행 버튼**, 아래 필드 경로 힌트 |
| 캐릭터 주위 | 목표 화살표 (§3) |
| 왼쪽 아래 | 가상 조이스틱 |
| 오른쪽 아래 | 공격, 회피, 일반스킬, 궁극기 |

- 필드 화면 **왼쪽 위의 캐릭터 상태**를 누르면 메뉴로 들어간다.

| 순서 | 메뉴 | 내용 |
|---|---|---|
| 1 | 상점 | 재화 충전, 광고 제거 상품, 뽑기 |
| 2 | 장비 | 페어 장비·보조장비 목록과 장착, 도구·기능 해금 확인 |
| 3 | 성장 | 하위 탭 2개: **캐릭터**(레벨, 능력치 투자, 초기화, 강화 단계, 파티 편성) / **계정**(계정 레벨, 성장 해금) |
| 4 | 도전과제 | 업적, 일일 과제 |
| 5 | 지도 | 사냥 월드맵, 선택 탐험 목적지, 발견한 웨이포인트(워프). 스토리 선택/전투 기록은 별도 화면 |

### 캐릭터 첫 등장 소개

- 캐릭터(아군, 보스)가 스토리에 처음 나올 때 짧은 **소개 카드**(일러스트, 이름, 한두 줄 소개)를 보여 준다. 테마를 잘 모르는 해외 플레이어도 인물 관계를 따라오게 하기 위해서다.
- 지나간 소개는 성장 메뉴의 캐릭터 상세에서 다시 볼 수 있다.

### 소리

- 대화는 글자가 나올 때 캐릭터마다 다른 짧은 **말소리 효과음**을 낸다(언어 무관).
- 캐릭터 음성은 짧은 외침(스킬, 보스룸 진입·승리·패배, 피격·기합)으로 한정하고, 표현 모드마다 다른 목소리를 쓴다. 기본은 언어가 없는 기합·감탄 소리다. 스토리 대사는 더빙하지 않는다.
- 설정에서 배경음악, 효과음, 음성 크기를 따로 조절한다.

### 대화 화면

캐릭터끼리 또는 NPC와 대화할 때:

```
┌──────────────────────────────────────────────────────────┐
│ [왼쪽 화자    ]   ┌ 말풍선 (왼쪽 화자) ┐           [오른쪽 화자  ] │
│ [ 일러스트    ]   └─────────────────┘           [ 일러스트    ] │
│ [ (상반신)    ]          ┌ 말풍선 (오른쪽 화자) ┐  [ (상반신)    ] │
│ [             ]          └──────────────────┘  [              ] │
│ [ 이름        ]   ┌ 말풍선 …          ┐           [ 이름        ] │
│                       [ 선택지 1 ]  [ 선택지 2 ]                  │
└──────────────────────────────────────────────────────────┘
```

- 왼쪽과 오른쪽에 대화하는 두 인물의 일러스트를 보여준다. 말하는 쪽은 밝게, 듣는 쪽은 어둡게 표시한다.
- 가운데는 **채팅 화면처럼 말풍선이 위에서 아래로 쌓인다**. 왼쪽 인물의 말은 왼쪽 정렬, 오른쪽 인물의 말은 오른쪽 정렬이다. 위로 스크롤하면 앞 대화를 다시 볼 수 있다.
- 선택지는 가운데 아래에 버튼으로 나오고, 고른 선택지는 플레이어 쪽 말풍선으로 쌓인다.
- 일러스트는 표현 모드를 따른다. 셋 이상이 대화하면 말하는 인물로 좌우 자리를 바꿔 넣는다.
- 화면을 누르면 다음 대사로 넘어간다. 자동 넘김과 건너뛰기 버튼을 둔다.

- v18 발행·구현 기준 채택은 2026-11-01 사용자가 승인했다. 사용자 결정은 쿼터뷰·캐릭터 전환 유지·궁극기 쿨다운·필드 적 비중첩·턴당 이동1회+공격행위1회·병과별 범위 일괄 타격·일반공격만 병과 상성 유지·스킬 고유 범위/효과(상성 없음, 상태이상 향후 가능)·모드 간 같은 스킬 이름이다. 선공·행동 순서·반격·쿨다운 수치 등 보완안은 CR-003의 초기 검수안이며 최종 디자인·체감 승인과 구분한다.
