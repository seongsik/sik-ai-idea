# 스테이지 기반 전략 게임 기본 골격

> 한 줄 요약: 내가 만드는 게임의 공통 게임 규칙. 가로 화면 도트 탑뷰 RPG로, 퍼즐을 풀고 적 무리를 모아 사냥하며 도구·보조장비·캐릭터를 얻어 새 구역과 1:1 액션 보스전에 도전한다. 격자 턴제는 개수를 유지하는 선택 콘텐츠다. 개별 게임은 테마(명칭, 캐릭터, 스토리, 필드)만 바꾼다.
>
> 최종 수정: 2026-11-01 (v17: 액션 중심 공통 골격)

- 카테고리: game
- 문서 유형: 공통 지침 (개별 아이디어가 아님)
- 작성일: 2026-11-01
- 적용 대상: 개별 게임 기획서가 "스테이지 기반 전략 게임 기본 골격을 따른다"고 명시한 모든 게임

## 이 지침의 사용법

게임 관련 공통 지침은 세 개이고, 함께 쓴다.

| 지침 | 정하는 것 | 이 아이디어 리포지터리의 경로 |
|---|---|---|
| **스테이지 기반 전략 게임 기본 골격** (이 문서) | 게임 규칙: 구조, 필드, 전투, 캐릭터, 장비, 성장, 화면 | `game/stage-strategy-framework/README.md` |
| **게임 개발 공통 과금 지침** | 돈: 재화, 가격, 뽑기, 광고, 환불, 스팀판 과금 | `game/monetization-guideline/README.md` |
| **게임 개발·출시 공통 지침** | 만들고 내는 방법: 엔진, 코드 구조, 서버, 다국어, 개발 도구, 아트 파이프라인, 출시 체크리스트, 개발 단계 | `game/dev-release-guideline/README.md` |

- 개별 게임 기획서에는 지침 내용을 다시 쓰지 않는다. 각 지침의 "게임별로 정의할 항목"(테마 데이터)과 그 게임만의 고유 내용만 적는다.
- 구현은 별도 리포지터리에서 하고, 이 아이디어 리포지터리의 공통 지침 세 개와 게임 기획서를 **참조**해 개발한다. 이 리포지터리에는 아이디어와 지침만 기록하고 구현물은 두지 않는다.
- 지침과 게임 기획서가 충돌하면 지침이 우선한다. 예외가 필요하면 게임 기획서에 "지침 예외"로 명시하고 이유를 적는다.
- 게임 내 명칭은 **캐주얼하고 직관적인 이름**을 쓴다. 세계관 색이 강한 고유 용어는 캐릭터 이름, 상징 장비 이름, 스토리에만 쓴다.
- "(제안)"이 붙은 수치와 방식은 초기 설계값이다. 구조는 유지하고, **난이도와 밸런스에 관련된 제안값(지형 수치, 피해 공식, 회피율, 난이도 계수, 보급기지 회복량, 드롭 확률, 1:1 대결 승리 조건, 인연 보너스 재화·버프 크기 등)은 플레이테스트로 확정한다**. 확정 전까지는 원격 설정으로 바꿀 수 있게 둔다.

## 1. 게임 구조

- **가로 화면 도트 탑뷰 RPG**다. 메인 화면은 필드이고, 게임을 켜면 마지막으로 저장한 필드 위치에서 시작한다.
- 세 가지 모드로 이뤄진다.

| 모드 | 언제 | 방식 |
|---|---|---|
| 필드 | 평소 | 캐릭터를 조작해 탐험. 퍼즐, NPC 대화와 선택, 적 무리를 유인·밀집시켜 처리하는 액션 사냥 (§3, §4) |
| 1:1 대결 | 스토리의 정해진 대결 지점, 1:1 대결 스테이지 | 일반 적이 없는 1:1 전장에서 필드와 같은 액션 전투 (§5) |
| 턴제 전투 | 필드에서 발견하고 선택해 입장하는 전투 지점 | 격자 맵에서 출전 3명으로 싸우는 턴제 전략 전투 (§6) |

```
필드 (액션 탐험) ── 일반 적 ──> 필드 액션 전투 (그 자리에서)
     │
     ├─ 선택 전투 지점에서 입장 선택 ──> 턴제 전략 전투 (별도 화면, 출전 3명)
     │
     ├─ 1:1 대결 지점 도착 ────> 1:1 전장 (필드와 같은 액션, 일반 적 없음)
     │
     ├─ 웨이포인트 ──> 발견한 웨이포인트로 워프 (지도 메뉴)
     │
     └─ NPC 대화·선택, 퍼즐, 상자, 구역 이동(자동 저장)
```

- 턴제 전투와 1:1 대결을 묶어 **스테이지**라고 부른다. 1:1 대결은 턴제 전투 안에서 일어나지 않는다.
- 필드 구성은 「젤다의 전설: 꿈꾸는 섬」을 오마주한다. 참고하는 것은 필드 구성과 조작감(방 단위 구성, 퍼즐, 트릭, 숨은 길, 도구로 길 열기)뿐이다. 닌텐도의 그래픽, 음악, 맵 배치, 아이템 디자인과 이름, "젤다" 명칭은 쓰지 않고 홍보 문구에도 쓰지 않는다.
- 스태미나는 두지 않는다. 필드 탐험과 스테이지는 언제든 제한 없이 할 수 있다.
- **테마 고유 시스템**: 게임마다 테마에서 나온 고유 시스템을 **2개 이상** 둔다. 같은 골격의 게임이 그림만 바꾼 것으로 보이지 않게 하고, 스토어 심사(개발·출시 지침 "시리즈 출시 원칙")를 통과하기 위해서다.
  - 골격 규칙을 바꾸지 않고 **위에 얹는** 형태로 만든다(예: 특정 지형 효과, 필드의 고유 이동 방식, 특별한 장 형식). 골격 규칙을 바꿔야 하면 지침 예외로 적는다.
  - 최소 두 개를 **퍼즐·필드 사냥·1:1 대결의 메인 경로**에서 경험하게 한다. 턴제용 효과를 추가로 둘 수 있지만 턴제 참가가 고유 시스템 체험의 전제가 되어서는 안 된다. 첫 1~2장 안에 소개한다.
  - 과금과 연결하지 않는다(고유 시스템을 쓰려고 돈을 내야 하는 구조 금지).

### 저작권·상표 준수 (절대 규칙)

모든 게임이 반드시 지킨다. **지침 예외로 풀 수 없다.**

1. **원전만 쓴다.** 저작권이 끝난 원전(신화, 전설, 역사 기록, 고전 문학)의 인물 이름과 줄거리는 쓸 수 있다. 같은 원전을 다룬 **현대 작품**(소설, 영화, 드라마, 만화, 애니메이션, 게임)의 캐릭터 디자인, 각색 설정, 창작 인물, 고유 명칭, 대사, 줄거리는 쓰지 않는다.
2. **저작권이 살아 있는 작품은 통째로 피한다.** 현대 소설 등 보호 기간이 남은 작품의 인물, 세계관, 고유 기술·아이템 이름, 줄거리를 쓰지 않는다. 원전이 없는 테마(창작 세계관)는 모두 새로 만든다.
3. **고유 명칭과 상표를 쓰지 않는다.** 특정 작품이 만든 종족·괴물·아이템·조직 이름, 상표로 등록된 명칭은 쓰지 않는다. 장르에서 오래 함께 써 온 일반 명칭(엘프, 드래곤, 좀비, 소림 등)만 쓴다.
4. **닮게 만들지 않는다.** 색, 머리 모양, 의상, 무기, 상징의 조합으로 특정 작품의 캐릭터나 디자인을 떠올리게 하지 않는다. 하나하나는 흔한 요소라도 조합이 특정 캐릭터를 가리키면 쓰지 않는다.
5. **AI 생성에 작품명을 넣지 않는다.** 아트·문장 생성 지시(프롬프트)에 다른 작품, 작가, 캐릭터, 스튜디오 이름을 넣지 않는다.
6. **홍보에도 쓰지 않는다.** 스토어 설명, 광고, 공지에 다른 작품 이름이나 "~풍", "~ 같은 게임"을 쓰지 않는다. 오마주한 게임(위 필드 구성)도 마찬가지다.
7. **게임마다 목록을 둔다.** 게임 기획서에 "저작권 준수" 항목을 두고, 테마 원전의 상태와 닮게 하면 안 되는 작품·요소를 적는다. 아트와 문구는 만들 때와 출시 전(개발·출시 지침 체크리스트)에 이 목록과 대조한다. 의심되면 쓰지 않는다.

- **기본 범위 밖** (모든 게임 공통, 1차 출시 기준): 실시간 PvP, 길드 같은 온라인 경쟁 요소, 내정·외교 같은 대전략 요소. 넣으려면 게임 기획서에 "지침 예외"로 적는다.
- **도박 미니게임 금지** (예외 불가): 카드, 주사위, 슬롯처럼 도박을 흉내 내는 미니게임은 넣지 않는다. 도박사·살룬·주점은 이야기 소재로만 쓴다. 넣으면 연령 등급이 크게 오른다(예: 호주 R18+).

## 2. 진행 구조

- 스토리를 따라 장(章) 단위로 진행한다. 장 하나가 필드 하나다. 스테이지 번호는 `장-스테이지` 형식이다 (1-1, 1-2, …).
- **메인 진행**은 퍼즐 → 무리 사냥 → 도구·보조장비·캐릭터 획득 → 새 길·새 전술 → 1:1 액션 보스 대결의 순환이다. 순서는 장별로 조합한다.
- **턴제는 완전히 선택적**이다. 턴제 0회로도 모든 장, 결말, 어려움+ 해금과 필수 성장·능력 획득이 가능해야 한다. 메인 목표의 선행 조건에 턴제 클리어·턴제 보상·턴제 전용 캐릭터를 넣지 않는다.
- 필드에서 메인 목표를 찾아가며, 턴제 지점은 별도 선택 아이콘과 입장 확인으로 표시한다. 지나치거나 패배·포기해도 메인 진행을 막지 않는다. 발견한 전투는 나중에 방문할 수 있다.
- 스토리 사건의 설명과 결말은 메인 경로에서 전달한다. 선택 턴제는 그 사건의 전술적 재현·별동 전투이며, 생략했다고 필수 대사·장 보상·스토리 분기를 잃지 않는다.
- 메인 목표와 선택 스테이지 완료 기록을 분리한다. 도구·보조장비·캐릭터 보상은 고유 보상 ID로 중복 지급을 막는다. **범위 제안**: 도구·통행 해금은 진행 칸(기본/어려움+)별 ID, 캐릭터·보조장비는 계정별 ID를 쓴다. 어려움+에서는 도구와 통행을 다시 얻을 수 있지만 계정 공통 보유품을 반복 지급하지 않는다. 재입장·저장 복구·이미 완료한 목표 재실행은 같은 범위의 보상을 다시 주지 않는다.
- **장 구성 기본값** (게임별로 조정 가능):

| 항목 | 기본값 |
|---|---|
| 스테이지 | **8개**: 선택 턴제 전투 6개(전술 보스전 포함) + 메인 1:1 액션 보스 대결 2개 |
| 특수 스테이지 | 장마다 0~1개 (선택 콘텐츠) |
| 필드 크기 | 바깥 필드 화면 25~30장(약 6×5) + 작은 던전 화면 8~10장 = **화면 35~40장** |
| 웨이포인트 | 4~6개. 스테이지 한두 개마다 하나씩 |
| 필드 도구 | 최대 1개 (도구가 다 나올 때까지) |
| 처음 공략 시간 (기본 난이도) | 메인 경로와 선택 턴제를 분리해 측정. 종전 2.5~3시간은 턴제 6개 포함 추정이므로 메인 필수 시간으로 사용하지 않음. 새 목표 시간은 수직 슬라이스 플레이로 정함 |
| 한 구간 | 웨이포인트에서 다음 웨이포인트(또는 스테이지)까지 10~20분. 모바일에서 끊어서 할 수 있는 단위 |

- **메인 스토리는 12장, 스테이지 총 96개**(선택 턴제 72개 + 메인 1:1 대결 24개)다. 이는 제작 분량이며 메인 완료에 96개 전부를 요구하지 않는다. 모든 게임은 테마의 이야기 분량이 12장을 채울 수 있어야 한다(원전이 짧은 테마는 창작으로 채운다). 게임 기획서의 장 구성은 12장 전부를 적는다.
- **12장을 모두 완성한 뒤 출시한다.** 출시가 늦어지더라도 장을 나눠 내지 않는다. 출시 뒤 업데이트는 분기 스토리, 특수 스테이지, 이벤트로 한다.
- 메인 경로만의 플레이 시간, 턴제 72개를 포함한 시간, 어려움·특수 콘텐츠 시간을 따로 보고한다. 종전 30~36시간/50~60시간 추정은 새 골격의 확정 목표가 아니다. 어려움+는 별도 한 회차다.
- **난이도**는 **기본**과 **어려움** 두 가지다.
  - 어려움은 같은 스테이지의 기본 난이도를 클리어하면 열린다.
  - 어려움 첫 클리어 보상은 기본 난이도 첫 클리어와 별도로 지급한다(과금 지침의 무료 획득처).
- **어려움+ 모드** (전부 클리어한 플레이어를 위한 다음 회차):
  - **해금**: 메인 스토리 12장의 필수 목표와 1:1 보스 대결을 **기본 난이도로** 완료하면 열린다. 선택 턴제·어려움·특수 스테이지 클리어는 요구하지 않는다.
  - **별도 진행 칸**: 어려움+는 기존 진행을 지우지 않고 **모드를 켜는 방식**이다. 켜면 별도의 진행 칸에서 스토리가 1장 처음부터 시작하고, 필드 탐험 상태(가 본 화면, 퍼즐, 상자, NPC 선택), 웨이포인트, 필드 도구도 처음 상태다. 보조장비 보유는 유지하되 진행용 통행 권한은 새 회차 목표에 따라 다시 해금한다(보유만으로 퍼즐·길을 건너뛰지 않음). 기존 회차의 진행과 전투 기록(재클리어, 어려움 도전)은 그대로 남고, 지도 메뉴에서 두 진행 칸을 오갈 수 있다.
  - **유지되는 것**: 캐릭터, 장비, 레벨, 강화, 스킨, 재화, 계정 레벨과 성장 해금, 업적과 인연 기록. 구매한 상품과 뽑기로 얻은 것은 어떤 경우에도 사라지지 않는다(과금 지침).
  - **힌트·길잡이 끔**: 목표 화살표, 경로 힌트, 미니맵·월드맵의 다음 목표 표시, 퍼즐 힌트 대사가 나오지 않는다. 미니맵과 월드맵 자체(가 본 곳 표시)는 남는다.
  - **난이도**: 모든 스테이지가 어려움 이상이다. 적 능력치, 적 AI, 제한 턴, 재도전 횟수(1회)는 어려움과 같게 시작한다(제안, 더 높이는 계수는 플레이테스트로 정한다).
  - **보상 3배**: 어려움+의 스테이지 첫 클리어 보상은 3배다(과금 지침의 무료 획득처). 어려움+ 전용 도전과제(§10)를 따로 두고, 그 보상도 같은 종류 기본 업적의 3배로 정한다.
  - 어려움+는 한 번의 회차다. 끝까지 클리어한 뒤에는 전투 기록에서 어려움+ 스테이지를 다시 할 수 있다(재클리어 보상은 기본과 같음).
- **분기점**: 장 끝이나 NPC 대화의 선택에 따라 다음 장 경로가 달라진다. 다른 쪽 경로는 나중에 다시 플레이할 수 있다.
- **특수 스테이지** 유형: 1:1 대결 전용(1명), 방어전(정해진 턴 동안 버티기), 호위전(특정 캐릭터 생존), if 스토리.
- **전투 기록**: 이미 클리어한 스테이지는 지도 메뉴의 "전투 기록"에서 바로 다시 시작한다. 재클리어 보상과 어려움 난이도 도전도 여기서 한다.
- 모든 스테이지는 과금 없이, 플레이어의 숙련도와 전략만으로 클리어할 수 있게 만든다(과금 지침 "난이도 설계 규칙").
- **플레이 시간 목표**: 턴제 전투 하나는 5~15분 안에 끝난다. 필드 탐험은 언제 멈춰도 진행이 저장된다(§3 자동 저장).

## 3. 필드

- **크기 단위**: 필드는 **화면** 단위로 만든다. 화면 하나는 가로 16 × 세로 9 **타일**이고, 타일 하나는 16×16픽셀(캐릭터 한 명이 서는 크기, 한 걸음)이다. 화면 끝에 닿으면 옆 화면으로 넘어간다. 화면 하나를 가로질러 걷는 데 약 3초가 걸린다(초당 5타일 기준). 턴제 전투 맵의 크기(§6)는 타일 단위다.
- 넓이보다 **화면당 밀도**를 우선한다. 화면마다 퍼즐, 숨은 길, 적 배치, NPC, 상자 중 하나 이상을 둔다.
- 조작하는 캐릭터는 **출전 파티 3명 중 리더**다. 필드에서 언제든 파티 안에서 바꿔 조작할 수 있다.
- 필드에서 하는 일:
  - 간단한 퍼즐 (스위치, 열쇠, 블록 밀기·당기기 같은 트릭). 퍼즐이 풀 수 없는 상태로 꼬이지 않도록, 구역을 나갔다 들어오면 초기화한다.
  - NPC와 대화하고 선택하기. 선택은 스토리 분기에 영향을 줄 수 있다.
  - 상자, 숨은 길 찾기.
  - 일반 적(잡몹)과 액션 전투 (§4).
- **필드 도구**: 스토리 진행으로 **3~4개**를 얻고, 도구를 얻으면 이전에 갈 수 없던 길이 열린다. 이름과 디자인은 게임별로 독자적으로 만든다.

| 기본형 | 하는 일 |
|---|---|
| 밀기·당기기 | 무거운 블록과 바위를 밀고 당긴다 |
| 뛰어넘기 | 구멍이나 낮은 물을 건넌다 |
| 끌어당기기 | 멀리 있는 지점으로 몸을 끌어당겨 건넌다 |
| 부수기 | 금 간 벽이나 막힌 길을 부순다 |

- **웨이포인트**: 디아블로의 웨이포인트 방식을 차용한다. 웨이포인트를 밟으면 발견 처리되고, 발견한 웨이포인트 사이를 지도 메뉴에서 바로 워프한다. 밟으면 파티 전원의 체력이 최대로 회복된다. 이름과 디자인은 게임별로 정한다.
- **일반 적 보상**: 처치하면 확률적으로 재화 1을 준다(제안: 10%). 필드 사냥은 캐릭터 성장 경험치를 준다(§7). 체력 회복 아이템과 게임별 보조장비 보상을 둘 수 있다. 필수 보조장비는 확률 드롭만으로 지급하지 않고 메인 목표에서 확정 지급한다.
- **필드 사망**: 조작 캐릭터의 체력이 0이 되면 현재 필드 지역의 시작 지점에서 최대 체력으로 부활한다. 재화나 경험치를 잃는 등의 페널티는 없다. 파티의 다른 캐릭터로 바꾸지 않고 바로 부활한다.
- **길 안내**:
  - **미니맵**: 필드 화면 오른쪽 위에 작게 상시 표시한다. 지금 있는 화면 주변과, 가 본 화면만 보여 준다(안 가 본 곳은 가려짐). 웨이포인트, 스테이지 지점, 지역 출구를 아이콘으로 표시한다. 누르면 월드맵이 열린다.
  - **월드맵**: 지도 메뉴(§11)에서 연다. 장(필드)들의 위치와 연결, 발견한 웨이포인트(워프), 스테이지 지점, 다음 목표를 보여 준다.
  - **목표 화살표**: 조작 캐릭터 주위에, 스토리상 다음 목표 방향을 가리키는 화살표를 표시한다. 화살표는 캐릭터를 중심으로 360도 돌아가며 목표까지의 **직선 방향**을 가리킨다.
    - 목표: 다음 필수 메인 목표(퍼즐·사냥·대결·이야기) 지점. 선택 턴제를 다음 필수 목표로 안내하지 않는다. 다음 목표가 다른 필드에 있으면 그 필드로 가는 지금 필드의 출구를 가리킨다.
    - 목표가 가까워지면(같은 화면 안) 화살표가 흐려지고 목표 지점에 표시가 나타난다.
    - 직선 방향이라 벽이나 퍼즐 때문에 바로 갈 수 없을 수 있다. 길 찾기는 플레이어 몫으로 남겨 탐험의 재미를 지킨다.
    - 숨은 길, 상자, 선택 콘텐츠는 가리키지 않는다.
    - 설정에서 끌 수 있다(기본은 켜짐).
  - **경로 힌트**: 목표 화살표만으로 길을 찾기 어려울 때 쓰는 도움 기능이다.
    - 쓰면 **1분 동안** 조작 캐릭터 위치에서 목표 화살표의 목표까지 **최단 경로**를 바닥에 빛나는 선으로 보여 준다. 캐릭터가 움직이면 경로도 따라 갱신된다.
    - 퍼즐로 치워야 하는 장애물(밀어야 하는 블록, 잠긴 문, 부숴야 하는 벽, 필드 도구가 필요한 곳)이 길을 막고 있어도 **관통해서** 경로를 그린다. 그 장애물 위치는 경로 위에 따로 표시해, 어디서 무엇을 풀어야 하는지 알 수 있게 한다. 벽, 절벽, 물처럼 원래 지나갈 수 없는 지형은 관통하지 않는다.
    - 횟수: 최대 **3회**까지 쌓이고, **5분에 1회**씩 충전된다. 게임을 꺼 둔 동안에도 충전된다.
    - 재화나 광고로 충전하지 않는다.
    - 버튼 위치는 미니맵 바로 아래이고, 남은 횟수와 다음 충전까지 남은 시간을 표시한다.
- **자동 저장**: 필드 구역(화면)을 이동할 때마다 자동 저장한다. 퍼즐 진행, 상자, NPC 선택, 발견한 웨이포인트도 저장 대상이다.

## 4. 액션 전투 (필드, 1:1 대결 공통)

- 조작:

| 위치 | 구성 |
|---|---|
| 왼쪽 | 가상 조이스틱 (이동) |
| 오른쪽 | 공격 버튼, 회피 버튼, 일반스킬 버튼, 궁극기 버튼 |

- PC(스팀)는 키보드·마우스와 게임패드로 같은 명령을 낸다(§12).
- 캐릭터마다 **일반스킬 1개 + 궁극기 1개, 총 2개**를 가진다. 기본 공격·회피·필드 도구는 이 두 스킬에 포함하지 않는다. 세 번째 캐릭터 스킬 슬롯을 만들지 않는다.
- 일반스킬은 재사용 대기시간으로 운용한다. 궁극기는 전투로 충전해 밀집한 적을 쓸어버리거나 보스의 빈틈을 공략하는 큰 행동으로 만든다. **충전 방식은 제안**: 유효 피해·처치로 충전, 허공 공격·파괴물·이미 죽은 적으로 충전 불가, 궁극기 피해로 자기 충전 불가. 캐릭터별 게이지와 쿨다운은 교체·구역 이동·저장 복구로 초기화되지 않는다. 보스 진입 시 지급 게이지는 대결 데이터로 고정하며 재입장 반복으로 늘지 않는다.
- 두 스킬은 액션·턴제 효과를 별도로 데이터에 정의한다. 턴제 사용 제한은 §6을 따른다.

### 몰이사냥과 타격감

- 필드 사냥은 **여러 적을 유인해 모으고 범위 공격·일반스킬·궁극기로 처리하는 Hack & Slash** 구조다. 단일 적만 하나씩 배치한 전투로 대체하지 않는다.
- 기본 공격의 범위·관통·대상 수, 스킬의 밀치기·끌어모으기·경직과 적의 추격·공격 예고·회복 틈을 데이터로 정한다. 근접은 다수 처리와 공간 확보, 원거리는 거리·직선 사격이라는 장점과 빈틈을 모두 갖게 한다.
- 약한 일반 적, 접근을 압박하는 적, 원거리 견제 적, 경직 저항이 있는 정예를 조합한다. 모든 적이 한 점에 겹치거나 같은 프레임에 일제 공격하지 않게 하고, 화면 끝 탈출로 무상 처치·보상 복제를 반복할 수 없게 한다.
- 몰이 규모는 화면 크기·충돌·가독성·실기기 성능을 보고 정하는 **제안값**이다. 기존 16×9타일 화면과 16픽셀 타일을 유지한 첫 시험에서 동시 적 8~12마리를 검증하되, 측정 없이 출시 성능 목표로 확정하지 않는다.
- 보스는 잡몹 없는 1:1을 유지한다. 공격 예고 → 회피·위치 선정 → 빈틈 공략의 반복으로 만들며, 일반 적처럼 무한 경직으로 봉쇄되지 않게 한다.
- 공격 판정·다중 피격·경직·넉백·처치 이벤트를 렌더링과 분리한다. 방향별 도트 동작, 준비·타격·후딜, 피격 섬광·효과음·짧은 타격 정지의 표현을 이후 에셋으로 교체할 수 있어야 한다. 최종 화풍·버튼 배치·타격감은 플레이 가능한 미리보기로 사람이 검수한다.
- 기본 공격은 캐릭터마다 세 유형 중 하나다.

| 공격 유형 | 방식 | 예 |
|---|---|---|
| 휘두르기 | 근접. 앞쪽 부채꼴 범위를 벤다 | 칼, 창, 도끼 |
| 화살 | 원거리. 직선으로 날아가는 투사체 | 활, 쇠뇌 |
| 에너지볼 | 원거리. 느리지만 강하거나 범위 효과가 있는 투사체 | 술법, 기공, 부채 |

- 능력치 반영 (능력치는 §7):

| 능력치 | 액션 전투에서의 효과 |
|---|---|
| 공격력 | 기본 공격과 스킬의 피해 |
| 방어력 | 받는 피해 감소, 회피 |
| 통솔력 | 캐릭터별 최대 체력. `최대 체력 = 50 + 통솔력 × 5` (제안, 턴제 병력의 1/10) |
| 기동력 | 이동 속도 |

- 체력은 캐릭터마다 따로 관리한다. 조작 캐릭터를 바꾸면 그 캐릭터의 남은 체력으로 싸운다.
- 체력 회복: 웨이포인트(파티 전원 최대), 1:1 대결 진입(대결 캐릭터 최대), 회복 아이템(일부), 필드 사망 후 부활(최대).
- **액션 보조 모드**: 설정에서 켜면 공격 범위 안의 적을 자동으로 공격한다. 자동 조준과 받는 피해 감소도 함께 쓸 수 있다. 보상에는 영향을 주지 않는다.

## 5. 1:1 대결

- 메인 콘텐츠인 **1:1 액션 보스전**이며, 턴제 전투와 **따로** 진행하는 독립 스테이지다. 스토리의 정해진 대결 지점과 1:1 대결 전용 특수 스테이지에서 일어난다.
- 일반 적이 없는 1:1 전장에서 §4 액션 전투로 싸운다. 들어갈 때 대결 캐릭터의 체력이 최대로 회복된다.
- 승리 조건: 제한 시간 안에 상대 체력을 0으로 만들거나, 시간이 끝났을 때 남은 체력 비율이 더 높으면 이긴다(제안).
- 결과: 이기면 스토리가 진행된다. 지면 페널티 없이 다시 도전한다. 끝나면 스테이지 종료 광고가 나온다.
- 연출: 진입할 때 두 캐릭터의 일러스트 컷인과 대사. 게임에서 가장 공들일 연출 포인트다.
- 1:1 대결의 게임 내 이름은 게임별로 정한다.

## 6. 턴제 전투

### 기본 규칙

- 격자(사각형 칸) 맵에서 진행한다. 맵 크기는 출전 인원에 맞춰 작게 잡는다(제안: 작은 맵 8×10, 큰 맵 10×14). 큰 맵은 스크롤과 확대·축소를 지원한다.
- 출전 인원은 **최대 3명**이다. 특수 스테이지는 1~2명으로 제한할 수 있다.
- 승리 조건 기본형: 캐릭터들을 전진시켜 **적 요새를 함락**한다(요새는 별도 수비 병력을 가진다). 게임별로 다른 승리 조건(적 전멸, 특정 적 격파, 버티기)을 스테이지마다 지정할 수 있다.
- 턴 제한이 있다. 화면 상단에 `N턴째 / 제한 M턴`을 항상 표시하고, 남은 턴이 3 이하가 되면 강조한다. 턴 단위의 게임 내 이름(예: "일")은 게임별로 정한다.
- 제한 턴 산정: `제한 턴 = 기준 클리어 턴 × 난이도 계수`(제안: 기본 1.4, 어려움 1.1)를 맵 규모로 보정하고, **15~50턴 범위**로 자른다. 기준 클리어 턴은 뽑기 강화와 계정 성장 해금이 전혀 없는 편성으로 측정한 평균값이다.

| 스테이지 규모 | 제한 턴 기준 범위 |
|---|---|
| 작은 맵 (8×10 안팎), 장 초반 | 15~25 |
| 큰 맵 (10×14 안팎), 보스전 | 25~40 |
| 대규모 전투, 방어전 같은 특수 스테이지 | 40~50 |

  - 같은 스테이지는 어려움 난이도의 제한 턴이 기본보다 적다. 어떤 경우에도 15턴 미만이나 50턴 초과는 두지 않는다.

### 턴 진행

- **페이즈제**다. 한 턴은 한쪽 진영 전원이 한 번씩 행동하는 페이즈와, 다른 쪽 진영의 페이즈로 이뤄진다.
- **선공 결정**: 1턴째를 시작할 때 플레이어와 적이 **가위바위보**를 해서 이긴 쪽이 먼저 페이즈를 가진다. 비기면 다시 한다. 적의 선택은 무작위다.
- **출전 배치**: 스테이지마다 아군 출발지 **캠프**가 있고, 출전 캐릭터는 캠프 주변 8타일 중 **무작위** 위치에서 시작한다.
- **캐릭터 행동**: 자기 페이즈에 캐릭터를 하나씩 골라 이동하고, 아래 중 하나를 한다. 행동을 확정하기 전에는 이동을 취소할 수 있다.
  - **적이 있는 칸으로 이동**: 그 적과 **교전**이 시작된다(아래 "교전").
  - **대기**: 아무것도 하지 않고 행동을 끝낸다.
  - **구출**: 맞닿은 포로 아군을 구출한다(아래 "포로와 구출").
- **스킬**: 일반스킬과 궁극기의 턴제 효과를 각각 정의한다. **사용 제한 제안**: 각각 전투당 1회, 한 행동에는 둘 중 하나만 사용. 액션 궁극기 게이지는 턴제로 가져오거나 턴제에서 충전하지 않는다. 소비 상태는 되감기 스냅샷에 포함한다.

### 교전

- 캐릭터가 적이 있는 칸으로 이동하면 교전이 시작된다. 적 페이즈에 적이 아군 칸으로 이동해도 같다.
- 교전이 시작되면 양쪽이 **공격 / 스킬 / 방어 / 퇴각** 중 하나를 동시에 고른다. 적의 선택은 AI가 정한다.
  - 스킬을 고르면 남아 있는 일반스킬·궁극기 중 하나를 선택한다. 사용 제한은 위 제안을 따른다.
- **퇴각**을 고른 경우:
  - 상대가 **방어**를 골랐으면: 병력 손실 없이(100% 보존) 퇴각한다.
  - 상대가 **공격이나 스킬**을 골랐으면: 맞붙었을 때 입었을 피해의 **절반**을 입고 퇴각한다.
  - 교전을 건 공격자는 적에게 도달한 이동 경로에서 **적 칸 바로 앞 타일**로 복귀한다.
  - 교전을 받은 방어자가 퇴각하면, 공격자를 먼저 직전 타일로 복귀시킨 뒤 방어자에 인접한 빈 통행 가능 칸 중 공격자와 가장 멀어지는 칸으로 옮긴다. 거리가 같으면 좌표순으로 정한다. 가능한 칸이 없으면 제자리에 남되 위 피해 경감은 적용한다.
  - 양쪽이 모두 퇴각해도 공격자 복귀 → 방어자 퇴각 순서로 처리한다.
- 교전 결과표 (행: 내 선택, 열: 상대 선택. 피해는 아래 "전투 계산"의 공식 기준 1배):

| 내 선택 \ 상대 | 공격 | 스킬 | 방어 | 퇴각 |
|---|---|---|---|---|
| 공격 | 서로 1배 피해 | 내가 1배, 상대 스킬 효과 | 내가 상대에게 0.5배, 나는 피해 없음 | 상대는 0.5배 입고 퇴각 |
| 스킬 | 상대 1배, 내 스킬 효과 | 서로 스킬 효과 | 방어 무시, 내 스킬 효과 | 상대는 내 스킬 피해의 0.5배 입고 퇴각 |
| 방어 | 나는 0.5배만 입음, 상대 피해 없음 | 방어 무시, 상대 스킬 효과 | 아무 일 없음 | 상대는 손실 없이 퇴각 |
| 퇴각 | 0.5배 입고 퇴각 | 상대 스킬 피해의 0.5배 입고 퇴각 | 손실 없이 퇴각 | 둘 다 손실 없음 |

  - 공격은 방어에 약하고, 방어는 스킬에 뚫리고, 각 스킬의 사용 횟수는 제한된다. 퇴각은 손실을 줄이는 선택이다.
  - 교전 후 양쪽이 모두 남아 있으면, 교전을 건 쪽은 적 칸 직전 타일에 멈춘다(같은 칸에 두 유닛이 있지 않게).
- **아군이 교전을 받을 때**(적 페이즈): 매번 플레이어가 고른다. 설정에서 **자동 선택**을 켜면 AI가 추천하는 선택을 바로 쓴다.
- **궁병의 원거리 교전**: 궁병은 2타일 떨어진 적을 지정해 이동 없이 교전을 걸 수 있다. 이때 근접 병종은 공격을 골라도 피해를 주지 못한다. 상대도 궁병이면 원거리 반격할 수 있다. 궁병이 적 칸으로 들어가는 근접 교전도 할 수 있다.

### 궁병 균형 검수 (제안)

- 사거리 2와 근접 반격 불가라는 역할은 유지한다. **인접한 살아 있는 적이 있으면 원거리 사격 불가**, **원거리 일반 공격 피해 계수 0.75**를 첫 비교안으로 둔다. 이는 확정 하향 수치가 아니다. 일반스킬·궁극기는 각 데이터의 사거리·위력·사용 조건을 따르고 우회로가 되는지 함께 검사한다.
- 평지에서는 접근·근접 압박이 실제로 작동해야 한다. 강·다리·수비 범위 때문에 반격할 수 없는 적은 엄폐·사거리 이탈·동료 지원을 고려한다. 명중 불가 선택이나 끝없는 대기/왕복을 최선 행동으로 고르지 않게 한다.
- 동일 능력치·병력으로 병종만 바꾼 대조 실험과 실제 기본 편성 실험을 구분한다. 궁병 단독 대 혼합 편성의 승률·턴 수·병력 손실, 좋은 위치에서의 이득과 접근당했을 때의 손해를 함께 비교한다. 약한 병졸 1~2턴 처치와 좋은 선택의 쾌감은 유지한다.
- 시야 차단·탄약·사격 후 재장전 같은 추가 규칙은 이번 기본안에 넣지 않는다. 위 비교 결과로도 문제가 남을 때 별도로 검토한다.

### 지형 (기본형, 제안)

| 지형 | 이동 비용 | 방어 보정 |
|---|---|---|
| 평지 | 1 | 0% |
| 숲 | 2 | +20% |
| 산 | 3 | +40% |
| 강 | 통과 불가 (다리는 1) | -10% |
| 성채·관문 | 1 | +30% |
| 적 요새 | 1 | +50%, 별도 수비 병력 |
| 보급기지 | 1 | +10%. 병력 회복 (아래) |

- 지형 이름과 그림은 테마에 맞게 바꿀 수 있다. 수치 구조는 유지한다.
- **보급기지**: 맵 중간중간에 보급기지를 둔다. 아군이 보급기지 칸에 도달하면(그 칸에서 이동을 마치면) **병력이 회복**된다.
  - 회복량은 최대 병력의 50%(제안), 보급기지마다 전투당 1회 사용(제안).
  - 아군 전용이다. 적은 쓰지 않는다(제안).
  - 맵마다 1~2개를 두고, 위치는 스테이지 데이터로 정한다. 턴제 전투에서 병력을 회복하는 수단은 보급기지, 구출, 회복 스킬뿐이다.

### 병력과 이동

- 병력(턴제 전투의 체력): `최대 병력 = 500 + 통솔력 × 50`. 매 전투 시작 시 가득 찬다.
- 이동 칸 수: `기본 3칸 + 기동력 5포인트당 1칸`, 최대 8칸.
- 적의 인접 칸(ZOC, 지배 영역)에 들어가면, 그 적의 칸으로 들어가 교전하는 것 말고는 그 턴의 남은 이동이 끝난다. 그래서 적을 그냥 지나칠 수 없다.

### 병종

- 병종은 캐릭터가 **인솔하는 병력의 종류**(보병, 기병, 궁병)이고 **캐릭터마다 고정**이다. 캐릭터 자신의 무기나 액션 전투의 기본 공격 유형(§4)과는 별개다. 예: 칼을 쓰는 캐릭터도 궁병을 인솔할 수 있다.
- 병종은 병력끼리 싸울 때의 상성을 정한다.
- 기본형: **기병 > 보병 > 궁병 > 기병**. 유리하면 피해 1.2배, 불리하면 0.8배.
- 궁병은 2타일 거리에서 교전을 걸 수 있고, 근접 교전에서 반격 피해를 주지 못한다(위 "교전").
- 병종 이름과 종류는 테마에 맞게 바꿀 수 있다. 바꿀 때도 세 병종 순환 상성 구조는 유지한다.

### 전투 계산

- 교전에서 피해가 오가는 경우의 피해량은 아래 공식을 쓴다. 어떤 조합에서 누가 피해를 주는지는 교전 결과표를 따른다.
- 피해량(제안): `피해 = 공격자 병력 × 0.1 × (공격력 + 20) / (대상 방어력 + 20) × 병종 상성 × (1 − 지형 방어 보정)`
  - 상수 20은 능력치가 작을 때 수치 차이가 과도하게 커지지 않게 하는 완충값이다.
- 회피: 대상의 방어력에 비례해 피해를 완전히 피할 확률이 있다(제안: 최대 20%).
- 양쪽이 서로 병력을 잃으므로, 강한 캐릭터도 연전하면 약해진다.

### 적 AI

적의 행동은 아래 순서로 정한다. 수치는 플레이테스트로 조정할 수 있다.

1. **행동 순서**: 적 페이즈가 오면, 아군과 가까운 적부터 한 명씩 행동한다.
2. **활성화**: 적은 처음에 대기 상태다. 아군이 **감지 범위**(이동 칸 수 + 2타일) 안에 들어오거나, 같은 무리의 적이 교전하거나, 스테이지 이벤트가 일어나면 활성화된다. 대기 상태의 적은 움직이지 않는다. (맵 전체의 적이 한꺼번에 몰려오지 않게 하기 위함)
3. **이동 가능 타일 계산**: 지형 이동 비용과 아군의 지배 영역(ZOC)을 반영한 최단거리 탐색(다익스트라)으로, 이번 턴에 갈 수 있는 타일을 모두 구한다.
4. **행동 후보 만들기**: 갈 수 있는 타일마다 "그 타일에서 대기" 또는 "그 타일을 거쳐 맞닿은 아군 칸으로 교전 진입"(궁병은 2타일 원거리 교전 포함)을 후보로 만든다.
5. **점수 매기기**: 후보마다 아래 점수를 더한다. 역할마다 가중치가 다르다.

| 점수 요소 | 내용 |
|---|---|
| 예상 교전 이득 | (내가 줄 예상 피해 − 받을 예상 피해). 병종 상성과 지형 보정 반영 |
| 마무리 | 이 교전으로 아군을 포로로 만들 수 있으면 큰 가산점 |
| 위험 | 다음 아군 페이즈에 이 타일로 교전을 걸 수 있는 아군 수만큼 감점 |
| 지형 | 이 타일의 방어 보정만큼 가산 |
| 목표 거리 | 역할의 목표(아래)까지 가까워질수록 가산 |
| 겹침 방지 | 이미 다른 적이 노린 아군을 또 노리면 감점 (한 명에게 몰리는 것을 줄임) |

6. **가장 점수가 높은 후보**를 실행한다.

| 역할 | 목표 | 성향 |
|---|---|---|
| 수비 | 요새 또는 지정 지점 | 지정 지점에서 일정 거리(3타일) 밖으로 나가지 않는다. 그 안에 들어온 아군만 노린다 |
| 요격 | 병력이 가장 적은 아군, 또는 병종 상성이 유리한 아군 | 마무리와 상성 점수를 크게 본다 |
| 진격 | 아군 캠프 또는 가장 가까운 아군 | 목표 거리 점수를 크게 보고, 위험 점수는 작게 본다 |

- **교전 선택**(공격·스킬·방어·퇴각): 적은 매번 같은 선택을 하지 않는다. 각 선택의 예상 결과로 확률을 정해 무작위로 고른다(예: 병력이 많이 남았으면 공격 쪽 확률이 높고, 적으면 방어·퇴각 확률이 높다). 플레이어가 적의 선택을 완전히 읽을 수 없게 하면서도 상황에 맞는 경향을 보인다. 스킬은 효과가 큰 순간(예상 피해가 크거나 마무리할 수 있을 때)에 쓴다.
- **난이도별 차이**:

| 난이도 | 차이 |
|---|---|
| 기본 | 위 점수로 한 수만 본다. 교전 선택의 무작위 폭이 크다 |
| 어려움 | 위험 점수를 크게 보고(다음 아군 페이즈의 반격까지 고려), 교전 선택이 상황에 더 정확하다. 적 병력 배율이 높다 |

- 적은 보급기지를 쓰지 않고, 포로를 공격하지 않는다.

### 적 장수

- 턴제 전투의 적 중 일부는 **적 장수**다. 일반 적과 달리 이름과 일러스트가 있다.
- 적 장수의 특징:
  - **교전에 들어갈 때 짧은 대화**(1~2줄)를 대화 화면 형식(§11)으로 보여 준다. 처음 교전할 때만 보여 주고, 같은 전투에서 다시 교전하면 생략한다.
  - **일반스킬·궁극기를 쓸 수 있다**. 아군과 같이 §6 턴 진행의 사용 제한을 따른다. 일반 적은 스킬이 없다.
- 일러스트: 적 장수마다 따로 그리지 않고, **공용 적장 일러스트 몇 종을 돌려가며** 쓴다(이름과 대사만 다르게). 표현 모드(§7)에 맞춰 오리지널·재해석 두 벌을 둔다. 몇 종을 둘지는 게임별로 정한다(기본 8종).
- 스토리 보스(§7 획득)는 적 장수와 별개로, 자기 전용 일러스트를 쓴다.
- 적 장수도 병력이 0이 되면 전장에서 사라진다. 적 장수를 쓰러뜨려도 별도 보상은 없다.

### 포로와 구출

- 병력이 0이 된 아군은 **그 자리에서 포로 상태**가 된다. 포로는 행동할 수 없다.
- 다른 아군이 포로와 **맞닿은 칸**에서 **구출** 행동을 하면 포로가 부활한다.
  - 구출하는 캐릭터는 그 턴의 행동을 쓰고, **자기 현재 병력의 절반**을 포로에게 넘겨준다.
  - 부활한 캐릭터는 다음 아군 페이즈부터 행동한다.
- 포로가 있는 칸은 아무도 지나가거나 멈출 수 없고, 적은 포로를 공격하지 않는다.
- 적군은 병력이 0이 되면 포로가 되지 않고 전장에서 사라진다.
- 아군 전원이 포로가 되면 **전멸**이다.
- 포로가 된 캐릭터도 전투가 끝나면 페널티 없이 돌아온다.

### 승패와 보상

- **요새 함락**: 요새 칸에 맞닿아 교전(요새는 공격만 받고 반격하지 않음)해 요새의 수비 병력을 0으로 만들면 즉시 함락, 승리한다.
- **보상**: 선택 턴제는 재화·경험치·전투 기록 보상을 준다. 장 보상 캐릭터는 메인 장 완료에서 지급한다(§7). 턴제 독점 필수 도구·보조장비·캐릭터는 두지 않는다.
- **경험치**: 출전한 캐릭터 전원(포로가 됐던 캐릭터 포함)이 받는다.
- **전투 중 이벤트**: 특정 턴 도달, 특정 지역 진입, 특정 캐릭터 포로·퇴각 시 대사, 적 증원, 승리 조건 변경을 스테이지 데이터로 지정할 수 있다. 대사는 대화 화면(§11) 형식을 쓴다.

### 조작 편의

- 행동 확정 전 이동 취소.
- 교전 전 예상 결과 표시: 각 선택 조합에서 내가 주고받을 피해, 회피율.
- 적 이동 범위 보기.
- 적 페이즈 2배속과 건너뛰기.
- 자동 전투는 두지 않는다.

### 재도전(되감기)과 실패

- 실패 조건과 재도전 혜택 기본형:

| 실패 조건 | 재도전 혜택 |
|---|---|
| 아군 전멸 | 5턴 전으로 되감기 |
| 제한 턴 소진 | 10턴 전으로 되감기 |

  - 전투가 시작된 지 5턴(또는 10턴)이 지나지 않았으면 1턴째로 되돌아간다.
- 횟수: 스테이지 1회 도전당 **기본 최대 3회, 어려움 최대 1회**. 전멸과 소진을 합산한다. 광고 제거 여부와 관계없이 모든 플레이어가 같다.
- 광고 제거가 적용되지 않았으면 재도전할 때마다 보상형 광고를 1회 보고, 적용 중이면 광고 없이 쓴다.
- 재도전을 다 썼거나 포기하면 스테이지가 실패로 끝나고 짧은 광고가 나온다(광고 제거 적용 중이면 없음).
- 재도전 혜택의 게임 내 이름은 게임별로 정한다.

## 7. 캐릭터

### 획득

- 기본 획득 경로:
  - **기본 제공**: 처음에 3명. 세 명이 **병종 셋(기병·보병·궁병)을 하나씩** 맡고, 기본 공격은 **근접과 원거리를 섞어**, 초반부터 병종 상성과 캐릭터 교체 조작을 익히게 한다.
  - **장 보상**: **장마다 1명**. 그 장의 스토리에서 가장 중요한 캐릭터(장의 보스, 또는 그 장에서 합류하는 인물) 한 명을 그 장의 필수 퍼즐·사냥·1:1 보스 대결과 마지막 이야기 목표를 처음 완료할 때 준다. 선택 턴제 클리어 여부와 무관하다. 이미 가지고 있으면 강화 단계가 1 오르고, 최대 단계면 대신 재화 30을 준다. 12장이면 장 보상은 12명이다. **지급 범위 제안**: 계정·장별 최초 1회이며 어려움+에서는 캐릭터를 재지급하지 않는다. 난이도별 스테이지 재화 보상은 과금 지침대로 별도다.
  - **뽑기**: 모바일판에서 기본 제공과 장 보상 외의 캐릭터는 **뽑기로만** 얻는다. 모든 캐릭터가 처음부터 뽑기 풀에 있다(과금 지침). 개별 1:1 대결 상대나 선택 턴제 보스 자체가 추가 캐릭터 보상을 주지는 않는다. 장의 메인 완료 보상은 별도로 지급한다.
- **인기 캐릭터**: 게임마다 테마에서 인기가 높을 캐릭터를 **4~6명** 지정한다(그중 최상위 2명 포함). 인기 캐릭터는 **장 보상으로 주지 않고 뽑기 전용**이다. 스토리의 핵심 인물이어도 장 보상은 그 장의 다른 관련 인물로 정하고, 인기 캐릭터는 게스트로 출전한다.
  - **최상위 인기 2명**은 계정당 **한 번씩** 상점에서 직접 살 수 있다(과금 지침 "최상위 인기 캐릭터 1회 구매").
- **게스트 출전**: 스토리에 동료로 나오지만 아직 보유하지 않은 캐릭터는, 스토리상 필요한 스테이지에서만 **게스트**로 출전한다(정해진 1:1 대결, 스토리상 함께 싸우는 턴제 전투). 게스트는 그 스테이지 전용의 고정 능력치로 나오고, 스테이지가 끝나면 빠진다. 보유한 캐릭터라면 게스트 대신 플레이어의 캐릭터가 나온다. 써 보고 마음에 들면 뽑기로 얻게 하는 판매 동선이기도 하다.
- 모든 캐릭터에 **스토리 획득 목표**를 데이터로 지정한다. 목표에는 메인 경로의 장·퍼즐·사냥·대결 완료 ID를 쓴다. 모바일판에서는 장 보상 12명만 이 데이터로 지급하고, 뽑기가 없는 스팀판은 이 데이터로 모든 캐릭터를 무상 지급한다(과금 지침 "스팀(PC)판").
- 캐릭터에는 등급이 없다.
- **성인 설정** (예외 불가): 모든 플레이 캐릭터는 **성인(18세 이상)**으로 설정하고 성인으로 디자인한다. 원전에서 어린 나이인 인물(소년 왕, 소년 영웅 등)도 성인 시점으로 그린다. 소개 문구에 "소년", "소녀" 같은 미성년 표현을 쓰지 않는다. 재해석 모드와 스킨이 미성년자를 성적으로 그린다는 비판과 스토어 정책 위반을 막기 위해서다.
- **캐릭터 명단**: 게임마다 **30명 이상**. 병종은 **보병과 기병이 궁병보다 많게** 짠다(책사·군주처럼 원거리 이미지인 인물도 보병·기병에 배치할 수 있다. 병종과 기본 공격 유형은 따로 정한다).

### 스토리 속 퇴장과 보스 획득

- **스토리에서 죽거나 퇴장한 캐릭터도 편성에서는 계속 쓴다.** 원전대로 스토리에서 퇴장하더라도(예: 삼국지의 관우), 그 캐릭터는 보유 목록에 남고 이후 스테이지에 출전할 수 있다. 키우고 과금으로 강화한 캐릭터를 잃지 않게 하기 위해서다.
  - 퇴장 이후의 스토리 대화에는 나오지 않는다. 출전 중인 전투에서는 전투 대사만 한다.
  - 원하는 게임은 퇴장을 피하는 if 결말을 분기나 특수 스테이지로 둘 수 있다.
- **획득은 스토리와 별개다.** 원전에서 죽거나 끝까지 적으로 남는 인물도 장 보상이나 뽑기로 얻으면 캐릭터 명단에 오른다. 스토리에서 그 인물이 아군이 되었다고 바꾸지 않는다.
- 장의 보스가 사람이 아니면(괴물 등) 그 장에서 구하거나 되돌린 인물을 장 보상으로 정한다.

### 능력치

| 능력치 | 턴제 전투 | 액션 전투 (필드, 1:1 대결) |
|---|---|---|
| 공격력 | 피해량 | 기본 공격과 스킬 피해 |
| 방어력 | 받는 피해 감소, 회피 | 받는 피해 감소, 회피 |
| 통솔력 | 최대 병력 | 최대 체력 |
| 기동력 | 이동 칸 수 | 이동 속도 |

### 성향

- 캐릭터와 장비에는 성향이 있다: **지휘관형, 암습형, 돌격형, 방어형**.
- 성향은 상성에 쓰지 않는다. **장비를 통해 능력치에 가점을 주는 역할**만 한다(§8).

### 성장

- 처음 얻은 캐릭터는 1레벨이며, 능력치 포인트 **20**이 그 캐릭터의 특성에 맞게 네 능력치에 나눠져 있다.
- 레벨은 **메인 목표·필드 사냥·1:1 대결**에서 얻는 경험치로 오르며, 선택 턴제 경험치는 추가 획득처다. 턴제 0회·무강화 기본 및 장 보상 편성으로 메인 경로를 검증한다.
  - 경험치량·필요량은 장/적/목표별 데이터로 조절하는 제안값이다. 종전 스테이지 승리마다 무조건 +1레벨, 패배 1/10 규칙을 대체한다. 메인 목표는 첫 완료 보상, 반복 사냥·대결·턴제는 반복 보상을 구분한다.
  - 필드 사냥 경험치는 출전 파티 3명에게 지급해 리더 교체가 성장을 손해 보게 하지 않는다. 실패·구역 이동·저장 복구에서 동일 처치나 목표 경험치를 중복 지급하지 않는다.
  - 최대 레벨은 **50**이다. 50레벨의 능력치 총합은 20 + 49×3 = 167이다.
- 레벨이 오를 때마다 능력치 포인트 **3**을 얻고, 플레이어가 네 능력치 중 원하는 곳에 하나씩 투자한다.
- 능력치 초기화: 캐릭터별 **첫 1회 무료**, 이후 **재화 100**.
- 중복 강화: 같은 캐릭터를 다시 얻으면(뽑기, 장 보상) 강화 단계가 1 오르고 **보너스 능력치 포인트 +5**를 얻는다. 최대 **+5단계(보너스 +25)**다. 최대 단계면 뽑기 풀에서 빠진다.
  - +25는 50레벨 총 포인트(167)의 약 15%로, 체감은 되지만 전략을 대신하지 않는 수준이다.
  - 스팀판은 뽑기가 없으므로 재화 300으로 1단계씩 강화한다(과금 지침 "스팀(PC)판").
  - 강화 단계는 초상화 테두리와 발밑 오라로 눈에 보이게 표시한다(아래 "강화 단계 표시").

### 강화 단계 표시

- **강화 단계마다** 눈에 보이는 표시가 붙는다. 두 표현 모드 모두에서 보인다.
  - **초상화 효과**: 필드 왼쪽 위 캐릭터 상태, 대화 화면, 캐릭터 상세의 초상화 테두리가 단계마다 바뀐다.
  - **발밑 오라**: 필드에서 조작하는 캐릭터의 발밑에 단계별 오라가 생긴다. 1:1 대결과 턴제 전투의 유닛에도 같은 오라를 보여 준다.

| 강화 단계 | 초상화 효과 | 발밑 오라 |
|---|---|---|
| +0 | 기본 테두리 | 없음 |
| +1 | 동색 테두리 | 옅은 동색 원 |
| +2 | 은색 테두리 | 은색 원 |
| +3 | 금색 테두리 | 금색 원, 은은한 반짝임 |
| +4 | 금색 테두리 + 빛나는 모서리 | 금색 원 + 위로 오르는 빛 입자 |
| +5 (각성) | 각성 전용 테두리(움직이는 빛) | 각성 오라(캐릭터 성향 색, 바닥 문양과 빛 기둥) |

- 오라는 도트 그래픽에 맞는 단순한 효과로 만들고, 저사양 기기에서는 입자 수를 줄인다.
- 최대 강화 때는 비매품 각성 스킨도 준다(과금 지침 "각성 스킨").

### 표현 모드

- 캐릭터 디자인을 **오리지널**과 **재해석**(게임별 컨셉) 중에서 고를 수 있다. 처음 실행할 때 고르고, 설정에서 언제든 바꾼다.
- 바꾸면 일러스트(초상화, 스탠딩, 컷인)와 도트 스프라이트가 모두 바뀐다. 두 모드 모두 일러스트와 도트를 한 벌씩 만든다. 게임 규칙과 능력치는 같다.
- 출시 후 스킨은 재해석 모드 전용으로만 만든다(과금 지침).
- **대사 두 벌**: 스토리 대사, 캐릭터 대사, 전투 대사는 모드별로 **따로** 쓴다. 재해석 모드는 여성 캐릭터끼리의 대화이므로 말투와 분위기를 바꾼다.
  - **성격과 사건은 오리지널을 따른다.** 같은 장면, 같은 선택지, 같은 결과다. 바뀌는 것은 말투, 호칭(예: 의형제 → 의자매, 형님 → 언니), 리액션이다.
  - 재해석 대사는 **외모에 어울리는 말투**로 쓰고, **가벼운 개그**를 넣는다(티격태격, 허당 리액션, 캐릭터 버릇을 살린 농담 등). 개그는 장면당 한두 마디로, 이야기 흐름을 끊지 않게 한다.
  - 개그를 넣지 않는 장면: 죽음·퇴장·비극 장면, 마지막 결전 직전, 공포 연출 중.
  - 개그 금지: 성적인 농담, 외모·몸매 평가, 특정 집단 비하, 실존 인물·신앙 대상을 우스개로 만드는 것. 게임별로 **개그 제외 인물**(국가적으로 존경받는 인물, 신앙 대상, 성직자)을 정해 그 인물은 재해석에서도 품위 있는 말투만 쓴다(본인이 개그를 하지 않을 뿐, 다른 인물의 개그에 반응할 수는 있다).
  - **연애·혼인 관계**: 재해석 모드는 모든 캐릭터가 여성이므로, 원작의 연애·혼인 관계(부부, 연인, 짝사랑)는 재해석에서 **"평생의 맹세", "충성 서약" 같은 깊은 신뢰 관계**로 바꾼다. 배신, 갈등, 이별, 비극 같은 **사건은 그대로** 둔다. 캐릭터 설명의 관계 표기(아내, 연인)도 재해석 화면에서는 맹세 관계로 표시한다(예: "토르의 아내" → "토르와 평생을 맹세한 전우"). 시장마다 다른 동성 관계 표현 규제와 반발을 피하고, 이야기 구조는 원작대로 지키기 위해서다.
  - 대사가 없는 쪽 모드로 빠지지 않게, 스토리 대사는 모든 줄을 두 벌 다 만든다. 시스템 문구(메뉴, 튜토리얼 안내)는 한 벌을 같이 쓴다.
- **성직자 캐릭터** (승려, 비구니, 사제, 성녀, 무녀, 수녀 등 종교인): 두 모드 모두 **노출 없는 디자인**으로만 만들고, 노출이 있는 스킨을 만들지 않는다.

## 8. 장비

### 기능성 보조장비

- **필드 도구**, **보조장비**, **페어 장비**를 구분한다. 도구는 새 길과 퍼즐 조작을 열고, 보조장비는 사냥·회피·지형 대응 등 플레이 방식을 보완하며, 페어 장비는 기존 능력치 가점·강화를 담당한다.
- 보조장비는 퍼즐·사냥 목표·보스 보상으로 얻는다. **필수 기능은 메인 경로에서 확정 획득**하며, 유료 구매·뽑기·선택 턴제·희귀 확률 드롭이 진행 조건이 되지 않는다. 필요한 캐릭터 기능도 기본·장 보상·해당 구간 게스트 또는 도구로 해결할 수 있게 한다.
- **슬롯 제안**: 캐릭터당 보조장비 1칸을 페어 장비 1칸과 별도로 둔다. 필수 통행 능력은 획득 후 해금 기록으로 남겨 장비 교체로 길에 갇히지 않게 한다. 효과·중첩·교체 허용 시점은 데이터와 테스트로 정한다.
- 보조장비는 기존 페어 장비 뽑기 풀·중복 강화 상품에 넣지 않는다. 보조장비 획득·장착·기능 해금 기록은 저장 대상이다.

### 페어 장비

- 장비에는 등급이 없다.
- **캐릭터 하나에 상징 장비 하나를 페어로 함께 출시한다.** 새 캐릭터를 추가하면 그 페어 장비도 장비 뽑기 풀에 함께 추가된다.
- 페어 장비는 장비 뽑기로 얻는다. 기본 제공 캐릭터 3명의 페어 장비는 **튜토리얼 보상으로 지급**한다.
- 장비는 최대 강화에 도달하기 전까지 뽑기 풀에 남는다. 이미 가진 장비(튜토리얼로 받은 장비 포함)가 다시 나오면 강화된다.
- 캐릭터 한 명은 페어 장비 **1개**를 장착한다(보조장비 슬롯은 별도). 장비는 전용이 아니어서 누구나 장착할 수 있다.
- 장비의 효과는 **능력치 가점**뿐이다. 장비 하나당 가점 합계는 **+10**이고, 네 능력치에 장비마다 다르게 배분한다.
- 성향 보너스 (두 조건을 모두 만족하면 **높은 쪽 하나만**):

| 조건 | 장비 가점 보너스 | 예: 가점 +10 장비 |
|---|---|---|
| 성향 불일치 | 없음 | +10 |
| 캐릭터와 장비의 성향이 같음 | **+10%** | +11 |
| 캐릭터와 그 페어 장비 | **+30%** | +13 |

- 중복 강화: 같은 장비를 다시 얻으면 강화 단계가 1 오르고, 단계마다 가점이 +10% 오른다. 최대 +5단계다. 강화 보너스와 성향 보너스는 곱한다.

## 9. 계정 성장

- 계정 경험치: 스테이지 **첫 클리어 100**(난이도별 따로), **재클리어 20**. 메인 퍼즐·사냥 목표도 계정 경험치 획득처로 두고 첫 완료/반복량을 데이터로 정한다(수치 제안). 턴제를 해야만 계정 성장이 가능한 구조를 금지한다.
- **성장** 메뉴에서 계정 **5레벨마다** 해금 단계가 하나씩 열린다. 단계마다 **재화 100**을 써서 해금한다.
- 해금 효과: 단계마다 **전체 캐릭터의 능력치 1종 +2**. 순서는 공격력 → 방어력 → 통솔력 → 기동력을 반복한다.
- 해금하지 않아도 클리어할 수 있는 작은 폭으로 둔다. 기준 난이도는 해금이 전혀 없는 상태로 검증한다.

## 10. 도전과제

| 종류 | 내용 | 보상 |
|---|---|---|
| 업적 | 1회성 목표 (예: 1장 클리어, 캐릭터 10명 모으기) | 재화 20~100 |
| 일일 과제 | 매일 초기화되는 목표 (예: 스테이지 3회 클리어, 필드 적 20마리 처치) | 과제당 재화 10 |

- 일일 과제는 하루 3개다(하루 최대 재화 30).
- 업적 보상 총량은 게임별로 정하고, 과금 지침의 무료 획득 속도에 맞춰 관리한다.
- **어려움+ 전용 업적**: 어려움+ 장 클리어, 힌트 없이 장 클리어, 재도전 없이 보스 클리어 등. 보상은 같은 종류 기본 업적의 3배다(§2 어려움+).

### 인연 도전과제 (캐릭터 수집)

키우지 않는 캐릭터도 가지고 있는 것만으로 의미가 있게 하는 수집 도전과제다.

- 스토리의 중요한 장면마다 **관련 캐릭터 3명으로 된 "인연"**을 하나씩 정한다(예: 의형제를 맺는 장면의 세 사람).
- 세 명을 모두 **보유**하면(출전하거나 키우지 않아도 됨) 인연이 완성된다.
  - 그 장면의 **장면 일러스트**가 인연 도감에서 열린다(모든 나라 공통). 표현 모드에 맞춰 두 벌을 둔다.
  - **1회 보너스 재화**를 준다(제안: 인연마다 50).
  - **특정 상황에서만 켜지는 전투 버프**가 영구히 적용된다. 버프는 계정 전체에 적용되고, 그 세 명이 출전하지 않아도 켜진다.
- 버프의 상황 유형:

| 상황 유형 | 예 |
|---|---|
| 장 | 그 장면이 나오는 장의 스테이지에서 |
| 지형 | 특정 지형(강, 다리, 숲 등)에서 교전할 때 |
| 상대 병종 | 특정 병종과 교전할 때 |
| 모드 | 1:1 대결에서, 또는 필드 전투에서 |
| 행동 | 스킬을 쓸 때, 방어를 고를 때 |

- 버프 크기는 작게 둔다(제안: 인연 하나당 해당 능력치 또는 피해 +5%). 같은 상황에 여러 인연이 겹치면 합계 최대 +15%(제안).
- 기준 난이도 검증은 인연 버프가 하나도 없는 상태로 한다(과금 지침 "난이도 설계 규칙").
- **첫 인연은 기본 제공 캐릭터 3명**으로 구성해, 게임을 시작하자마자 완성되게 한다. 인연 기능과 도감을 처음 보여 주는 튜토리얼로 쓴다.
- 장면 일러스트는 여러 캐릭터가 한 그림에 나오므로, 캐릭터별 얼굴과 의상을 맞추는 데 시간이 더 든다. 수직 슬라이스에서 첫 인연의 장면 일러스트로 제작 방식을 먼저 시험한다(개발·출시 지침 §8).
- 성장 메뉴에 **인연 도감**을 두어, 인연 목록, 모은 캐릭터, 완성 여부와 버프 내용을 보여 준다. 아직 없는 캐릭터는 실루엣으로 보여 주고 얻는 방법(스토리, 주간 직접 판매, 뽑기)을 알려 준다.
- **일본**: 경품표시법의 "콤프가챠" 규제(유료 뽑기로 특정 조합을 모으면 보상을 주는 구조 금지) 때문에, 일본에서는 인연이 캐릭터 보유와 연결되지 않게 한다. 인연 장면 일러스트는 **캐릭터 보유가 아니라 스토리 진행**(그 장면이 나오는 장을 클리어)으로 열리고, 보너스 재화와 전투 버프는 주지 않는다. 일본 출시 전 법무 확인을 받는다.
- **한국 등**: 캐릭터를 모아 보상을 받는 구조는 한국 게임산업법상 "컴플리트형" 확률형 아이템 표시 대상일 수 있다. 확률 공개 화면에 인연 보상 구조를 함께 안내한다(과금 지침 "법규·스토어 준수").
- 인연 구성 규칙: 모든 인연은 가능하면 뽑기 없이도 완성할 수 있게 짠다(스토리 획득 또는 주간 직접 판매). 일본 외 지역에서도 "뽑기로만 모을 수 있는 조합"이라는 인상을 줄이기 위해서다.

## 11. 화면과 UI

- 아트: 필드와 전투는 **도트 그래픽 탑뷰**, 캐릭터는 **일러스트**(대화, 상세 화면, 획득 연출, 컷인).
- 화면 방향: **가로**, 양손 조작.
- 필드 화면 배치:

| 위치 | 구성 |
|---|---|
| 왼쪽 위 | 캐릭터 상태(조작 중인 캐릭터 초상화, 체력, 파티 교체). 누르면 메뉴 |
| 오른쪽 위 | 미니맵(누르면 월드맵), 그 아래 경로 힌트 버튼 |
| 캐릭터 주위 | 목표 화살표 (§3) |
| 왼쪽 아래 | 가상 조이스틱 |
| 오른쪽 아래 | 공격, 회피, 일반스킬, 궁극기 |

- 필드 화면 **왼쪽 위의 캐릭터 상태**를 누르면 메뉴로 들어간다.

| 순서 | 메뉴 | 내용 |
|---|---|---|
| 1 | 상점 | 재화 충전, 광고 제거 상품, 뽑기 |
| 2 | 장비 | 페어 장비·보조장비 목록과 장착, 도구·기능 해금 확인 |
| 3 | 성장 | 하위 탭 2개: **캐릭터**(레벨, 능력치 투자, 초기화, 강화 단계, 파티 편성) / **계정**(계정 레벨, 성장 해금) |
| 4 | 도전과제 | 업적, 일일 과제 |
| 5 | 지도 | 월드맵, 다음 목표, 발견한 웨이포인트(워프), 전투 기록 |

### 캐릭터 첫 등장 소개

- 캐릭터(아군, 보스)가 스토리에 처음 나올 때 짧은 **소개 카드**(일러스트, 이름, 한두 줄 소개)를 보여 준다. 테마를 잘 모르는 해외 플레이어도 인물 관계를 따라오게 하기 위해서다.
- 지나간 소개는 성장 메뉴의 캐릭터 상세에서 다시 볼 수 있다.

### 소리

- 대화는 글자가 나올 때 캐릭터마다 다른 짧은 **말소리 효과음**을 낸다(언어 무관).
- 캐릭터 음성은 짧은 외침(스킬, 1:1 대결 진입·승리·패배, 피격·기합)으로 한정하고, 표현 모드마다 다른 목소리를 쓴다. 기본은 언어가 없는 기합·감탄 소리다. 스토리 대사는 더빙하지 않는다.
- 설정에서 배경음악, 효과음, 음성 크기를 따로 조절한다.

### 대화 화면

캐릭터끼리 또는 NPC와 대화할 때:

```
┌──────────────────────────────────────────────────────────┐
│ [왼쪽 화자    ]   ┌ 말풍선 (왼쪽 화자) ┐           [오른쪽 화자  ] │
│ [ 일러스트    ]   └─────────────────┘           [ 일러스트    ] │
│ [ (상반신)    ]          ┌ 말풍선 (오른쪽 화자) ┐  [ (상반신)    ] │
│ [             ]          └──────────────────┘  [              ] │
│ [ 이름        ]   ┌ 말풍선 …          ┐           [ 이름        ] │
│                       [ 선택지 1 ]  [ 선택지 2 ]                  │
└──────────────────────────────────────────────────────────┘
```

- 왼쪽과 오른쪽에 대화하는 두 인물의 일러스트를 보여준다. 말하는 쪽은 밝게, 듣는 쪽은 어둡게 표시한다.
- 가운데는 **채팅 화면처럼 말풍선이 위에서 아래로 쌓인다**. 왼쪽 인물의 말은 왼쪽 정렬, 오른쪽 인물의 말은 오른쪽 정렬이다. 위로 스크롤하면 앞 대화를 다시 볼 수 있다.
- 선택지는 가운데 아래에 버튼으로 나오고, 고른 선택지는 플레이어 쪽 말풍선으로 쌓인다.
- 일러스트는 표현 모드를 따른다. 셋 이상이 대화하면 말하는 인물로 좌우 자리를 바꿔 넣는다.
- 화면을 누르면 다음 대사로 넘어간다. 자동 넘김과 건너뛰기 버튼을 둔다.
