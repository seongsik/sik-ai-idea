# 스테이지 기반 전략 게임 기본 골격

> 한 줄 요약: 내가 만드는 게임의 공통 게임 규칙. 가로 화면 도트 탑뷰 RPG로, 캐릭터를 바꿔 가며 필드를 모험하고(퍼즐, NPC, 액션 전투), 스토리의 핵심 전투는 격자 턴제 전략으로, 1:1 대결은 액션으로 치른다. 개별 게임은 테마(명칭, 캐릭터, 스토리, 필드)만 바꾼다.
>
> 최종 수정: 2026-11-02 (장 구성 기본값과 목표 화살표 세부 확정, 경로 힌트 추가)

- 카테고리: game
- 문서 유형: 공통 지침 (개별 아이디어가 아님)
- 작성일: 2026-11-01
- 적용 대상: 개별 게임 기획서가 "스테이지 기반 전략 게임 기본 골격을 따른다"고 명시한 모든 게임

## 이 지침의 사용법

게임 관련 공통 지침은 세 개이고, 함께 쓴다.

| 지침 | 정하는 것 | 이 아이디어 리포지터리의 경로 |
|---|---|---|
| **스테이지 기반 전략 게임 기본 골격** (이 문서) | 게임 규칙: 구조, 필드, 전투, 캐릭터, 장비, 성장, 화면 | `game/stage-strategy-framework/README.md` |
| **게임 개발 공통 과금 지침** | 돈: 재화, 가격, 뽑기, 광고, 환불, 스팀판 과금 | `game/monetization-guideline/README.md` |
| **게임 개발·출시 공통 지침** | 만들고 내는 방법: 엔진, 코드 구조, 서버, 다국어, 개발 도구, 아트 파이프라인, 출시 체크리스트, 개발 단계 | `game/dev-release-guideline/README.md` |

- 개별 게임 기획서에는 지침 내용을 다시 쓰지 않는다. 각 지침의 "게임별로 정의할 항목"(테마 데이터)과 그 게임만의 고유 내용만 적는다.
- 구현 리포지터리로 가져갈 때는 지침 세 개와 게임 기획서를 함께 복사한다.
- 지침과 게임 기획서가 충돌하면 지침이 우선한다. 예외가 필요하면 게임 기획서에 "지침 예외"로 명시하고 이유를 적는다.
- 게임 내 명칭은 **캐주얼하고 직관적인 이름**을 쓴다. 세계관 색이 강한 고유 용어는 캐릭터 이름, 상징 장비 이름, 스토리에만 쓴다.
- "(제안)"이 붙은 수치와 방식은 초기 설계값이다. 구조는 유지하고, 수치는 플레이테스트로 조정한다.

## 1. 게임 구조

- **가로 화면 도트 탑뷰 RPG**다. 메인 화면은 필드이고, 게임을 켜면 마지막으로 저장한 필드 위치에서 시작한다.
- 세 가지 모드로 이뤄진다.

| 모드 | 언제 | 방식 |
|---|---|---|
| 필드 | 평소 | 캐릭터를 조작해 탐험. 퍼즐, NPC 대화와 선택, 일반 적과 액션 전투 (§3, §4) |
| 1:1 대결 | 스토리의 정해진 대결 지점, 1:1 대결 스테이지 | 일반 적이 없는 1:1 전장에서 필드와 같은 액션 전투 (§5) |
| 턴제 전투 | 스토리의 핵심 전투 지점 | 격자 맵에서 출전 3명으로 싸우는 턴제 전략 전투 (§6) |

```
필드 (액션 탐험) ── 일반 적 ──> 필드 액션 전투 (그 자리에서)
     │
     ├─ 스토리 전투 지점 도착 ──> 턴제 전략 전투 (별도 화면, 출전 3명)
     │
     ├─ 1:1 대결 지점 도착 ────> 1:1 전장 (필드와 같은 액션, 일반 적 없음)
     │
     ├─ 웨이포인트 ──> 발견한 웨이포인트로 워프 (지도 메뉴)
     │
     └─ NPC 대화·선택, 퍼즐, 상자, 구역 이동(자동 저장)
```

- 턴제 전투와 1:1 대결을 묶어 **스테이지**라고 부른다. 1:1 대결은 턴제 전투 안에서 일어나지 않는다.
- 필드 구성은 「젤다의 전설: 꿈꾸는 섬」을 오마주한다. 참고하는 것은 필드 구성과 조작감(방 단위 구성, 퍼즐, 트릭, 숨은 길, 도구로 길 열기)뿐이다. 닌텐도의 그래픽, 음악, 맵 배치, 아이템 디자인과 이름, "젤다" 명칭은 쓰지 않고 홍보 문구에도 쓰지 않는다.
- 스태미나는 두지 않는다. 필드 탐험과 스테이지는 언제든 제한 없이 할 수 있다.

## 2. 진행 구조

- 스토리를 따라 장(章) 단위로 진행한다. 장 하나가 필드 하나다. 스테이지 번호는 `장-스테이지` 형식이다 (1-1, 1-2, …).
- 필드에서 다음 스테이지 장소를 직접 찾아간다.
- **장 구성 기본값** (게임별로 조정 가능):

| 항목 | 기본값 |
|---|---|
| 스테이지 | 4개: 턴제 전투 3개(마지막이 보스전) + 1:1 대결 1개 |
| 특수 스테이지 | 장마다 0~1개 (선택 콘텐츠) |
| 필드 크기 | 바깥 필드 화면 25~30장(약 6×5) + 작은 던전 화면 8~10장 = **화면 35~40장** |
| 웨이포인트 | 3~4개. 스테이지 사이마다 하나씩 |
| 필드 도구 | 최대 1개 (도구가 다 나올 때까지) |
| 처음 공략 시간 (기본 난이도) | **약 1.5~2시간**: 필드 탐험 30~40분, 던전 15~20분, 턴제 전투 30~40분, 1:1 대결 3~5분, 대화 10분 |
| 한 구간 | 웨이포인트에서 다음 웨이포인트(또는 스테이지)까지 10~20분. 모바일에서 끊어서 할 수 있는 단위 |

- 6장 기준 메인 스토리는 약 9~12시간, 어려움 난이도와 특수 스테이지를 더하면 15~20시간이다.
- **난이도**는 **기본**과 **어려움** 두 가지다.
  - 어려움은 같은 스테이지의 기본 난이도를 클리어하면 열린다.
  - 어려움 첫 클리어 보상은 기본 난이도 첫 클리어와 별도로 지급한다(과금 지침의 무료 획득처).
- **분기점**: 장 끝이나 NPC 대화의 선택에 따라 다음 장 경로가 달라진다. 다른 쪽 경로는 나중에 다시 플레이할 수 있다.
- **특수 스테이지** 유형: 1:1 대결 전용(1명), 방어전(정해진 턴 동안 버티기), 호위전(특정 캐릭터 생존), if 스토리.
- **전투 기록**: 이미 클리어한 스테이지는 지도 메뉴의 "전투 기록"에서 바로 다시 시작한다. 재클리어 보상과 어려움 난이도 도전도 여기서 한다.
- 모든 스테이지는 과금 없이, 플레이어의 숙련도와 전략만으로 클리어할 수 있게 만든다(과금 지침 "난이도 설계 규칙").

## 3. 필드

- **크기 단위**: 필드는 **화면** 단위로 만든다. 화면 하나는 가로 16 × 세로 9 **타일**이고, 타일 하나는 16×16픽셀(캐릭터 한 명이 서는 크기, 한 걸음)이다. 화면 끝에 닿으면 옆 화면으로 넘어간다. 화면 하나를 가로질러 걷는 데 약 3초가 걸린다(초당 5타일 기준). 턴제 전투 맵의 크기(§6)는 타일 단위다.
- 넓이보다 **화면당 밀도**를 우선한다. 화면마다 퍼즐, 숨은 길, 적 배치, NPC, 상자 중 하나 이상을 둔다.
- 조작하는 캐릭터는 **출전 파티 3명 중 리더**다. 필드에서 언제든 파티 안에서 바꿔 조작할 수 있다.
- 필드에서 하는 일:
  - 간단한 퍼즐 (스위치, 열쇠, 블록 밀기·당기기 같은 트릭). 퍼즐이 풀 수 없는 상태로 꼬이지 않도록, 구역을 나갔다 들어오면 초기화한다.
  - NPC와 대화하고 선택하기. 선택은 스토리 분기에 영향을 줄 수 있다.
  - 상자, 숨은 길 찾기.
  - 일반 적(잡몹)과 액션 전투 (§4).
- **필드 도구**: 스토리 진행으로 **3~4개**를 얻고, 도구를 얻으면 이전에 갈 수 없던 길이 열린다. 이름과 디자인은 게임별로 독자적으로 만든다.

| 기본형 | 하는 일 |
|---|---|
| 밀기·당기기 | 무거운 블록과 바위를 밀고 당긴다 |
| 뛰어넘기 | 구멍이나 낮은 물을 건넌다 |
| 끌어당기기 | 멀리 있는 지점으로 몸을 끌어당겨 건넌다 |
| 부수기 | 금 간 벽이나 막힌 길을 부순다 |

- **웨이포인트**: 디아블로의 웨이포인트 방식을 차용한다. 웨이포인트를 밟으면 발견 처리되고, 발견한 웨이포인트 사이를 지도 메뉴에서 바로 워프한다. 밟으면 파티 전원의 체력이 최대로 회복된다. 이름과 디자인은 게임별로 정한다.
- **일반 적 보상**: 처치하면 확률적으로 재화 1을 준다(제안: 10%). 캐릭터 경험치는 주지 않는다. 체력 회복 아이템이 떨어질 수 있다.
- **필드 사망**: 조작 캐릭터의 체력이 0이 되면 현재 필드 지역의 시작 지점에서 최대 체력으로 부활한다. 재화나 경험치를 잃는 등의 페널티는 없다. (제안: 파티의 다른 캐릭터로 바꾸지 않고 바로 부활)
- **길 안내**:
  - **미니맵**: 필드 화면 오른쪽 위에 작게 상시 표시한다. 지금 있는 화면 주변과, 가 본 화면만 보여 준다(안 가 본 곳은 가려짐). 웨이포인트, 스테이지 지점, 지역 출구를 아이콘으로 표시한다. 누르면 월드맵이 열린다.
  - **월드맵**: 지도 메뉴(§11)에서 연다. 장(필드)들의 위치와 연결, 발견한 웨이포인트(워프), 스테이지 지점, 다음 목표를 보여 준다.
  - **목표 화살표**: 조작 캐릭터 주위에, 스토리상 다음 목표 방향을 가리키는 화살표를 표시한다. 화살표는 캐릭터를 중심으로 360도 돌아가며 목표까지의 **직선 방향**을 가리킨다.
    - 목표: 다음 스테이지 지점. 다음 목표가 다른 필드에 있으면 그 필드로 가는 지금 필드의 출구를 가리킨다.
    - 목표가 가까워지면(같은 화면 안) 화살표가 흐려지고 목표 지점에 표시가 나타난다.
    - 직선 방향이라 벽이나 퍼즐 때문에 바로 갈 수 없을 수 있다. 길 찾기는 플레이어 몫으로 남겨 탐험의 재미를 지킨다.
    - 숨은 길, 상자, 선택 콘텐츠는 가리키지 않는다.
    - 설정에서 끌 수 있다(기본은 켜짐).
  - **경로 힌트**: 목표 화살표만으로 길을 찾기 어려울 때 쓰는 도움 기능이다.
    - 쓰면 **1분 동안** 조작 캐릭터 위치에서 목표 화살표의 목표까지 **최단 경로**를 바닥에 빛나는 선으로 보여 준다. 캐릭터가 움직이면 경로도 따라 갱신된다.
    - 퍼즐로 치워야 하는 장애물(밀어야 하는 블록, 잠긴 문, 부숴야 하는 벽, 필드 도구가 필요한 곳)이 길을 막고 있어도 **관통해서** 경로를 그린다. 그 장애물 위치는 경로 위에 따로 표시해, 어디서 무엇을 풀어야 하는지 알 수 있게 한다(제안). 벽, 절벽, 물처럼 원래 지나갈 수 없는 지형은 관통하지 않는다.
    - 횟수: 최대 **3회**까지 쌓이고, **5분에 1회**씩 충전된다. 게임을 꺼 둔 동안에도 충전된다.
    - 재화나 광고로 충전하지 않는다.
    - 버튼 위치는 미니맵 바로 아래이고, 남은 횟수와 다음 충전까지 남은 시간을 표시한다(제안).
- **자동 저장**: 필드 구역(화면)을 이동할 때마다 자동 저장한다. 퍼즐 진행, 상자, NPC 선택, 발견한 웨이포인트도 저장 대상이다.

## 4. 액션 전투 (필드, 1:1 대결 공통)

- 조작:

| 위치 | 구성 |
|---|---|
| 왼쪽 | 가상 조이스틱 (이동) |
| 오른쪽 | 공격 버튼, 회피 버튼, 스킬 버튼 2개 |

- PC(스팀)는 키보드·마우스와 게임패드로 같은 명령을 낸다(§12).
- 캐릭터마다 고유 스킬 2개를 가진다.
- 기본 공격은 캐릭터마다 세 유형 중 하나다.

| 공격 유형 | 방식 | 예 |
|---|---|---|
| 휘두르기 | 근접. 앞쪽 부채꼴 범위를 벤다 | 칼, 창, 도끼 |
| 화살 | 원거리. 직선으로 날아가는 투사체 | 활, 쇠뇌 |
| 에너지볼 | 원거리. 느리지만 강하거나 범위 효과가 있는 투사체 | 술법, 기공, 부채 |

- 능력치 반영 (능력치는 §7):

| 능력치 | 액션 전투에서의 효과 |
|---|---|
| 공격력 | 기본 공격과 스킬의 피해 |
| 방어력 | 받는 피해 감소, 회피 |
| 통솔력 | 캐릭터별 최대 체력. `최대 체력 = 50 + 통솔력 × 5` (제안, 턴제 병력의 1/10) |
| 기동력 | 이동 속도 |

- 체력은 캐릭터마다 따로 관리한다. 조작 캐릭터를 바꾸면 그 캐릭터의 남은 체력으로 싸운다.
- 체력 회복: 웨이포인트(파티 전원 최대), 1:1 대결 진입(대결 캐릭터 최대), 회복 아이템(일부), 필드 사망 후 부활(최대).
- **액션 보조 모드**: 설정에서 켜면 공격 범위 안의 적을 자동으로 공격한다. 자동 조준과 받는 피해 감소도 함께 쓸 수 있다. 보상에는 영향을 주지 않는다.

## 5. 1:1 대결

- 턴제 전투와 **따로** 진행하는 독립 스테이지다. 스토리의 정해진 대결 지점과 1:1 대결 전용 특수 스테이지에서 일어난다.
- 일반 적이 없는 1:1 전장에서 §4 액션 전투로 싸운다. 들어갈 때 대결 캐릭터의 체력이 최대로 회복된다.
- 승리 조건: 제한 시간 안에 상대 체력을 0으로 만들거나, 시간이 끝났을 때 남은 체력 비율이 더 높으면 이긴다(제안).
- 결과: 이기면 스토리가 진행된다. 지면 페널티 없이 다시 도전한다(제안). 끝나면 스테이지 종료 광고가 나온다.
- 연출: 진입할 때 두 캐릭터의 일러스트 컷인과 대사. 게임에서 가장 공들일 연출 포인트다.
- 1:1 대결의 게임 내 이름은 게임별로 정한다.

## 6. 턴제 전투

### 기본 규칙

- 격자(사각형 칸) 맵에서 진행한다. 맵 크기는 출전 인원에 맞춰 작게 잡는다(제안: 작은 맵 8×10, 큰 맵 10×14). 큰 맵은 스크롤과 확대·축소를 지원한다.
- 출전 인원은 **최대 3명**이다. 특수 스테이지는 1~2명으로 제한할 수 있다.
- 승리 조건 기본형: 캐릭터들을 전진시켜 **적 요새를 함락**한다(요새는 별도 수비 병력을 가진다). 게임별로 다른 승리 조건(적 전멸, 특정 적 격파, 버티기)을 스테이지마다 지정할 수 있다.
- 턴 제한이 있다. 화면 상단에 `N턴째 / 제한 M턴`을 항상 표시하고, 남은 턴이 3 이하가 되면 강조한다. 턴 단위의 게임 내 이름(예: "일")은 게임별로 정한다.
- 제한 턴 산정(제안): `제한 턴 = 기준 클리어 턴 × 난이도 계수`, 맵 규모로 보정. 기준 클리어 턴은 뽑기 강화와 계정 성장 해금이 전혀 없는 편성으로 측정한 평균값이다. 난이도 계수는 기본 1.4, 어려움 1.1.

### 지형 (기본형, 제안)

| 지형 | 이동 비용 | 방어 보정 |
|---|---|---|
| 평지 | 1 | 0% |
| 숲 | 2 | +20% |
| 산 | 3 | +40% |
| 강 | 통과 불가 (다리는 1) | -10% |
| 성채·관문 | 1 | +30% |
| 적 요새 | 1 | +50%, 별도 수비 병력 |

- 지형 이름과 그림은 테마에 맞게 바꿀 수 있다. 수치 구조는 유지한다.

### 병력과 이동

- 병력(턴제 전투의 체력): `최대 병력 = 500 + 통솔력 × 50`. 매 전투 시작 시 가득 찬다.
- 이동 칸 수: `기본 3칸 + 기동력 5포인트당 1칸`, 최대 8칸.
- 적의 인접 칸(ZOC, 지배 영역)에 들어가면 그 턴의 남은 이동이 끝나서, 적을 그냥 지나칠 수 없다.

### 병종

- 캐릭터는 병종을 가지며 **캐릭터마다 고정**이다. 병종은 병력끼리 싸울 때의 상성을 정한다.
- 기본형: **기병 > 보병 > 궁병 > 기병**. 유리하면 피해 1.2배, 불리하면 0.8배.
- 궁병은 2칸 거리에서 공격할 수 있고, 근접 공격을 받으면 반격하지 못한다.
- 병종 이름과 종류는 테마에 맞게 바꿀 수 있다. 바꿀 때도 세 병종 순환 상성 구조는 유지한다.

### 전투 계산

- 공격자가 먼저 피해를 주고, 방어자가 살아 있으면 반격한다.
- 피해량(제안): `피해 = 공격자 병력 × 0.1 × (공격력 + 20) / (대상 방어력 + 20) × 병종 상성 × (1 − 지형 방어 보정)`
  - 상수 20은 능력치가 작을 때 수치 차이가 과도하게 커지지 않게 하는 완충값이다.
- 회피: 대상의 방어력에 비례해 피해를 완전히 피할 확률이 있다(제안: 최대 20%).
- 양쪽이 서로 병력을 잃으므로, 강한 캐릭터도 연전하면 약해진다.

### 적 AI (제안)

- 적마다 AI 역할을 정한다: 수비(요새 주변에 머묾), 요격(가장 약한 아군을 노림), 진격(아군을 향해 전진).
- 행동 후보마다 점수(예상 피해, 받을 반격, 지형 보너스, 병종 상성, 요새와의 거리)를 매겨 고른다.
- 난이도는 AI가 몇 수 앞을 보는지와 적 병력 배율로 조절한다.

### 재도전(되감기)과 실패

- 실패 조건과 재도전 혜택 기본형:

| 실패 조건 | 재도전 혜택 |
|---|---|
| 아군 전멸 | 5턴 전으로 되감기 |
| 제한 턴 소진 | 10턴 전으로 되감기 |

  - 전투가 시작된 지 5턴(또는 10턴)이 지나지 않았으면 1턴째로 되돌아간다.
- 횟수: 스테이지 1회 도전당 **기본 최대 3회, 어려움 최대 1회**. 전멸과 소진을 합산한다. 광고 제거 여부와 관계없이 모든 플레이어가 같다.
- 광고 제거가 적용되지 않았으면 재도전할 때마다 보상형 광고를 1회 보고, 적용 중이면 광고 없이 쓴다.
- 재도전을 다 썼거나 포기하면 스테이지가 실패로 끝나고 짧은 광고가 나온다(광고 제거 적용 중이면 없음).
- 재도전 혜택의 게임 내 이름은 게임별로 정한다.

## 7. 캐릭터

### 획득

- 기본 획득 경로:
  - **기본 제공**: 처음에 3명.
  - **보스 격파**: 스토리 보스를 물리치면 그 캐릭터를 얻는다. 이미 가지고 있으면 강화 단계가 1 오르고, 최대 단계면 대신 재화 30을 준다.
  - **스토리 합류**: 정해진 스테이지를 클리어하면 합류한다.
  - **뽑기**: 모바일판만. 모든 캐릭터가 처음부터 뽑기 풀에 있다(과금 지침).
- 모든 캐릭터에 **스토리 획득 스테이지**를 데이터로 지정한다. 스팀판은 이 데이터로 모든 캐릭터를 무상 지급한다(과금 지침 "스팀(PC)판").
- 캐릭터에는 등급이 없다.

### 능력치

| 능력치 | 턴제 전투 | 액션 전투 (필드, 1:1 대결) |
|---|---|---|
| 공격력 | 피해량 | 기본 공격과 스킬 피해 |
| 방어력 | 받는 피해 감소, 회피 | 받는 피해 감소, 회피 |
| 통솔력 | 최대 병력 | 최대 체력 |
| 기동력 | 이동 칸 수 | 이동 속도 |

### 성향

- 캐릭터와 장비에는 성향이 있다: **지휘관형, 암습형, 돌격형, 방어형**.
- 성향은 상성에 쓰지 않는다. **장비를 통해 능력치에 가점을 주는 역할**만 한다(§8).

### 성장

- 처음 얻은 캐릭터는 1레벨이며, 능력치 포인트 **20**이 그 캐릭터의 특성에 맞게 네 능력치에 나눠져 있다.
- 레벨은 스테이지 결과로 오른다.
  - **승리**: 출전한 캐릭터는 레벨이 1 오른다(승리 경험치 = 다음 레벨까지 필요한 경험치 전부).
  - **패배**: 승리 경험치의 **1/10**을 얻는다.
  - 필드 일반 적은 캐릭터 경험치를 주지 않는다.
  - 최대 레벨은 **50**이다. 50레벨의 능력치 총합은 20 + 49×3 = 167이다.
- 레벨이 오를 때마다 능력치 포인트 **3**을 얻고, 플레이어가 네 능력치 중 원하는 곳에 하나씩 투자한다.
- 능력치 초기화: 캐릭터별 **첫 1회 무료**, 이후 **재화 100**.
- 중복 강화: 같은 캐릭터를 다시 얻으면(뽑기, 보스 격파) 강화 단계가 1 오르고 **보너스 능력치 포인트 +5**를 얻는다. 최대 **+5단계(보너스 +25)**다. 최대 단계면 뽑기 풀에서 빠진다.
  - +25는 50레벨 총 포인트(167)의 약 15%로, 체감은 되지만 전략을 대신하지 않는 수준이다.
  - 스팀판은 뽑기가 없으므로 재화 300으로 1단계씩 강화한다(과금 지침 "스팀(PC)판").

### 표현 모드

- 캐릭터 디자인을 **오리지널**과 **재해석**(게임별 컨셉) 중에서 고를 수 있다. 처음 실행할 때 고르고, 설정에서 언제든 바꾼다.
- 바꾸면 일러스트(초상화, 스탠딩, 컷인)와 도트 스프라이트가 모두 바뀐다. 두 모드 모두 일러스트와 도트를 한 벌씩 만든다. 게임 규칙과 능력치는 같다.
- 출시 후 스킨은 재해석 모드 전용으로만 만든다(과금 지침).

## 8. 장비

- 장비에는 등급이 없다.
- **캐릭터 하나에 상징 장비 하나를 페어로 함께 출시한다.** 새 캐릭터를 추가하면 그 페어 장비도 장비 뽑기 풀에 함께 추가된다.
- 페어 장비는 장비 뽑기로 얻는다. 기본 제공 캐릭터 3명의 페어 장비는 **튜토리얼 보상으로 지급**한다.
- 장비는 최대 강화에 도달하기 전까지 뽑기 풀에 남는다. 이미 가진 장비(튜토리얼로 받은 장비 포함)가 다시 나오면 강화된다.
- 캐릭터 한 명은 장비 **1개**만 장착한다. 장비는 전용이 아니어서 누구나 장착할 수 있다.
- 장비의 효과는 **능력치 가점**뿐이다. 장비 하나당 가점 합계는 **+10**이고, 네 능력치에 장비마다 다르게 배분한다.
- 성향 보너스 (두 조건을 모두 만족하면 **높은 쪽 하나만**):

| 조건 | 장비 가점 보너스 | 예: 가점 +10 장비 |
|---|---|---|
| 성향 불일치 | 없음 | +10 |
| 캐릭터와 장비의 성향이 같음 | **+10%** | +11 |
| 캐릭터와 그 페어 장비 | **+30%** | +13 |

- 중복 강화: 같은 장비를 다시 얻으면 강화 단계가 1 오르고, 단계마다 가점이 +10% 오른다. 최대 +5단계다. 강화 보너스와 성향 보너스는 곱한다.

## 9. 계정 성장

- 계정 경험치: 스테이지 **첫 클리어 100**(난이도별 따로), **재클리어 20**.
- **성장** 메뉴에서 계정 **5레벨마다** 해금 단계가 하나씩 열린다. 단계마다 **재화 100**을 써서 해금한다.
- 해금 효과: 단계마다 **전체 캐릭터의 능력치 1종 +2**. 순서는 공격력 → 방어력 → 통솔력 → 기동력을 반복한다.
- 해금하지 않아도 클리어할 수 있는 작은 폭으로 둔다. 기준 난이도는 해금이 전혀 없는 상태로 검증한다.

## 10. 도전과제

| 종류 | 내용 | 보상 |
|---|---|---|
| 업적 | 1회성 목표 (예: 1장 클리어, 캐릭터 10명 모으기) | 재화 20~100 |
| 일일 과제 | 매일 초기화되는 목표 (예: 스테이지 3회 클리어, 필드 적 20마리 처치) | 과제당 재화 10 |

- 일일 과제는 하루 3개를 기본으로 한다(제안, 하루 최대 30).
- 업적 보상 총량은 게임별로 정하고, 과금 지침의 무료 획득 속도에 맞춰 관리한다.

## 11. 화면과 UI

- 아트: 필드와 전투는 **도트 그래픽 탑뷰**, 캐릭터는 **일러스트**(대화, 상세 화면, 획득 연출, 컷인).
- 화면 방향: **가로**, 양손 조작.
- 필드 화면 배치:

| 위치 | 구성 |
|---|---|
| 왼쪽 위 | 캐릭터 상태(조작 중인 캐릭터 초상화, 체력, 파티 교체). 누르면 메뉴 |
| 오른쪽 위 | 미니맵(누르면 월드맵), 그 아래 경로 힌트 버튼 |
| 캐릭터 주위 | 목표 화살표 (§3) |
| 왼쪽 아래 | 가상 조이스틱 |
| 오른쪽 아래 | 공격, 회피, 스킬 2개 |

- 필드 화면 **왼쪽 위의 캐릭터 상태**를 누르면 메뉴로 들어간다.

| 순서 | 메뉴 | 내용 |
|---|---|---|
| 1 | 상점 | 재화 충전, 광고 제거 상품, 뽑기 |
| 2 | 장비 | 보유 장비 목록, 장착 |
| 3 | 성장 | 하위 탭 2개: **캐릭터**(레벨, 능력치 투자, 초기화, 강화 단계, 파티 편성) / **계정**(계정 레벨, 성장 해금) |
| 4 | 도전과제 | 업적, 일일 과제 |
| 5 | 지도 | 월드맵, 다음 목표, 발견한 웨이포인트(워프), 전투 기록 |

### 대화 화면

캐릭터끼리 또는 NPC와 대화할 때:

```
┌──────────────────────────────────────────────────────────┐
│ [왼쪽 화자    ]   ┌ 말풍선 (왼쪽 화자) ┐           [오른쪽 화자  ] │
│ [ 일러스트    ]   └─────────────────┘           [ 일러스트    ] │
│ [ (상반신)    ]          ┌ 말풍선 (오른쪽 화자) ┐  [ (상반신)    ] │
│ [             ]          └──────────────────┘  [              ] │
│ [ 이름        ]   ┌ 말풍선 …          ┐           [ 이름        ] │
│                       [ 선택지 1 ]  [ 선택지 2 ]                  │
└──────────────────────────────────────────────────────────┘
```

- 왼쪽과 오른쪽에 대화하는 두 인물의 일러스트를 보여준다. 말하는 쪽은 밝게, 듣는 쪽은 어둡게 표시한다.
- 가운데는 **채팅 화면처럼 말풍선이 위에서 아래로 쌓인다**. 왼쪽 인물의 말은 왼쪽 정렬, 오른쪽 인물의 말은 오른쪽 정렬이다. 위로 스크롤하면 앞 대화를 다시 볼 수 있다.
- 선택지는 가운데 아래에 버튼으로 나오고, 고른 선택지는 플레이어 쪽 말풍선으로 쌓인다.
- 일러스트는 표현 모드를 따른다. 셋 이상이 대화하면 말하는 인물로 좌우 자리를 바꿔 넣는다.
- 화면을 누르면 다음 대사로 넘어간다. 자동 넘김과 건너뛰기 버튼을 둔다.
