# 게임 개발·출시 공통 지침

> 한 줄 요약: 내가 만드는 게임을 어떻게 만들고 내는지에 대한 공통 지침. 엔진과 코드 구조, 서버, 다국어, 개발 도구와 AI 사용, 아트 파이프라인, 출시 체크리스트, 개발 단계를 정한다.
>

- 카테고리: game
- 문서 유형: 공통 지침 (개별 아이디어가 아님)
- 작성일: 2026-11-02
- 적용 대상: 개별 게임 기획서가 "게임 개발·출시 공통 지침을 따른다"고 명시한 모든 게임

  - 스테이지 기반 전략 게임 기본 골격: `game/stage-strategy-framework/README.md` (게임 규칙)
  - 게임 개발 공통 과금 지침: `game/monetization-guideline/README.md` (돈)

## 이 지침의 사용법

- 개별 게임 기획서에는 이 지침을 다시 쓰지 않는다. 아래 "게임별로 정의할 항목"만 채운다.
- 구현은 별도 리포지터리에서 하고, 이 아이디어 리포지터리의 공통 지침 세 개와 게임 기획서를 **참조**해 개발한다. 이 리포지터리에는 아이디어와 지침만 기록하고 구현물은 두지 않는다.
- 개발 도구, 요금제, 모델 정보는 자주 바뀐다. 분기마다 다시 확인하고 이 문서를 갱신한다.

## 1. 플랫폼과 엔진

- 1차 출시: **Android(Google Play)와 iOS(App Store)**, 전 세계 동시 출시.
- 2차 출시: **스팀(PC)**, 모바일 출시 후. 과금은 과금 지침 "스팀(PC)판", 구조는 기본 골격 §12를 따른다.
- 엔진: **Unity (C#)**를 권장한다.
  - Android, iOS, PC를 한 코드로 빌드할 수 있다.
  - 광고(AdMob, Unity LevelPlay), 인앱 결제(Unity IAP), 현지화(Localization 패키지) 공식 지원이 성숙해 있다.
  - 2D 타일맵, 픽셀 퍼펙트 카메라, 2D 물리(블록 밀기 퍼즐)가 도트 탑뷰 RPG에 잘 맞는다.
  - 대안: Godot(가볍고 무료, 광고·결제 플러그인은 서드파티), Flutter + Flame.

## 2. 코드 구조

| 폴더 | 내용 |
|---|---|
| `Core/` | 게임 규칙. 렌더링과 분리된 순수 C# 로직이라 단위 테스트할 수 있다. 턴제 전투(맵, 이동 범위, 전투 계산, 턴 관리, 승패 판정), 액션 전투 판정 |
| `AI/` | 턴제 전투의 적 행동 결정, 필드 적 행동 |
| `Field/` | 필드 이동, 구역 전환, 퍼즐, 필드 도구, 웨이포인트, NPC 대화와 선택 |
| `Meta/` | 캐릭터 성장, 장비, 계정 레벨과 성장 해금, 도전과제, 뽑기, 진행 저장. 기본 골격을 구현하며 게임 사이에 재사용한다 |
| `Monetization/` | 광고, 인앱 결제, 스토어 환불 알림 처리. 과금 지침을 구현하며 게임 사이에 재사용하고, 스팀판에서는 꺼진 상태로 빌드한다 |
| `UI/`, `Scenes/` | 화면 |
| `Data/` | 스테이지, 캐릭터, 장비, 대사, 필드 데이터 (ScriptableObject 또는 JSON). 테마는 이 데이터와 아트만 바꾼다 |

- 턴제 전투 상태는 불변 객체로 두고, 행동은 `Apply(state, action) → state` 형태로 처리한다. 매 턴 시작 상태를 스택에 쌓아 되감기(기본 골격 §6), 리플레이, AI 시뮬레이션에 같은 코드를 쓴다.
- 입력, 화면 비율, 과금 모듈, 계정은 처음부터 분리한다(기본 골격 §12).

## 3. 서버와 데이터

- 관리형 서비스(Firebase의 Auth·Firestore·Cloud Functions, 또는 PlayFab)를 쓴다.
- 서버에서 처리하는 것: 결제 영수증 검증, 재화 잔액(유료·무료 분리 기록), 뽑기 결과 생성, 스토어 환불 알림 처리, 클라우드 저장.
- 클라우드 저장과 계정 연동: 모바일은 Google·Apple 계정, 스팀판은 스팀 계정과 스팀 클라우드.
- 분석: 스테이지 이탈률, 광고 시청률, 과금·무과금 클리어율 격차, 필드 구역별 체류 시간, 사망 위치, 경로 힌트 사용 위치(퍼즐·난이도 조정용. 힌트가 몰리는 곳은 퍼즐이나 길 설계를 고친다).
- 원격 설정(Remote Config): 광고 빈도, 드롭 확률, 밸런스 수치를 앱 업데이트 없이 조정한다.

## 4. 다국어

- 1차 언어: **한국어, 영어, 중국어(번체), 일본어**. 중국 본토는 출시하지 않으므로 번체를 쓴다.
- 2차 언어: 중국어 간체, 베트남어, 태국어, 인도네시아어, 스페인어, 포르투갈어(브라질), 독일어, 프랑스어.
- 모든 텍스트(UI, 대사, 스토리, 캐릭터 이름, NPC 대화와 선택지)를 문자열 키로 관리하고 코드에 하드코딩하지 않는다.
- 고유명사(캐릭터 이름, 장비 이름, 지명)는 언어별 관례 표기를 따른다. 게임별로 표기표를 만든다.
- 폰트: 도트 그래픽에 어울리는 픽셀 폰트를 기본으로 하되, CJK와 2차 언어 문자(태국어, 베트남어 성조)를 지원하는 폰트를 언어별로 준비하고 분리해 내려받는다.
- 레이아웃: 문장이 긴 언어(독일어 등)에 대비해 텍스트 영역이 자동으로 줄어들거나 줄바꿈되게 한다. 대화 화면의 말풍선 길이도 같다.
- 번역: 1차 번역은 AI로, 대량 작업은 일괄 처리(아래 §5)로 돌린다. 출시 전 원어민 검수를 거치고, 용어집(고유명사, 능력치·성향·병종·메뉴 명칭)으로 표기를 통일한다.
- 스토어 등록 정보(설명, 스크린샷 문구)도 언어별로 현지화한다.

## 5. 개발 도구와 AI 사용

2026-11 기준. 분기마다 다시 확인한다.

### AI 코딩 도구

- 후보: Claude Code(Claude Fable 5.1 / Opus 5.5)와 OpenAI Codex(GPT-6 Astra). 이 규모에서는 둘 다 충분하다.
- 선택: 첫 프로토타입을 두 도구에 같은 기획 문서로 맡겨 보고, 결과물과 작업 흐름이 맞는 쪽을 고른다.
- 요금제: 월 $100(Claude Max 5x 또는 ChatGPT Pro 100)으로 시작하고, 한도에 자주 걸리면 $200으로 올린다.
  - Claude Pro($20)는 Fable 5.1이 기본 한도에 포함되지 않고 사용량 크레딧으로 따로 과금된다. Max는 주간 한도의 절반까지 Fable을 쓸 수 있다.
  - ChatGPT Plus($20)는 Astra 사용량이 적다. Pro 100/200은 코덱스 한도 안에 Astra가 포함된다.
- API를 개발 도구로 직접 쓰지 않는다. Fable 5.1과 GPT-6 Astra 모두 입력 100만 토큰당 $10, 출력 $50이라, 매일 에이전트로 코딩하면 월 $300~1,000 이상이 될 수 있다.
- 모델 사용 원칙:

| 작업 | 모델 수준 |
|---|---|
| 전체 구조 설계, 전투 AI, 밸런스 공식, 원인 불명 버그 | 최상위 (Fable 5.1 / Astra) |
| 기능 구현, 리팩터링, 테스트 작성 | 중상위 (Opus 5.5 등) |
| 코드 탐색, 데이터 파일(JSON) 작성, 문자열 정리 | 경량 (Sonnet 5.5 / Haiku 5.5 등) |

- 자동 분배: 구현 리포지터리에 작업 성격별 서브에이전트를 정의해 모델을 고정한다(Claude Code는 `.claude/agents/*.md`의 `model` 항목).
- 개발 절차: 구현 리포지터리에 sik-sdd-foundation을 설치하고, 이 아이디어 리포지터리의 공통 지침과 게임 기획서를 참조해 요구사항 후보를 구현 리포지터리의 요구사항 정의서로 옮겨 시작한다.

### 게임 데이터 제작에 쓰는 AI (API)

- 다국어 1차 번역, 대사·NPC 대화 초안, 스토어 문구 현지화.
- 대량 작업은 **Message Batches API**(비동기 일괄 처리, 50% 할인, 보통 24시간 안에 결과)로 돌리고, 저렴한 모델(Sonnet 5.5, Haiku 5.5)을 쓴다.
- 이 비용은 개발 도구 요금제와 별개로 잡는다.

## 6. 아트 파이프라인

| 용도 | 도구와 방식 |
|---|---|
| 도트: 필드 타일셋, 캐릭터 4방향 이동·공격·회피·스킬·피격 동작, 턴제 전투 유닛 | 도트 전용 생성기(예: PixelLab, 월 $12부터)로 초안 + 사람이 보정 |
| 일러스트: 초상화, 스탠딩, 1:1 대결 컷인, 획득 연출 | 캐릭터 일관성 기능이 있는 이미지 생성 모델로 초안. 핵심 캐릭터(기본 제공 3명, 주요 보스)는 일러스트레이터 작업 검토 |
| 홍보 영상, 트레일러 | 영상 생성 도구(예: Higgsfield). 출시 직전에만 필요 |

- 표현 모드(기본 골격 §7)에 따라 **일러스트와 도트를 모두 2벌**(오리지널, 재해석) 만든다. 캐릭터 수를 정하기 전에, 첫 개발 범위의 캐릭터 3명으로 1명당 실제 제작 시간을 잰다.
- 도트 그래픽은 정수 배율로만 확대해야 깨지지 않는다.

## 7. 출시 체크리스트

과금 관련 법규(확률 공개, 청약철회, 국가별 랜덤박스 규제, 광고 동의)는 과금 지침을 따른다.

- 연령 등급:
  - IARC 등급(Google Play), App Store 연령 등급 설문, 국내 게임물관리위원회 자체등급분류(오픈마켓 사업자).
  - 등급은 두 표현 모드 중 더 높은 쪽 기준으로 받는다. 재해석 모드의 노출 수위는 12세 이용가 수준으로 관리한다.
- 개인정보 처리방침 URL을 스토어에 등록한다.
- 출시 국가: 중국 본토는 판호(출판 허가)가 필요하므로 제외한다.
- 사업자와 신고 (국내): 사업자등록과 통신판매업 신고. 게임산업법상 게임제작업·배급업 등록 대상인지 확인한다.
- 스토어 개발자 계정:
  - Google Play: 등록비 1회 $25. 신규 개인 계정은 프로덕션 출시 전에 비공개 테스트(일정 인원 이상, 14일 이상)가 필요하다. 현재 인원 기준을 확인하고 일정에 넣는다.
  - Apple Developer Program: 연 $99.
  - 수수료: 두 스토어 모두 소규모 개발자 프로그램 신청 시 연 매출 100만 달러까지 15%.
  - 스팀: 앱당 등록비 $100(매출 $1,000 이후 환급), 수수료 30%. AI 생성 콘텐츠를 썼다면 상점 페이지에 공개한다.
- 제목과 상표: 출시 국가별로 상표 검색을 하고 고유한 제목을 짓는다.
- 오마주 대상의 권리: 참고한 게임(기본 골격 §1)의 에셋, 이름, 홍보 문구를 쓰지 않았는지 출시 전에 확인한다.
- 아트 권리:
  - 외주 일러스트는 계약서에 저작권 양도(또는 독점 이용 허락)와 2차 활용(스킨, 굿즈, 홍보) 범위를 명시한다.
  - AI 생성 이미지는 사용한 도구의 상업 이용 약관을 확인하고 생성 기록(프롬프트, 날짜)을 보관한다.
- 기기 대응: 저사양 Android(램 3~4GB), 다양한 화면비(노치, 폴더블, 태블릿)에서 테스트한다. 액션 조작은 60fps를 목표로 한다.
- 보안: 결제 검증 키와 서버 비밀값은 코드 저장소에 넣지 않는다. AI 코딩 도구에 비밀값이 든 파일을 읽히지 않는다.
- 운영 비용: 서버, 도메인과 개인정보 처리방침 페이지, 번역 검수 비용을 월 고정비로 잡는다.
- 광고 수익: 국가별 광고 단가 차이가 크다(한국·미국·일본이 높고 동남아·남미가 낮음). 소프트 런칭 국가를 고를 때 함께 본다.

## 8. 개발 단계

1. **프로토타입 (턴제 전투)**: 맵 1개, 기본 제공 캐릭터 3명 vs 적 3명. 이동, 전투 계산, 병종 상성, 턴 제한, 승리 조건, 되감기까지. 다국어 키 구조는 이 단계부터 적용한다.
2. **수직 슬라이스 (세 모드 통합)**: 필드 1개 지역(화면 8~10장) + 작은 던전 1개(화면 5장, 퍼즐 3개, 도구 1개) + 턴제 전투 1개 + 1:1 대결 1개 + 조작 캐릭터 3명. 세 모드를 오가는 흐름, 재미, 제작 속도(화면 1장당 레벨 디자인 시간, 캐릭터 1명당 아트 시간)를 확인하고 전체 분량을 정한다.
3. **1장 완성**: 1장 필드 전체와 스테이지(기본·어려움), 메뉴, 캐릭터 성장, 보스 획득, 대화와 선택, 한국어·영어.
4. **수익화와 메타**: 과금 지침 구현(광고, 30일 패스, 영구 광고 제거, 재화 충전, 환불 처리), 뽑기, 장비, 강화, 계정 성장, 도전과제, 서버 영수증 검증, 클라우드 저장.
5. **소프트 런칭**: 1~3장, 1차 언어 4개. 일부 국가에 먼저 출시해 이탈률, 광고 수익, 난이도, 과금·무과금 클리어율 격차를 측정한다.
6. **글로벌 출시**: 2차 언어, 장 추가 업데이트, 분기 스토리와 특수 스테이지 확대.
7. **스팀판**: 모바일 출시 후. 과금 지침 "스팀(PC)판" 적용, 키보드·게임패드 조작 다듬기, 스팀 클라우드.
