# 스타 그리드 RPG (가칭)

> 한 줄 요약: 은하 전쟁 속 독립 함대의 지휘관과 파일럿들을 이끄는 가로 화면 도트 탑뷰 SF RPG. 우주 정거장과 행성을 탐험하고, 함대전은 격자 턴제 전략으로, 에이스 파일럿 대결은 1:1 액션으로 치른다.

- 카테고리: game
- 상태: 아이디어
- 작성일: 2026-11-02
- 구현 리포지터리: -
- 따르는 공통 지침 (구현 리포지터리는 이 아이디어 리포지터리의 아래 문서들을 참조한다):
  - **스테이지 기반 전략 게임 기본 골격** (`game/stage-strategy-framework/README.md`): 게임 규칙 전부.
  - **게임 개발 공통 과금 지침** (`game/monetization-guideline/README.md`): 재화, 가격, 뽑기, 광고, 환불.
  - **게임 개발·출시 공통 지침** (`game/dev-release-guideline/README.md`): 엔진, 서버, 다국어, 아트·사운드, 출시.
- 이 문서에는 SF 우주전쟁 테마 데이터만 적는다.

## 컨셉

- 거대 제국과 연합 사이에서 살아남으려는 독립 함대의 이야기. 모든 인물과 세계관은 창작이다.
- 필드는 우주 정거장 내부, 사막 행성, 얼음 위성, 폐선 잔해. 에어록, 중력 스위치, 전력 회로 퍼즐.
- 턴제 전투는 우주 공간 격자에서 함선 단위로 싸운다. 승리 조건 기본형 "요새 함락"은 "적 기함 또는 요새 위성 격파"다.
- 1:1 대결은 에이스 파일럿끼리의 기체 대결이다.

## 스토리와 장 구성 (예시)

| 장 | 이야기 | 필드 | 턴제 전투 보스 | 1:1 에이스 대결 |
|---|---|---|---|---|
| 1장 | 탈출 | 포위된 정거장 | 제국 순찰대 | - |
| 2장 | 사막 행성 | 사막 행성 도시 | 해적 두목 | 해적 에이스 |
| 3장 | 얼음 위성 | 연구 기지 | 탈주 전투 로봇 | - |
| 4장 | 성운의 함정 | 폐선 잔해 | 제국 기동함대 | 제국 에이스 |
| 5장 | 수도 성계 | 제국 요새 | 제국 제독 | 제독의 호위 에이스 |

- 필드 도구: 중력 장갑(밀기·당기기), 추진 부츠(뛰어넘기), 견인 빔(끌어당기기), 폭파 장치(부수기).
- 적장(공용 일러스트 예): 제국 장교, 해적 선장, 로봇 지휘 유닛, 현상금 사냥꾼, 외계 족장, 정보 요원.
- 인연 예: "첫 출항"(함장, 에이스 파일럿, 기관장), "그림자 작전"(해커, 외계인 용병, 에이스 파일럿).

## 저작권 준수 (절대 준수)

기본 골격 §1 "저작권·상표 준수"(절대 규칙, 지침 예외 불가)를 따른다. 이 테마에서 특히 지킬 내용:

- 원전: 원전 없음. 세계관, 인물, 함선, 종족을 모두 창작한다.
- 유명 SF 작품(스타워즈, 건담, 스타크래프트, 매스 이펙트, 스타트렉 등)의 고유 요소를 쓰지 않는다. 예: "포스" 같은 신비한 힘, 광선검, 인간형 거대 로봇 디자인, 특정 종족과 함선 디자인과 이름.
- 공격 유형 "에너지 블레이드"는 손잡이에서 빛나는 칼날이 나오는 형태를 피하고, 독자적인 무기 형태로 디자인한다.
- 의심되는 디자인과 이름은 쓰지 않는다.
