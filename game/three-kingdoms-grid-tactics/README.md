# 삼국지 그리드 RPG

> 한 줄 요약: 피처폰 RPG의 감성을 담은 가로 화면 도트 쿼터뷰 RPG. 유비·관우·장비와 퍼즐·몰이사냥을 풀고 도구·보조장비·장수를 얻어 1:1 액션 일기토 보스에 도전한다. 격자 턴제72개를 스토리 필수 전투로 진행하며, 직접 또는 광고 보상 AI 자동 전투를 선택한다. 장수 디자인은 오리지널과 미녀 재해석 중에서 고를 수 있다.

## 배경 / 문제

- 피처폰 시절에 즐기던 턴제 삼국지 게임은 한 판이 짧고 규칙이 단순한데도 수 싸움이 깊었다.
- 요즘 모바일 전략 게임은 성장·과금 압박이 무겁고, 필드를 탐험하는 재미와 턴제 수 싸움을 함께 주는 게임이 드물다.
- 원작은 지금 실행할 수 없으므로 기억나는 규칙을 바탕으로 새로 만들고, 「젤다의 전설: 꿈꾸는 섬」식 필드 모험을 더해 전 세계에 출시한다.

## 원작에서 기억하는 규칙

원작에서 가져온 규칙과, 그것이 공통 지침의 어디에 반영됐는지:

| 원작 규칙 | 반영 위치 |
|---|---|
| 격자 맵 턴제 전투, 장수마다 다른 기동력 | 기본 골격 §6 턴제 전투, §7 능력치 |
| 적과 마주치면 보유 군사력(병력)을 소모하며 전투 | 기본 골격 §6 병력, 전투 계산 |
| 장수를 전진시켜 적 요새를 공략 | v19에서는 기본 골격 §6의 거점 버프 제거·적 전멸 승리로 변경 |
| 턴 제한 (게임 안에서는 "전투 N일차 / 제한 M일") | 기본 골격 §6 턴 표시, 이 문서 "명칭" |
| 병과별 일반공격 범위/상성과 스킬별 범위/효과 | 기본 골격 §6 범위 공격과 스킬 |
| 일기토 | 기본 골격 §5 1:1 대결, 이 문서 "일기토 지점" |
| 대기실에서 장수 성장 | 기본 골격 §7 성장, §9 계정 성장 |
| 삼국지 스토리, 분기점, 특수 스테이지, `1-1, 1-2…` 진행 | 기본 골격 §2, 이 문서 "스토리와 장 구성" |

## 목표

- 필드 탐험의 재미(퍼즐, 숨은 길, NPC 선택)와 피처폰 삼국지의 턴제 수 싸움을 함께 준다.
- 삼국지를 잘 모르는 서구권 플레이어도 대화와 인물 소개 카드(기본 골격 §11)로 스토리를 따라올 수 있게 한다.
- 플레이 시간, 무과금 클리어 같은 공통 목표는 기본 골격 §2와 과금 지침을 따른다.

## 범위 밖 (Non-goals)

- 원작 게임의 이름, 그래픽, 음원 등 저작물 복제. 규칙과 분위기만 참고하고 에셋은 새로 만든다.
- 그 밖의 범위 밖(PvP, 내정·외교 등)은 기본 골격 §1 "기본 범위 밖"을 따른다.

## 사용자 / 사용 시나리오

1. 첫 실행 때 언어와 **장수 디자인(오리지널 / 미녀 재해석)**을 고른다. 도원결의 프롤로그 뒤에 유비·관우·장비와 함께 탁현 마을 필드에서 시작한다.
2. 마을 사람과 대화해 황건적 소식을 듣고, 철갑 장갑으로 길을 막은 바위를 밀어 숨은 길을 찾고, 황건적 잔당을 모아 공격·회피·일반스킬·궁극기로 물리친다. 관우(근접)와 유비(활)를 상황에 맞게 바꿔 조작한다.
3. 봉화대에 봉화를 올려 체력을 회복하고 워프 지점을 연다.
4. 황건적 산채의 필수 전투 지점에서 직접 전투 또는 광고 보상 AI 자동 전투를 선택한다. 패배하면 다시 도전하며 승리해야 연결된 이야기가 진행된다. 관우(기병), 장비(보병), 유비(궁병)가 각자 이동1회와 공격행위1회를 쓴다. 적 칸에 들어가지 않고 병과 일반공격 범위 또는 장수별 일반스킬·궁극기 범위의 적들을 한 번에 타격한다. 필드와 같은 이름의 두 스킬을 턴 쿨다운으로 재사용하며, 포로가 된 아군은 옆으로 가서 병력을 나눠 구출한다. 아군 막사와 적 성/막사 주변 공격 버프를 활용한다. 적 거점을 먼저 부숴 주변 적을 약화시키거나, 거점을 남긴 채 적을 전멸시켜 승리한다.
5. 2장 사수관 앞에서 관우가 화웅과 일기토를 벌인다. 잡몹이 없는 1:1 전장에서 직접 조작해 싸운다.
6. 퍼즐·사냥·일기토 목표로 경험치와 도구·보조장비를 얻고, 장 메인 완료로 보상 장수 1명을 얻는다. 필수 턴제 실패는 되감기(기본 3회, 어려움 1회)를 쓰거나 종료해 필드로 돌아간다.
7. 장수나 NPC와 대화하면 양옆에 두 인물의 일러스트가 나오고, 가운데에 채팅처럼 말풍선이 쌓인다. 3장 끝에서는 "서주를 지킬 것인가, 원소에게 의탁할 것인가" 같은 선택으로 다음 장 경로가 갈린다.

## 표현 모드 컨셉

| 모드 | 디자인 |
|---|---|
| 오리지널 | 원래 인물(남성 무장) 그대로. 연의 속 이미지(관우의 붉은 얼굴과 긴 수염, 장비의 고리눈 등)를 도트와 일러스트에 살린다 |
| 미녀 재해석 | 원래 인물의 관념적 특징과 분위기(관우의 위엄과 충의, 장비의 호쾌함, 제갈량의 지략)를 살려 미녀로 여성화. 노출 수위는 15세 이용가(Teen) 수준 |

- 출시 후 스킨은 미녀 재해석 모드 전용이다(과금 지침).

- **재해석 대사 톤** (기본 골격 §7 "대사 두 벌"): 유비는 다정한 맏언니, 장비는 술 좋아하는 털털한 막내(개그 담당), 조운은 성실한 모범생. 의형제는 의자매, 형님은 언니로 부른다.
- **개그 제외 인물**: 관우(관제 신앙), 제갈량.

### 재해석 대사 예시

AI가 재해석 대사 초안을 쓸 때의 톤 기준이다. 같은 장면을 두 모드로 나란히 적는다.

**프롤로그 도원결의**: 맹세는 진지하게, 끝에 개그 한 마디.

| 오리지널 | 재해석 |
|---|---|
| **유비**: 나라가 어지럽고 백성이 고통받는데, 이 몸 하나로는 아무것도 할 수 없구려. | **유비**: 백성들이 이렇게 힘든데… 나 혼자서는 아무것도 못 하겠어. |
| **장비**: 그럼 나와 함께하면 되지 않소! 내 집 뒤에 복숭아밭이 있으니 술 한잔하며 의논합시다! | **장비**: 그럼 같이 하면 되지! 우리 집 뒤에 복숭아밭 있거든? 거기서 한잔하면서 얘기하자! |
| **관우**: …천하를 위한 뜻이라면, 이 관우도 함께하겠소. | **관우**: …천하를 위한 뜻이라면, 나도 함께하지. |
| **유비**: 비록 같은 날 태어나지 못했으나, 같은 날 죽기를 원하오. | **유비**: 같은 날 태어나진 않았지만, 같은 날 죽기를 바라. |
| **장비**: 형님들, 오늘부터 우리는 형제요! | **장비**: 좋아, 오늘부터 우리는 의자매야! …근데 누가 언니야? |
| | **유비**: (웃으며) 나이순으로 하자. |
| | **장비**: 으악, 그럼 내가 막내잖아! |

**2장 사수관**: 개그 제외 인물(관우)은 개그를 하지 않고 반응만 한다.

| 오리지널 | 재해석 |
|---|---|
| **조조**: 출전 전에 이 술을 드시오. | **조조**: 이 술 한잔하고 가. |
| **관우**: 잠시 두시오. 곧 돌아와 마시겠소. | **관우**: 거기 둬. 금방 올게. |
| (화웅을 베고 돌아와) **관우**: 술은 아직 따뜻하구려. | (화웅을 베고 돌아와) **관우**: 아직 따뜻하네. |
| | **장비**: 잠깐, 그 사이에 내가 반 마셨는데? |
| | **관우**: …(말없이 장비를 본다) |
| | **장비**: 아, 아니… 따뜻하게 지켜 둔 거야! |

**6장 삼고초려**: 제갈량은 품위 있게, 개그는 장비가.

| 오리지널 | 재해석 |
|---|---|
| **장비**: 형님, 촌구석 서생을 세 번이나 찾아가다니요! 불이라도 질러 끌어낼까요? | **장비**: 언니, 벌써 세 번째야! 낮잠 자는 사람 깨우려고 이렇게까지 해야 돼? 문 확 열어 버릴까? |
| **유비**: 아우는 무례하게 굴지 마라. | **유비**: 장비야, 예의 지켜. |
| | **장비**: (작게) …나도 낮잠 자고 싶다. |
| **제갈량**: 장군의 뜻이 그토록 깊으니, 이 몸이 힘을 다하겠습니다. | **제갈량**: 세 번이나 찾아와 주신 그 마음, 가볍게 여기지 않겠습니다. 천하를 셋으로 나누는 계책을 말씀드리지요. |

### 첫 필드 사냥·보조장비 시안

- 1장 황건적 무리: 근접 잔당을 모으고 궁병 견제를 회피하면서 관우의 전방 베기·장비의 주변 밀치기로 공간을 만든다. 동시 8~12명은 첫 성능/체감 검수 수치이며 확정 배치가 아니다.
- 철갑 장갑은 기존 퍼즐 도구다. 별도 보조장비 **행군 각반**(가칭)은 1장 필수 사냥 목표 완료 시 확정 지급하는 초안이며, 회피 후 짧은 이동 보조로 몰이 위치 선정을 돕는다. 추가 스킬 버튼을 만들지 않으며 페어 장비와 별도 슬롯을 사용한다. 효과 수치는 플레이 검수 대상이다.
- 완료한 사냥 목표의 보조장비를 다시 지급하지 않는다. 이 사냥 보상을 별도의 턴제 보상이나 무작위 드롭으로 바꾸지 않는다.

## 인연 (기본 골격 §10 인연 도전과제)

규칙(보상, 버프 크기, 일본 처리, 구성 원칙)은 기본 골격 §10을 따르고, 여기에는 삼국지 장면과 장수 조합만 적는다. 장수 목록이 확정되면 장면마다 정한다.

| 인연 (장면) | 장수 3명 | 버프 (상황: 효과) |
|---|---|---|
| 도원결의 | 유비, 관우, 장비 | 1장 스테이지에서: 아군 공격력 +5% |

- 첫 인연은 도원결의(기본 제공 세 장수)다.
- 장면 일러스트 예: 복숭아 동산의 맹세, 사수관 앞의 술잔, 장판교 위의 장비, 융중 초가의 세 번째 방문.

## 테마 고유 시스템

기본 골격 §1 "테마 고유 시스템"에 따라, 골격 규칙 위에 얹는 이 게임만의 시스템이다. 스토어 스크린샷·영상 앞쪽과 심사 메모에 이 시스템을 보여 준다(개발·출시 지침 "시리즈 출시 원칙").

| 시스템 | 어디서 | 규칙 | 처음 나오는 장 |
|---|---|---|---|
| 계략 | 필드 퍼즐·사냥 + 필수 턴제 | 필드에서는 횃불·수문·은폐 지점을 조작해 적을 유인하고 지형을 활용한다(별도 캐릭터 스킬 슬롯 아님). 필수 턴제에서도 지형 장치를 조작하는 맵 상호작용이다(캐릭터별 세 번째 능력 아님, 공격행위 슬롯1회 소비·장치당 전투1회 제안). 화공(숲·초원 칸에 불, 2턴 지속 피해), 수공(강 옆 칸 범람, 이동 봉쇄), 매복(숲에 숨긴 부대가 첫 범위 공격에 추가 효과) | 1장 (화공 본격 활용은 6장 박망파) |
| 일기토의 기세 | 1:1 → 필드 사냥 + 필수 턴제 | 일기토 승리 뒤 그 장의 다음 필드 사냥 무리에서 공격력이 오른다(제안 +5%, 조우 완료 시 소모). 필수 턴제용 별도 1회 효과도 둘 수 있다. 지면 효과 없음. 저장·재입장으로 중복 충전하지 않는다. 연의처럼 장수의 승부가 전투의 흐름을 바꾼다 | 2장 |

## 저작권 준수 (절대 준수)

기본 골격 §1 "저작권·상표 준수"(절대 규칙, 지침 예외 불가)를 따른다. 이 테마에서 특히 지킬 내용:

- 원전: 정사 「삼국지」와 소설 「삼국지연의」(공유 저작물). 인물 이름, 사건, 일화는 여기서만 가져온다.
- 현대 삼국지 작품(코에이 「삼국지」·「진·삼국무쌍」 시리즈, 요코야마 미쓰테루 만화, 「창천항로」, 드라마·영화 「적벽대전」 등)의 캐릭터 디자인, 각색 설정, 창작 인물, 대사를 쓰지 않는다.
- 원작 피처폰 게임의 이름, 그래픽, 음원, 맵, 문장을 쓰지 않는다(범위 밖). 규칙과 분위기만 참고한다.
- 제목과 상표는 아래 "테마별 출시 위험"의 상표 검색을 따른다.
- 코에이 테크모의 "無双(무쌍)" 계열 상표와 겹치지 않게 스킬·상품 이름에 "무쌍"을 쓰지 않는다(여포 스킬은 "방천 난무").
- 의심되는 디자인과 이름은 쓰지 않는다.

## 테마별 출시 위험

- **남중(남만) 묘사**: "남만"은 "남쪽 오랑캐"라는 뜻이라 화면에는 지명 "남중"을 쓴다. 맹획·축융과 남중 사람들은 고유 문화를 가진 왕국으로 디자인하고, 원시인 분장이나 짐승 같은 모습으로 그리지 않는다.
- 제목: "삼국지 그리드 RPG"처럼 다른 단어와 결합해도 "삼국지(三國志)"가 들어간 상표는 기존 게임사 상표와 충돌할 수 있다(특히 일본). 한국·일본·대만·미국에서 상표 검색을 하고, 문제가 없으면 게임 이름을 상표로 출원한다. 일본은 "志"를 뺀 이름(三国グリッドRPG)을 기본안으로 둔다.
- 미녀 재해석: 중화권 일부에서는 역사 인물 여성화에 거부감이 있을 수 있다. 오리지널 모드를 기본 선택지로 함께 보여 준다.
- 관우는 중화권에서 관제(關帝)로 신앙 대상이기도 하다. 재해석 디자인과 대사에서 희화화하거나 성적으로 표현하지 않는다.
- 인지도 차이: 서구권은 삼국지 인지도가 낮다. 인물 소개 카드(기본 골격 §11)의 문구를 서구권 기준으로 쓰고, 도원결의 프롤로그에서 세 인물의 관계를 먼저 보여 준다.

## 열린 질문 / 리스크

- 원작 피처폰 게임의 이름은 기억나지 않는다. 원작의 이름, 그래픽, 음원, 맵, 문장을 쓰지 않고 규칙과 분위기만 참고하므로 출시에 지장은 없다. 출시 전에 화면과 문구가 특정 옛 게임을 그대로 닮지 않았는지만 확인한다.
- 출시 장수 수: 수직 슬라이스에서 장수 1명당 아트 제작 시간을 잰 뒤(개발·출시 지침 §6) 정한다.
- 여포처럼 능력치가 극단적인 장수를 뽑기로 초반에 얻을 때의 밸런스(과금 지침 열린 질문의 삼국지 사례).
