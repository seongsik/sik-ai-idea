# 삼국지 그리드 RPG

> 한 줄 요약: 피처폰 시절 턴제 삼국지 게임을 되살린 가로 화면 도트 탑뷰 RPG. 유비·관우·장비와 함께 필드를 모험하고(퍼즐, NPC, 액션 전투), 삼국지연의의 핵심 전투는 격자 턴제 전략으로, 일기토는 1:1 액션 대결로 치른다. 장수 디자인은 오리지널과 미녀 재해석 중에서 고를 수 있다.

## 배경 / 문제

- 피처폰 시절에 즐기던 턴제 삼국지 게임은 한 판이 짧고 규칙이 단순한데도 수 싸움이 깊었다.
- 요즘 모바일 전략 게임은 성장·과금 압박이 무겁고, 필드를 탐험하는 재미와 턴제 수 싸움을 함께 주는 게임이 드물다.
- 원작은 지금 실행할 수 없으므로 기억나는 규칙을 바탕으로 새로 만들고, 「젤다의 전설: 꿈꾸는 섬」식 필드 모험을 더해 전 세계에 출시한다.

## 원작에서 기억하는 규칙

원작에서 가져온 규칙과, 그것이 공통 지침의 어디에 반영됐는지:

| 원작 규칙 | 반영 위치 |
|---|---|
| 격자 맵 턴제 전투, 장수마다 다른 기동력 | 기본 골격 §6 턴제 전투, §7 능력치 |
| 적과 마주치면 보유 군사력(병력)을 소모하며 전투 | 기본 골격 §6 병력, 전투 계산 |
| 장수를 전진시켜 적 요새를 함락하면 승리 | 기본 골격 §6 승리 조건 기본형 |
| 턴 제한 (게임 안에서는 "전투 N일차 / 제한 M일") | 기본 골격 §6 턴 표시, 이 문서 "명칭" |
| 상성 관계 | 기본 골격 §6 병종 |
| 일기토 | 기본 골격 §5 1:1 대결, 이 문서 "일기토 지점" |
| 대기실에서 장수 성장 | 기본 골격 §7 성장, §9 계정 성장 |
| 삼국지 스토리, 분기점, 특수 스테이지, `1-1, 1-2…` 진행 | 기본 골격 §2, 이 문서 "스토리와 장 구성" |

## 목표

- 필드 탐험의 재미(퍼즐, 숨은 길, NPC 선택)와 피처폰 삼국지의 턴제 수 싸움을 함께 준다.
- 삼국지를 잘 모르는 서구권 플레이어도 대화와 인물 소개 카드(기본 골격 §11)로 스토리를 따라올 수 있게 한다.
- 플레이 시간, 무과금 클리어 같은 공통 목표는 기본 골격 §2와 과금 지침을 따른다.

## 범위 밖 (Non-goals)

- 원작 게임의 이름, 그래픽, 음원 등 저작물 복제. 규칙과 분위기만 참고하고 에셋은 새로 만든다.
- 그 밖의 범위 밖(PvP, 내정·외교 등)은 기본 골격 §1 "기본 범위 밖"을 따른다.

## 사용자 / 사용 시나리오

1. 첫 실행 때 언어와 **장수 디자인(오리지널 / 미녀 재해석)**을 고른다. 도원결의 프롤로그 뒤에 유비·관우·장비와 함께 탁현 마을 필드에서 시작한다.
2. 마을 사람과 대화해 황건적 소식을 듣고, 철갑 장갑으로 길을 막은 바위를 밀어 숨은 길을 찾고, 황건적 잔당을 공격·회피·스킬로 물리친다. 관우(근접)와 유비(활)를 상황에 맞게 바꿔 조작한다.
3. 봉화대에 봉화를 올려 체력을 회복하고 워프 지점을 연다.
4. 황건적 산채에 도착하면 격자 턴제 전투가 시작된다. 가위바위보로 선공을 정하고, 캠프 주변에 흩어진 관우(기병), 장비(보병), 유비(궁병)를 움직인다. 적 칸에 들어가면 공격·스킬·방어·퇴각 중 하나를 골라 수 싸움을 하고, 포로가 된 아군은 옆으로 가서 병력을 나눠 구출한다. 제한 일수 안에 산채를 함락하면 이긴다.
5. 2장 사수관 앞에서 관우가 화웅과 일기토를 벌인다. 잡몹이 없는 1:1 전장에서 직접 조작해 싸운다.
6. 이기면 장수 레벨이 오르고 보석과 보스 장수를 얻는다. 지면 되감기(기본 3회, 어려움 1회)를 쓰거나 실패로 끝낸다.
7. 장수나 NPC와 대화하면 양옆에 두 인물의 일러스트가 나오고, 가운데에 채팅처럼 말풍선이 쌓인다. 3장 끝에서는 "서주를 지킬 것인가, 원소에게 의탁할 것인가" 같은 선택으로 다음 장 경로가 갈린다.

## 스토리와 장 구성

프롤로그 + 12장. 장마다 턴제 6개(마지막이 보스전) + 일기토 2개. 유비 진영 시점으로 도원결의부터 오장원까지. 장 보상은 장마다 1명이고, 나머지 장수는 뽑기로 얻는다. 아직 없는 장수가 스토리에 동료로 나오면 그 스테이지에서만 게스트로 출전한다(기본 골격 §7).

## 적장 일러스트

턴제 전투의 적 장수(기본 골격 §6)는 아래 공용 일러스트 8종을 돌려 쓰고, 이름과 대사만 바꾼다. 각 종은 오리지널(남성 무장)과 미녀 재해석 두 벌이다. 스토리 보스(장각, 화웅, 여포 등)는 전용 일러스트를 쓴다.

| 종류 | 분위기 | 주로 나오는 장 (예시) |
|---|---|---|
| 황건 두목 | 누런 두건, 거친 산적풍 | 1장 |
| 서량 기병장 | 털가죽, 기마 무장 | 2~3장 |
| 동탁군 맹장 | 중갑, 위압적 | 2장 |
| 원소군 장수 | 화려한 명문가 갑옷 | 4장 |
| 조조군 장수 | 실용적인 흑색 갑옷 | 4~12장 |
| 손권군 수군장 | 경갑, 수군 복장 | 7장, 11장 |
| 노장 | 백발, 노련한 지휘관 | 전 장 |

- 이름 예시: "황건 두목 정원지", "동탁군 장수 호진". 첫 교전 대사 예시: "유비 따위가 감히!"

## 인연 (기본 골격 §10 인연 도전과제)

규칙(보상, 버프 크기, 일본 처리, 구성 원칙)은 기본 골격 §10을 따르고, 여기에는 삼국지 장면과 장수 조합만 적는다. 장수 목록이 확정되면 장면마다 정한다.

| 인연 (장면) | 장수 3명 | 버프 (상황: 효과) |
|---|---|---|
| 도원결의 | 유비, 관우, 장비 | 1장 스테이지에서: 아군 공격력 +5% |
| 사수관의 술잔 | 관우, 화웅, 유비 | 일기토에서: 공격력 +5% |
| 호뢰관 삼영전 | 여포, 관우, 장비 | 기병과 교전할 때: 받는 피해 -5% |
| 장판파 | 조운, 장비, 유비 | 다리·강 지형에서 교전할 때: 방어력 +5% |
| 삼고초려 | 유비, 제갈량, 관우 | 턴제 전투에서 스킬을 쓸 때: 스킬 효과 +5% |
| 적벽대전 | 제갈량, 감녕, 유비 | 강에 맞닿은 칸에서 교전할 때: 주는 피해 +5% |
| 황건적의 난 | 장각, 유비, 관우 | 보병과 교전할 때: 주는 피해 +5% |

- 첫 인연은 도원결의(기본 제공 세 장수)다.
- 장면 일러스트 예: 복숭아 동산의 맹세, 사수관 앞의 술잔, 장판교 위의 장비, 융중 초가의 세 번째 방문.
- 장수 목록이 늘면 손권군·조조군 장수가 들어간 인연(예: 적벽의 주유·황개·제갈량)을 추가한다.

## 저작권 준수 (절대 준수)

기본 골격 §1 "저작권·상표 준수"(절대 규칙, 지침 예외 불가)를 따른다. 이 테마에서 특히 지킬 내용:

- 원전: 정사 「삼국지」와 소설 「삼국지연의」(공유 저작물). 인물 이름, 사건, 일화는 여기서만 가져온다.
- 현대 삼국지 작품(코에이 「삼국지」·「진·삼국무쌍」 시리즈, 요코야마 미쓰테루 만화, 「창천항로」, 드라마·영화 「적벽대전」 등)의 캐릭터 디자인, 각색 설정, 창작 인물, 대사를 쓰지 않는다.
- 원작 피처폰 게임의 이름, 그래픽, 음원, 맵, 문장을 쓰지 않는다(범위 밖). 규칙과 분위기만 참고한다.
- 제목과 상표는 아래 "테마별 출시 위험"의 상표 검색을 따른다.
- 의심되는 디자인과 이름은 쓰지 않는다.

## 테마별 출시 위험

- 제목: "삼국지 그리드 RPG"처럼 다른 단어와 결합해도 "삼국지(三國志)"가 들어간 상표는 기존 게임사 상표와 충돌할 수 있다(특히 일본). 한국·일본·대만·미국에서 상표 검색을 하고, 문제가 없으면 게임 이름을 상표로 출원한다. 일본은 "志"를 뺀 이름(三国グリッドRPG)을 기본안으로 둔다.
- 미녀 재해석: 중화권 일부에서는 역사 인물 여성화에 거부감이 있을 수 있다. 오리지널 모드를 기본 선택지로 함께 보여 준다.
- 관우는 중화권에서 관제(關帝)로 신앙 대상이기도 하다. 재해석 디자인과 대사에서 희화화하거나 성적으로 표현하지 않는다.
- 인지도 차이: 서구권은 삼국지 인지도가 낮다. 인물 소개 카드(기본 골격 §11)의 문구를 서구권 기준으로 쓰고, 도원결의 프롤로그에서 세 인물의 관계를 먼저 보여 준다.

## 열린 질문 / 리스크

- 원작 피처폰 게임의 이름은 기억나지 않는다. 원작의 이름, 그래픽, 음원, 맵, 문장을 쓰지 않고 규칙과 분위기만 참고하므로 출시에 지장은 없다. 출시 전에 화면과 문구가 특정 옛 게임을 그대로 닮지 않았는지만 확인한다.
- 출시 장수 수: 수직 슬라이스에서 장수 1명당 아트 제작 시간을 잰 뒤(개발·출시 지침 §6) 정한다.
- 여포처럼 능력치가 극단적인 장수를 뽑기로 초반에 얻을 때의 밸런스(과금 지침 열린 질문의 삼국지 사례).
