# 격자 턴제 삼국지 공성전

> 한 줄 요약: 피처폰 시절 턴제 삼국지 게임을 되살린 것으로, 격자 맵에서 기동력이 다른 장수들을 전진시켜 군사력을 소모하며 싸우고, 제한 턴 안에 적 요새를 함락하면 이기는 가벼운 전략 게임.

- 카테고리: game
- 상태: 아이디어
- 작성일: 2026-10-31
- 구현 리포지터리: -

## 배경 / 문제

- 피처폰 시절에 즐기던 턴제 삼국지 게임은 한 판이 짧고 규칙이 단순한데도 수 싸움이 깊었다.
- 요즘 모바일 전략 게임은 과금·성장 요소가 무거워, 출퇴근길에 한 판씩 하기 좋은 담백한 전략 게임이 드물다.
- 원작은 지금 실행할 수 없으므로, 기억나는 핵심 규칙을 바탕으로 웹/모바일에서 바로 할 수 있게 새로 만든다.

## 원작에서 기억하는 핵심 규칙

이 다섯 가지는 반드시 지킨다. 나머지 규칙은 아래 "게임 규칙 구상"의 제안이며 바꿀 수 있다.

1. 턴제로 진행하고, 맵은 격자(사각형 칸)다.
2. 장수마다 기동력(한 턴에 이동할 수 있는 칸 수)이 다르다.
3. 적과 마주치면 전투가 일어나고, 각 장수가 보유한 군사력(병력)을 소모한다.
4. 장수들을 전진시켜 적 요새를 함락하면 승리한다.
5. 턴 수 제한이 있어서, 제한 안에 함락하지 못하면 패배한다.

## 목표

- 한 판 10~15분 안에 끝나는 스테이지형 턴제 전략 게임.
- 모바일 세로 화면에서 터치만으로 편하게 조작한다.
- 적 AI가 그럴듯하게 방어·반격해 매번 수 싸움이 생긴다.

## 범위 밖 (Non-goals)

- 원작의 이름, 그래픽, 음원 등 저작물 복제. 규칙과 분위기만 참고하고 에셋은 새로 만든다.
- 온라인 PvP, 과금, 가챠.
- 내정·외교 같은 대전략 요소 (전투 스테이지에만 집중).

## 사용자 / 사용 시나리오

1. 플레이어가 스테이지(예: 사수관 공략)를 고르고, 출전할 장수 3~5명을 배치한다.
2. 아군 턴에 장수를 하나씩 선택하면 이동 가능 칸이 표시되고, 이동한 뒤 인접한 적이 있으면 공격한다.
3. 적 턴에 AI가 수비·요격·요새 방어를 한다.
4. 적 요새 칸에 도달해 수비 병력을 0으로 만들면 함락, 승리.
5. 제한 턴(예: 20턴)이 지나거나 아군 장수가 모두 퇴각하면 패배.

## 게임 규칙 구상 (제안)

### 맵

- 크기는 8×12 정도의 사각 격자로, 모바일 세로 화면에 맞춘다.
- 지형마다 이동 비용과 전투 보정이 다르다.

| 지형 | 이동 비용 | 방어 보정 |
|---|---|---|
| 평지 | 1 | 0% |
| 숲 | 2 | +20% |
| 산 | 3 | +40% |
| 강 | 통과 불가 (다리만 1) | -10% |
| 성채/관문 | 1 | +30% |
| 적 요새 | 1 | +50%, 별도 수비 병력 |

### 장수 능력치

| 능력치 | 설명 |
|---|---|
| 병력 | 군사력이자 체력. 0이 되면 퇴각 |
| 무력 | 공격 피해에 영향 |
| 통솔 | 방어(받는 피해 감소)에 영향 |
| 기동력 | 한 턴 이동력 (예: 기병 6, 보병 4, 궁병 3) |
| 병종 | 기병 / 보병 / 궁병, 서로 상성이 있음 |

### 턴 진행

- 아군 페이즈에서 모든 아군 장수가 각각 한 번씩 이동한 뒤 행동하고, 이어서 적 페이즈가 진행된다. 이 한 쌍이 1턴이다.
- 행동은 공격, 대기, 요새 공격 중에서 고른다. 확장 단계에서 책략을 추가한다.
- 적의 인접 칸(ZOC, 지배 영역)에 들어가면 그 턴의 남은 이동이 끝나서, 적을 그냥 지나칠 수 없다.

### 전투

- 공격자가 먼저 피해를 주고, 방어자가 살아 있으면 반격한다. 궁병은 2칸 거리에서 공격할 수 있고, 근접 공격자에게는 반격하지 못한다.
- 피해량 계산식(초안):
  `피해 = 공격자 병력 × 0.1 × (무력 / 대상 통솔) × 상성 보정 × (1 - 지형 방어 보정)`
- 병종 상성은 기병 > 보병 > 궁병 > 기병 순으로 강하며, 유리한 쪽이 1.2배다.
- 양쪽이 서로 병력을 잃으므로, 강한 장수라도 연전하면 약해진다. 원작의 "군사력 소모" 감각을 살리는 부분이다.

### 승패 조건

- 승리: 적 요새의 수비 병력을 0으로 만든다(함락).
- 패배: 제한 턴 초과, 또는 아군 장수 전원 퇴각.
- 별 3개 평가(예시): 클리어 1개, 15턴 이내 1개, 퇴각 장수 없음 1개.

### 적 AI

- 장수마다 역할을 정한다. 수비형은 요새 주변에 머물고, 요격형은 가장 약한 아군을 노리고, 돌격형은 아군 본진을 향해 전진한다.
- 각 행동 후보에 점수를 매겨 고른다. 점수 요소는 예상 피해, 받을 반격, 지형 보너스, 요새와의 거리다.
- 난이도는 AI가 몇 수 앞을 보는지와 적 병력 배율로 조절한다.

## 기술 구상

- 플랫폼: 웹(모바일 브라우저 우선). 필요하면 PWA로 설치할 수 있게 한다.
- 언어/엔진: TypeScript와 Phaser 3. 더 가볍게 가려면 Canvas 2D만 써도 된다.
- 구조:
  - `core/`: 게임 규칙. 렌더링과 분리된 순수 로직이라 단위 테스트할 수 있다. 맵, 유닛, 이동 범위(다익스트라), 전투 계산, 턴 관리, 승패 판정을 담는다.
  - `ai/`: 적 행동 결정.
  - `scenes/`: 화면. 타이틀, 스테이지 선택, 전투, 결과.
  - `data/`: 스테이지·장수 JSON.
- 상태 관리: 게임 상태를 불변 객체로 두고, 행동은 `applyAction(state, action) → state` 형태로 처리한다. 이렇게 하면 되돌리기, 리플레이, AI 시뮬레이션에 같은 코드를 재사용할 수 있다.
- 그래픽: 도트 스타일 타일과 장수 아이콘으로 피처폰 감성을 살린다.
- 테스트: Vitest로 이동 범위, 전투 계산, 승패 판정을 단위 테스트한다.

## 구현 단계 (MVP → 확장)

1. MVP: 맵 1개에 평지와 숲만, 장수 3:3, 이동·전투·턴 제한·요새 함락까지 플레이 가능. AI는 가장 가까운 적을 공격하는 수준.
2. 지형 전체, 병종 상성, ZOC, 궁병 원거리 공격, 역할별 AI.
3. 스테이지 5개, 별 평가, 저장, 사운드.
4. 확장 후보:
   - 책략(화계, 매복)과 장수 고유 스킬
   - 아군 장수 성장
   - 일기토(장수 1:1 대결) 이벤트
   - 스테이지 에디터

## 열린 질문 / 리스크

- 원작 게임의 정확한 이름과 세부 규칙. 기억이 더 나면 "원작에서 기억하는 핵심 규칙"에 추가한다.
- 병력 소모 밸런스: 공격이 너무 유리하면 돌격만 하게 되고, 너무 불리하면 진행이 막힌다. 공식은 플레이테스트로 조정한다.
- 턴 제한의 난이도: 제한이 너무 빡빡하면 전략을 쓸 여지가 사라진다.
- 장수 이름은 역사 인물이라 사용에 문제가 없지만, 특정 상용 게임의 능력치 수치를 그대로 쓰지 않는다.
