# 와일드 웨스트 그리드 RPG (가칭)

> 한 줄 요약: 서부 개척 시대의 보안관과 총잡이들을 이끄는 가로 화면 도트 탑뷰 RPG. 사막 마을과 협곡을 탐험하고, 무법자 소굴 공략은 격자 턴제 전략으로, 정오의 결투는 1:1 액션으로 치른다.

- 카테고리: game
- 상태: 아이디어
- 작성일: 2026-11-02
- 구현 리포지터리: -
- 따르는 공통 지침 (구현 리포지터리는 이 아이디어 리포지터리의 아래 문서들을 참조한다):
  - **스테이지 기반 전략 게임 기본 골격** (`game/stage-strategy-framework/README.md`): 게임 규칙 전부.
  - **게임 개발 공통 과금 지침** (`game/monetization-guideline/README.md`): 재화, 가격, 뽑기, 광고, 환불.
  - **게임 개발·출시 공통 지침** (`game/dev-release-guideline/README.md`): 엔진, 서버, 다국어, 아트·사운드, 출시.
- 이 문서에는 서부시대 테마 데이터만 적는다.

## 컨셉

- 골드러시와 철도 시대, 무법 마을에 질서를 세우는 보안관 일행의 이야기.
- 필드는 사막 마을, 협곡, 광산, 기차역. 광산 수레 밀기, 다이너마이트로 막힌 길 뚫기, 기차 위 이동.
- 1:1 대결은 서부의 상징인 "정오의 결투"로, 공통 규칙(액션 전투)에 빨리 뽑기 연출을 더한다.
- 턴제 전투의 승리 조건 기본형 "요새 함락"은 "무법자 소굴 소탕"이다.

### 캐릭터 명단 (31명)

기마대 13, 근접 패거리 11, 사수 7. 실존 인물과 창작 인물을 섞는다. 서부 인물 대부분이 총을 쓰지만 병종과 기본 공격 유형은 따로 정한다. 무료 획득은 기본 제공 3명 + 장 보상 12명 = 15명, 나머지 16명은 뽑기로 얻는다(기본 골격 §7). 보유하지 않은 스토리 인물(제시 제임스, 빌리 더 키드 등)은 해당 스테이지에 게스트나 보스로 나온다.

- **인기 캐릭터** (뽑기 전용): 빌리 더 키드, 애니 오클리, 제시 제임스, 와일드 빌 히콕, 버치 캐시디, 바스 리브스. **최상위 2명 빌리 더 키드·애니 오클리**는 계정당 1회 직접 구매할 수 있다(과금 지침).

## 저작권 준수 (절대 준수)

기본 골격 §1 "저작권·상표 준수"(절대 규칙, 지침 예외 불가)를 따른다. 이 테마에서 특히 지킬 내용:

- 원전: 19세기 미국 서부의 실존 인물과 역사 기록(공유).
- 서부극 영화·게임(레드 데드 리뎀션, 「툼스톤」, 「석양의 무법자」 등)의 캐릭터, 설정, 대사, 음악 분위기를 닮게 하지 않는다.
- 실존 인물 외형은 사진·기록을 바탕으로 직접 디자인하고, 유명 배우의 얼굴을 닮게 하지 않는다(초상권).
- 의심되는 디자인과 이름은 쓰지 않는다.

## 테마별 출시 위험

- **아메리카 원주민 묘사**: 원주민을 적이나 고정관념으로 그리지 않는다. 원주민 인물은 플레이 캐릭터(뽑기 판매 대상)로 넣지 않고, 스토리에서 존중하는 NPC로만 등장시킨다. 신성한 상징을 장식으로 쓰지 않는다.
- **멕시코계 묘사**: 10장 국경의 악역은 미국인 무법자로 하고, 멕시코계 인물(로사)은 아군으로 그린다.
- **영화 이미지**: 버치 캐시디·선댄스 키드 등 영화로 유명한 실존 인물은 영화 속 모습이 아니라 사진과 기록을 바탕으로 디자인한다.
- 총기 표현은 15세 이용가(Teen)를 지키도록 사실적인 부상 묘사를 피한다.

## 열린 질문

- 정오의 결투에 "빨리 뽑기" 연출을 넣을 때, 공통 규칙(필드와 같은 액션 전투)에 테마 연출만 더하는 선에서 할지.
