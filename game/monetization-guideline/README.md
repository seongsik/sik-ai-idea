# 게임 개발 공통 과금 지침

> 한 줄 요약: 내가 만드는 모든 모바일 게임에 공통으로 적용하는 재화·결제·광고·랜덤박스 규칙. 개별 게임 기획서는 이 지침을 따르고, 게임별 명칭과 랜덤박스 결과물만 정의한다.

- 카테고리: game
- 문서 유형: 공통 지침 (개별 아이디어가 아님)
- 작성일: 2026-11-01
- 적용 대상: 개별 게임 기획서가 "게임 개발 공통 과금 지침을 따른다"고 명시한 모든 게임

## 이 지침의 사용법

- 개별 게임 기획서에는 과금 규칙을 다시 쓰지 않는다. 기획서에는 아래 "게임별로 정의할 항목"만 채운다.
- 구현 리포지터리로 가져갈 때는 이 문서와 게임 기획서를 함께 복사한다.
- 지침과 게임 기획서가 충돌하면 지침이 우선한다. 예외가 필요하면 게임 기획서에 "지침 예외"로 명시하고 이유를 적는다.

## 원칙

1. **과금 없이 클리어할 수 있어야 한다.** 모든 콘텐츠는 플레이어의 숙련도, 게임 이해도, 운용 전략만으로 충분히 클리어할 수 있는 난이도로 만든다. 과금은 시간 단축과 편의, 수집의 즐거움을 위한 것이지 진행 조건이 아니다.
2. **단순하고 투명하게 운영한다.** 재화는 하나, 가격은 고정 비율로 정하고, 확률은 모두 공개한다.
3. **등급이 없다.** 캐릭터와 장비는 모두 단일 등급이다. 차이는 같은 대상을 반복으로 획득했을 때의 강화 효과에서만 생긴다.
4. **광고는 보상과 맞바꾼다.** 강제 광고는 스테이지 클리어 시 짧은 광고 하나만 둔다.

## 재화

- 재화는 **한 종류**만 운영한다. 게임 안에서 얻는 재화와 유료로 충전한 재화가 같은 재화다.
- 재화 이름은 게임별로 게임 컨셉에 맞게 정한다.
- 기본 획득량: 스테이지 클리어 1회당 **30**. 게임 특성상 다르게 할 경우 게임 기획서에 명시한다.
- 내부 기록: 화면에는 하나로 보이지만, 서버에서는 유료 충전분과 무료 획득분을 따로 기록한다. 결제 취소나 청약철회가 들어오면 유료분만 정확히 계산해 처리해야 하기 때문이다.
  - 소비 순서는 무료 획득분을 먼저 쓴다. 이렇게 하면 플레이어가 나중에 환불을 요청할 때 유리하다.
- 재화 잔액은 서버에서 관리한다. 클라이언트에 저장된 값을 믿지 않는다.

## 재화 판매 가격

가격 공식은 다음과 같다.

- 원화: **재화 수량 × 10원**
- 미화: **재화 수량 ÷ 100달러**

| 상품 | 원화(KRW) | 미화(USD) |
|---|---|---|
| 재화 100 | 1,000원 | $1 |
| 재화 500 | 5,000원 | $5 |
| 재화 1,000 | 10,000원 | $10 |
| 재화 3,000 | 30,000원 | $30 |

- 원화와 미화 이외의 통화는 스토어가 미화 가격을 기준으로 자동 환산하게 둔다.
- 대량 구매 보너스(예: 3,000 구매 시 +10%)는 두지 않는다. 가격 비율이 항상 같아야 한다는 단순성 원칙 때문이다.
- 스토어 가격 포인트가 공식 값과 정확히 맞지 않는 국가에서는 가장 가까운 가격 포인트를 쓴다. 특히 App Store는 지정된 가격 포인트만 쓸 수 있으므로 출시 전에 확인한다.

## 랜덤박스(뽑기)

- 1회 가격: **100 재화**. 무과금 플레이어는 기본 획득량 기준으로 스테이지를 3~4개 클리어할 때마다 1회 뽑을 수 있다.
- 종류: 게임별로 정의한다. 기본형은 캐릭터 뽑기와 장비 뽑기 두 종류다.
- 등급 없음: 결과물은 모두 단일 등급이다.
- 확률: 해당 뽑기 풀의 모든 결과물을 **균등 확률**로 뽑는 것을 기본으로 한다. 균등하지 않게 하려면 게임 기획서에 이유와 확률표를 적는다.
- 중복 처리: 이미 가진 캐릭터나 장비가 다시 나오면 그 대상의 **강화 단계가 1 올라간다**. 단계별 효과와 최대 단계는 게임별로 정한다.
  - 최대 단계에 도달한 대상이 다시 나오면 재화로 일부 환급한다. 게임별로 별도로 정하지 않으면 환급액은 30이다.
- 천장(일정 횟수 안에 특정 결과 확정)은 두지 않는다. 등급이 없고 모든 결과물이 강화로 이어지기 때문에, "꽝"이 없는 구조로 대신한다.
- 확률 공개: 뽑기 화면에 결과물별 확률과 현재 풀 목록을 항상 표시한다.

## 광고

| 시점 | 형식 | 플레이어가 얻는 것 |
|---|---|---|
| 스테이지 클리어 | 짧은 전면 광고 (5초 후 건너뛰기) | 없음 |
| 실패(게임별 조건) | 긴 보상형 광고 (플레이어가 선택) | 게임별로 정의한 재도전 혜택(예: 몇 턴 전으로 되돌리기) |

- 튜토리얼 구간에는 클리어 광고를 띄우지 않는다.
- 보상형 광고는 플레이어가 고를 때만 재생한다. 보지 않고 처음부터 다시 하는 선택지를 항상 둔다.
- 광고 제거를 사지 않은 플레이어는 광고를 볼 때마다 재도전 혜택을 쓸 수 있다.

## 광고 제거 상품

- 가격: **5,500원** (미화는 $5.5에 가장 가까운 가격 포인트). 한 번 사면 영구 적용되는 비소모성 상품이다.
- 효과:
  - 클리어 시 전면 광고를 없앤다.
  - 실패 시 재도전 혜택을 광고 없이 바로 쓸 수 있다. 단, **횟수 제한**이 있다. 기본값은 스테이지 1회 도전당 3회이고, 게임별로 조정할 수 있다.
- iOS와 Android 모두 "구매 복원" 기능을 둔다.

## 난이도 설계 규칙

- 각 스테이지의 기준 난이도(제한 시간, 제한 턴, 적 강도 등)는 **뽑기 강화가 전혀 없는 상태**로 클리어할 수 있는지 검증해서 정한다.
- 기본 제공 캐릭터와 스토리 진행으로 얻는 캐릭터만으로 모든 스토리 스테이지를 클리어할 수 있어야 한다.
- 뽑기 강화 효과는 체감은 되되 전략을 대신하지는 않는 수준으로 둔다. 예를 들어 최대 강화 상태의 능력치 상승폭을 기본 능력치의 +30% 이내로 묶는다.
- 출시 후 클리어율 데이터를 볼 때도 "과금자와 무과금자의 클리어율 격차"를 지표로 관리한다.

## 법규·스토어 준수

- 확률 공개:
  - 한국 게임산업법은 2024년 3월부터 확률형 아이템 확률 표시를 의무로 정했다.
  - Google Play와 App Store 정책도 구매 전 확률 공개를 요구한다.
- 청약철회: 한국 전자상거래법상 사용하지 않은 유료 재화는 7일 안에 환불할 수 있어야 한다. 앞의 "내부 기록" 규칙(유료·무료 분리)으로 대응한다.
- 국가별 랜덤박스 규제:
  - 벨기에는 유료 랜덤박스를 사실상 금지하고 있어 출시 국가에서 제외하거나 해당 국가에서 유료 뽑기를 막는다.
  - 일본은 경품표시법(콤프가챠 금지)이 적용되므로, 특정 조합을 모으면 보상을 주는 구조를 만들지 않는다.
  - 중국 본토는 판호가 필요하므로 기본적으로 제외한다.
- 미성년자: 13세 미만을 대상으로 하지 않는다. 한국 미성년자 결제 관련 법정대리인 동의 요건을 확인한다.
- 광고 동의: iOS ATT, EU·영국 GDPR(Google UMP) 동의 화면을 적용한다.

## 게임별로 정의할 항목

개별 게임 기획서에는 아래 표만 채운다.

| 항목 | 설명 |
|---|---|
| 재화 이름 | 게임 컨셉에 맞는 이름 |
| 뽑기 종류와 이름 | 예: 캐릭터 뽑기, 장비 뽑기의 게임 내 명칭 |
| 뽑기별 결과물 풀 | 어떤 캐릭터·장비가 들어가는지, 풀이 늘어나는 조건 |
| 중복 강화 효과 | 강화 단계별 효과, 최대 단계 |
| 실패 조건과 재도전 혜택 | 보상형 광고로 얻는 혜택의 구체적 내용 |
| 지침 예외 | 있다면 내용과 이유 |

## 열린 질문

- App Store의 원화 가격 포인트 중 1,000원, 5,000원, 10,000원, 30,000원, 5,500원이 정확히 있는지 확인이 필요하다.
- 광고 제거 구매자의 재도전 횟수 제한 기본값(3회)이 적당한지는 플레이테스트로 확인한다.
- 최대 강화 후 중복분 환급액(30)이 적당한지 검토한다.
