# 자산 맞춤형 위협 인텔리전스 브리핑

> 한 줄 요약: 매일 보안 공지·CVE·보안 뉴스를 수집해 우리 회사가 실제 쓰는 제품·버전과 관련된 것만 골라 아침 브리핑으로 요약한다.

- 카테고리: security-ops
- 상태: 아이디어
- 작성일: 2026-10-27
- 구현 리포지터리: -

## 배경 / 문제

- 매일 쏟아지는 취약점·보안 공지 중 우리 환경과 관련된 것을 가려내는 데 시간이 많이 든다.
- 긴급 패치가 필요한 취약점을 늦게 인지하는 경우가 있다.

## 목표

- 자산 목록(제품, 버전, 담당자)과 매칭해 관련 있는 위협만 알린다.
- 긴급도(악용 여부, 외부 노출 자산 여부)에 따라 즉시 알림 / 일일 브리핑을 구분한다.

## 범위 밖 (Non-goals)

- 자산 관리 시스템 자체 구축 (기존 목록 연동).

## 사용자 / 사용 시나리오

1. 자산 목록(csv 또는 CMDB API)을 연결한다.
2. 매일 아침 수집기가 KISA 보호나라 보안공지, NVD/CVE, CISA KEV, 벤더 보안 권고, 보안 뉴스를 수집한다.
3. AI가 자산과 매칭·요약해 "우리에게 해당되는 것 / 조치 권고 / 담당자"를 브리핑한다.
4. 악용 중인(KEV) 취약점이 외부 노출 자산에 해당하면 즉시 알림.

## 핵심 기능

- [ ] 피드 수집기 (RSS, API)
- [ ] 제품명·버전 정규화(CPE 매칭)와 자산 매칭
- [ ] AI 요약·한국어 번역·조치 권고
- [ ] 일일 브리핑 메일/메신저, 긴급 알림
- [ ] 조치 추적(담당자 확인 여부)

## 기술 구상

- 수집: NVD API, CISA KEV JSON, KISA 보호나라 공지, 벤더 RSS
- AI: Claude API 요약·매칭 보조
- 실행: 일 1회 배치 + 긴급 피드 주기 조회

## 구현 단계 (MVP → 확장)

1. MVP: 피드 수집 + 자산 키워드 매칭 + 일일 메일.
2. CPE 기반 정밀 매칭, 긴급 알림.
3. 조치 추적, 취약점 진단 결과와 연계.

## 열린 질문 / 리스크

- 자산 목록의 정확도가 결과 품질을 좌우함.
- 제품명 표기 불일치(약어, 벤더명 변경) 처리.
