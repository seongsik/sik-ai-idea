# 보안 관제 경보 1차 분류(트리아지)

> 한 줄 요약: 보안 경보가 발생하면 관련 로그·자산·위협 정보를 자동으로 모아 오탐 가능성, 판단 근거, 다음 조치를 요약해 담당자가 빠르게 판단하게 한다.

- 카테고리: security-ops
- 상태: 아이디어
- 작성일: 2026-10-27
- 구현 리포지터리: -

## 배경 / 문제

- 관제 경보 대부분이 오탐이지만, 확인하려면 여러 콘솔(SIEM, EDR, 방화벽, 자산관리)을 오가며 맥락을 모아야 한다.
- 경보 피로로 실제 위협을 놓칠 위험이 있다.

## 목표

- 경보마다 관련 맥락을 자동 수집해 한 화면 요약을 제공한다.
- 담당자가 30초 안에 "종결 / 추가 조사 / 대응"을 판단할 수 있게 한다.
- 판단 결과를 학습 데이터로 쌓아 반복 오탐 규칙 튜닝을 제안한다.

## 범위 밖 (Non-goals)

- 자동 차단·격리 실행 (제안만, 실행은 승인 후).

## 사용자 / 사용 시나리오

1. SIEM에서 경보가 발생하면 웹훅으로 도구가 호출된다.
2. 도구가 출발지/목적지 IP 평판, 자산 소유자·중요도, 해당 사용자의 최근 행위, 과거 유사 경보 처리 이력을 조회한다.
3. AI가 요약(무슨 일이 있었나, 오탐 가능성, 근거, 권장 조치)을 메신저와 티켓에 남긴다.
4. 담당자가 판정을 누르면 기록된다.

## 핵심 기능

- [ ] 경보 수신(웹훅)과 맥락 수집 플레이북
- [ ] 위협 인텔리전스 조회(IP/도메인/해시 평판)
- [ ] AI 요약과 권장 조치
- [ ] 판정 기록과 오탐 규칙 튜닝 제안

## 기술 구상

- 연동: SIEM/EDR API, 자산관리 DB, 위협 인텔 API(VirusTotal, AbuseIPDB 등)
- AI: Claude API 도구 호출(tool use)로 필요한 조회를 스스로 선택
- 출력: Slack/Teams, 티켓 시스템

## 구현 단계 (MVP → 확장)

1. MVP: 특정 경보 유형 1~2개에 대해 맥락 수집 + 요약.
2. 경보 유형 확대, 과거 이력 유사도 검색.
3. 승인 기반 대응 조치(계정 잠금, IP 차단) 실행.

## 열린 질문 / 리스크

- 관제 로그의 외부 AI 전송 가능 범위.
- 요약 오판으로 실제 공격을 종결하는 위험 → 고위험 유형은 자동 종결 금지.
