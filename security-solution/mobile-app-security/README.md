# 모바일 앱 보안

> 한 줄 요약: 모바일 앱의 위변조·루팅·디버깅을 막는 앱 보호(난독화·무결성 검증) 솔루션과 앱 취약점 자동 점검을, AI 자동 개발로 만든다.

- 카테고리: security-solution
- 영역: ENDPOINT (단말 안에서 동작)
- 사내 개발 경험: 없음 (신규 영역)
- 상태: 아이디어
- 작성일: 2026-11-12
- 구현 리포지터리: -

## 배경 / 문제

- 금융·공공 앱은 루팅·탈옥 탐지, 위변조 방지, 화면 캡처 방지가 사실상 필수지만 OS 버전이 바뀔 때마다 우회 기법도 바뀐다.
- 앱 취약점 점검(하드코딩 키, 평문 저장, 인증서 검증 누락)을 수동으로 하면 배포 주기를 따라가지 못한다.

## 목표

- 앱 빌드 산출물(APK/AAB/IPA)에 보호 모듈을 자동 적용하는 도구를 만든다.
- 루팅·후킹 탐지 우회 기법을 AI로 수집·재현 테스트해 탐지 로직을 계속 보강한다.
- 앱 정적·동적 취약점 점검 결과를 개발자용 수정 가이드와 함께 제공한다.

## 범위 밖 (Non-goals)

- MDM(단말 관리) 기능.
- 앱 개발 자체(고객 앱 코드 수정은 가이드만 제공).

## 사용자 / 사용 시나리오

1. 고객사 개발자가 CI에서 빌드 산출물을 보호 도구에 넣는다.
2. 도구가 난독화·무결성 검증·루팅 탐지 모듈을 적용한 산출물을 돌려준다.
3. 같은 단계에서 취약점 점검이 돌고, 발견 항목마다 수정 예시 코드가 붙은 보고서가 나온다.
4. 솔루션 개발팀은 새 우회 도구(Frida 스크립트 등)가 나오면 AI가 재현 테스트를 만들고 탐지 로직을 보강한다.

## 핵심 기능

- [ ] 코드·문자열·리소스 난독화
- [ ] 앱 무결성(서명·해시) 검증과 위변조 탐지
- [ ] 루팅·탈옥·에뮬레이터·후킹·디버거 탐지
- [ ] 앱 정적·동적 취약점 점검과 수정 가이드
- [ ] CI 플러그인(Gradle, Xcode, GitHub Actions)

## 기술 구상

- 기술 스택: Kotlin/Java·Swift(런타임 SDK), C/C++(네이티브 탐지), Python(빌드 변환 도구), MobSF 참고
- 아키텍처: 빌드 산출물 → 변환 도구(보호 모듈 삽입, 난독화) → 재서명 → 보호된 앱 / 런타임 SDK → 탐지 이벤트 → 관리 서버
- 외부 연동: 고객 CI, 관리 콘솔, 모바일 보안 점검 기준
- AI 자동 개발 적용점:
  - 우회 재현: 공개 우회 스크립트 → 자동 재현 테스트 케이스
  - 점검: 디컴파일 코드 → 취약 패턴 탐지와 수정 예시
  - 호환성: OS·기기 매트릭스 테스트 자동 생성(디바이스 팜)

## 구현 단계 (MVP → 확장)

1. MVP: Android 대상 루팅·후킹 탐지 SDK + 정적 취약점 점검 보고서.
2. 빌드 변환 도구(난독화·무결성), iOS 지원.
3. 서버 연계 위협 대응(탐지 시 세션 차단), 우회 기법 자동 재현 파이프라인.

## 열린 질문 / 리스크

- 신규 영역 → 기존 상용 제품 대비 차별점과 인증(금융보안원 점검 기준) 대응.
- 난독화로 인한 앱 성능·크래시 위험 → 디바이스 팜 회귀 테스트 필수.
- 앱 스토어 정책 위반 가능성(동적 코드 로딩 등).
