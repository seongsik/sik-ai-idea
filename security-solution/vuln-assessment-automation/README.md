# 취약점 진단 자동화

> 한 줄 요약: 서버·네트워크 장비·DB·웹의 보안 설정을 국내 진단 기준에 맞춰 자동 점검하는 진단 솔루션을, 점검 스크립트와 판정 로직을 AI로 자동 생성해 대상 OS·장비를 빠르게 늘린다.

- 카테고리: security-solution
- 영역: ACCESS (사람과 권한을 통제)
- 사내 개발 경험: 없음 (신규 영역)
- 상태: 아이디어
- 작성일: 2026-11-12
- 구현 리포지터리: -

## 배경 / 문제

- 주요정보통신기반시설 기술적 취약점 분석·평가, 전자금융기반시설 점검 등 국내 기준은 항목이 수백 개이고, OS·장비 버전별로 점검 명령이 다르다.
- 점검 스크립트를 사람이 쓰고 유지하므로 신규 OS·장비 대응이 늦고, 판정 기준이 진단자마다 다르다.
- 결과 보고서 작성에 진단 시간만큼 시간이 든다.

## 목표

- 진단 기준 항목과 대상(OS·장비·DB·WAS)을 입력하면 점검 스크립트와 판정 로직을 AI로 생성한다.
- 생성된 스크립트는 양호·취약 상태를 만든 테스트 환경(컨테이너·VM)에서 자동 검증한다.
- 결과를 표준 보고서와 조치 가이드로 자동 작성한다.

## 범위 밖 (Non-goals)

- 모의해킹(공격 시도) 자동화.
- 여러 스캐너 결과를 모아 정규화하는 기능(별도 아이디어: 취약점 진단 결과 정규화). 이 솔루션은 결과를 표준 형식으로 내보낸다.

## 사용자 / 사용 시나리오

1. 진단자가 대상 자산 목록과 적용 기준을 선택한다.
2. 에이전트리스(SSH·WinRM·API) 또는 스크립트 배포 방식으로 점검을 실행한다.
3. 항목별 양호·취약·수동 확인 판정과 근거(수집한 설정 값)가 나온다.
4. 보고서와 조치 가이드가 자동 작성되고, 조치 후 재점검으로 이행을 확인한다.
5. 개발팀은 새 OS 버전이 나오면 AI가 생성한 스크립트를 테스트 환경에서 검증해 배포한다.

## 핵심 기능

- [ ] 진단 기준 항목 DB(주요정보통신기반시설, 전자금융, CIS)
- [ ] 대상별 점검 스크립트(Unix, Windows, 네트워크 장비, DB, WAS)
- [ ] 판정 로직과 근거 수집
- [ ] 스크립트 자동 생성과 양호·취약 테스트 환경 검증
- [ ] 보고서·조치 가이드 자동 작성과 재점검

## 기술 구상

- 기술 스택: Python 또는 Go(점검 엔진), Bash·PowerShell(점검 스크립트), 컨테이너·VM 테스트 환경, 보고서(docx/xlsx 생성)
- 아키텍처: 기준 항목 DB → 스크립트 저장소 → 실행 엔진(원격 접속) → 판정 → 결과 DB → 보고서
- 외부 연동: 자산관리, 계정 금고(점검 계정), 취약점 관리 시스템
- AI 자동 개발 적용점:
  - 스크립트: 기준 항목 문장 + 대상 OS → 점검 명령과 판정 로직
  - 테스트 환경: 항목별 양호·취약 설정을 만든 컨테이너 이미지 자동 생성
  - 보고서: 판정 결과 → 항목별 조치 방법과 영향 설명

## 구현 단계 (MVP → 확장)

1. MVP: 주요정보통신기반시설 Unix·Windows 서버 항목 스크립트 + 판정 + 엑셀 보고서.
2. 스크립트 자동 생성·검증 파이프라인, 네트워크 장비·DB 확대.
3. 정기 자동 점검과 이행 추적, 클라우드 설정 점검과 연계.

## 열린 질문 / 리스크

- 점검 계정 권한(관리자 권한)과 점검 중 시스템 영향.
- 판정이 애매한 항목(정책 판단 필요)은 "수동 확인"으로 분리.
- 기준 개정 추적.
