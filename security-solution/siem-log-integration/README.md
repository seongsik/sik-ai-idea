# SIEM·통합로그

> 한 줄 요약: 여러 보안 장비·서버 로그를 모아 정규화·상관분석하는 SIEM을, 로그 파서와 상관분석 룰을 AI로 자동 생성하고 자연어로 로그를 검색하게 해 신규 영역 진입 비용을 낮춘다.

- 카테고리: security-solution
- 영역: DATA (정보 자체를 보호)
- 사내 개발 경험: 없음 (신규 영역)
- 상태: 아이디어
- 작성일: 2026-11-12
- 구현 리포지터리: -

## 배경 / 문제

- SIEM 구축 비용의 대부분이 장비별 로그 파서 작성과 상관분석 룰 튜닝에 들어간다.
- 국내 보안 장비(DRM, DB 접근제어, 망연계, NAC) 로그 형식은 해외 SIEM이 기본 지원하지 않는다.
- 관제 요원이 검색 문법(SPL, KQL)을 익혀야 해서 진입 장벽이 높다.

## 목표

- 로그 샘플을 넣으면 파서(필드 추출·공통 스키마 매핑)와 테스트를 자동 생성한다.
- 위협 시나리오 설명에서 상관분석 룰을 생성하고 과거 로그로 검증한다.
- 자연어 질문을 검색 쿼리로 바꿔 실행한다.
- 사내 보안 제품(DRM, 개인정보 검색, 망연계, DB 접근제어, NAC, IDS) 로그를 기본 지원한다.

## 범위 밖 (Non-goals)

- 자동 대응(SOAR) 전체 기능 (2단계 이후).
- 대규모 데이터 레이크 자체 개발 (검증된 저장 엔진 사용).

## 사용자 / 사용 시나리오

1. 구축 엔지니어가 새 장비의 로그 샘플 수백 줄을 올리면 파서 초안과 매핑 결과가 나온다.
2. 엔지니어가 확인 후 배포하면 해당 로그가 공통 스키마로 저장된다.
3. 관제 요원이 "어제 퇴근 후 DB에서 대량 조회한 계정"을 물으면 쿼리와 결과가 나온다.
4. 보안 담당자가 시나리오를 문장으로 쓰면 상관분석 룰 초안과 과거 30일 적중 결과를 받는다.

## 핵심 기능

- [ ] 로그 수집(syslog, 에이전트, API)
- [ ] 파서 자동 생성과 공통 스키마(OCSF 등) 매핑
- [ ] 상관분석 룰 엔진과 룰 자동 생성·백테스트
- [ ] 자연어 검색
- [ ] 대시보드·보고서(법적 로그 보관 요건 포함)

## 기술 구상

- 기술 스택: Go(수집기), Kafka, ClickHouse 또는 OpenSearch, Sigma 룰 호환, 웹 콘솔
- 아키텍처: 수집기 → 메시지 큐 → 파서·정규화 → 저장소 → 상관분석 엔진·검색 → 경보·대시보드
- 외부 연동: 사내 보안 제품군, 방화벽·서버·클라우드 로그, 위협 인텔
- AI 자동 개발 적용점:
  - 파서: 로그 샘플 → 파서 코드 + 필드 매핑 + 테스트(샘플 전부 파싱 성공 확인)
  - 룰: 시나리오 문장 → Sigma 룰 → 과거 로그 백테스트
  - 검색: 자연어 → 쿼리 변환(실행 전 쿼리 표시)

## 구현 단계 (MVP → 확장)

1. MVP: 사내 제품 로그 5종 파서 + 공통 스키마 + 검색 + 기본 대시보드.
2. 파서 자동 생성 도구, Sigma 룰 엔진, 자연어 검색.
3. 룰 자동 생성·백테스트, 이상 행위 분석(UEBA), 경보 트리아지 연계.

## 열린 질문 / 리스크

- 신규 영역 → 기존 상용 SIEM에 사내 제품 파서만 공급하는 방식과 비교 필요.
- 대용량 로그 저장 비용과 보관 기간 요건.
- 자연어 검색이 잘못된 쿼리를 만들 위험 → 쿼리를 사용자에게 보여 준다.
