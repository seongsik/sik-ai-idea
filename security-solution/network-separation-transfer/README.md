# 망연계 솔루션

> 한 줄 요약: 업무망과 인터넷망처럼 분리된 망 사이에 파일·데이터를 안전하게 전달하는 망연계 솔루션을, 파일 검사·무해화(CDR)·연계 프로토콜 어댑터를 AI로 자동 개발해 확장한다.

- 카테고리: security-solution
- 영역: DATA (정보 자체를 보호)
- 사내 개발 경험: 있음 (현업에서 직접 개발한 영역)
- 상태: 아이디어
- 작성일: 2026-11-12
- 구현 리포지터리: -

## 배경 / 문제

- 공공·금융은 망분리 규제로 망연계가 필수이지만, 연계 대상 시스템(DB 동기화, API, 메일, 클립보드)이 늘어날 때마다 개별 개발이 필요하다.
- 파일 형식별 악성코드 검사·무해화(CDR) 지원 범위를 넓히기 어렵다.
- 최근 망분리 규제가 완화(다층 보안 체계 등)되면서 데이터 등급별 연계 정책 요구가 생겼다.

## 목표

- 연계 프로토콜 어댑터(REST, DB, SFTP, 메시지 큐)를 공통 인터페이스로 만들고, 새 어댑터를 AI로 자동 생성·테스트한다.
- 문서 형식별 CDR 모듈(액티브 콘텐츠 제거 후 재구성)을 AI 지원으로 확대한다.
- 데이터 등급·방향별 연계 정책과 승인 흐름을 지원한다.

## 범위 밖 (Non-goals)

- 물리적 일방향 장비(다이오드) 하드웨어 개발.
- 망분리 환경 컨설팅.

## 사용자 / 사용 시나리오

1. 직원이 인터넷망 PC에서 업무망으로 파일을 보낸다.
2. 연계 서버가 악성코드 검사, 형식 검증, CDR 무해화를 거쳐 업무망에 전달한다.
3. 업무망 → 인터넷망 반출은 결재 승인과 개인정보 검사 후 전달된다.
4. 시스템 담당자는 두 망 사이 DB·API 연계를 설정 화면에서 등록한다.

## 핵심 기능

- [ ] 파일 전송(양방향)과 승인 결재
- [ ] 악성코드 검사·형식 위장 탐지·CDR 무해화
- [ ] 개인정보 검사(반출 시)
- [ ] 시스템 간 연계 어댑터(DB, API, SFTP, MQ)
- [ ] 전송 이력·감사 로그

## 기술 구상

- 기술 스택: Java/Go(연계 서버), C/C++ 또는 Rust(CDR 엔진), 백신 엔진 연동, PostgreSQL
- 아키텍처: 송신 측 에이전트 → 송신 연계 서버 → (전용 회선·일방향 구간) → 수신 연계 서버 → 수신 측 / 각 서버에 검사 파이프라인(백신 → 형식 검증 → CDR → 개인정보)
- 외부 연동: 백신 엔진, 개인정보 검색 엔진, 그룹웨어 결재, SIEM
- AI 자동 개발 적용점:
  - CDR: 문서 형식 명세(OOXML, HWPX, PDF) → 액티브 요소 제거·재구성 코드 + 악성 샘플 회귀 테스트
  - 어댑터: 연계 대상 API 명세 → 어댑터 코드와 통합 테스트
  - 정책: 데이터 등급 규정 → 연계 정책 설정 초안

## 구현 단계 (MVP → 확장)

1. MVP: 기존 망연계 제품에 공통 어댑터 인터페이스 정의 + AI 어댑터 생성 도구.
2. CDR 지원 형식 확대(HWPX, PDF), 형식 위장 탐지.
3. 데이터 등급별 연계 정책(다층 보안 체계 대응), 생성형 AI 서비스 이용을 위한 안전한 질의 연계.

## 열린 질문 / 리스크

- 국정원 보안기능 확인서·CC인증 대상 기능 변경 시 재인증 범위.
- CDR 재구성으로 문서가 깨지는 위험 → 원본 보관·복원 정책.
- 망분리 규제 개편 방향 추적.
