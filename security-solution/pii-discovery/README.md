# 개인정보 검색

> 한 줄 요약: PC·서버·DB에 흩어진 개인정보를 찾아 암호화·삭제·이동하도록 돕는 개인정보 검색 솔루션을, 패턴 정의·문서 파서·오탐 판별을 AI로 자동 개발해 정확도를 높인다.

- 카테고리: security-solution
- 영역: DATA (정보 자체를 보호)
- 사내 개발 경험: 있음 (현업에서 직접 개발한 영역)
- 상태: 아이디어
- 작성일: 2026-11-12
- 구현 리포지터리: -

## 배경 / 문제

- 정규식 기반 검색은 주민등록번호·카드번호처럼 형식이 있는 정보는 잘 찾지만, 오탐(제품 번호, 날짜)이 많고 이름·주소 같은 비정형 정보는 놓친다.
- 이미지(스캔 문서, 신분증 사진), 압축 파일, 새 문서 형식 지원 요청이 계속 들어온다.
- 검출 결과가 많으면 사용자가 조치하지 않고 방치한다.

## 목표

- 형식 검증(체크섬)과 문맥 판별(AI)을 결합해 오탐을 줄인다.
- 문서 형식 파서를 AI로 자동 생성·테스트해 지원 형식을 빠르게 늘린다.
- 검출 항목마다 "왜 개인정보인지"와 권장 조치(암호화·삭제·마스킹)를 보여 준다.

## 범위 밖 (Non-goals)

- 개인정보 처리방침 작성·법률 자문.
- 단말 데이터를 외부 AI API로 전송하는 방식 (판별 모델은 사내 또는 단말에서 실행).

## 사용자 / 사용 시나리오

1. 관리자가 전사 점검 일정을 정하면 에이전트가 PC·파일 서버를 검색한다.
2. 검출 결과가 사용자에게 알림으로 가고, 사용자는 항목별로 암호화·삭제·예외 신청을 한다.
3. 관리자는 부서별 보유 현황과 조치율을 대시보드로 본다.
4. 개발팀은 새 문서 형식 요청이 오면 AI가 만든 파서와 테스트 샘플을 검토해 배포한다.

## 핵심 기능

- [ ] 형식 기반 검출(주민번호, 여권, 운전면허, 카드, 계좌, 전화, 이메일)과 체크섬 검증
- [ ] 문맥 기반 판별(이름·주소·건강정보 등 비정형)
- [ ] 문서·압축·이미지(OCR) 파서
- [ ] DB 컬럼 샘플링 검색
- [ ] 사용자 조치(암호화·삭제·예외)와 관리자 대시보드

## 기술 구상

- 기술 스택: C++/Rust(에이전트 검색 엔진), Python(판별 모델), 경량 한국어 NER 모델(온프레미스), OCR 엔진
- 아키텍처: 에이전트(파일 열거 → 파서 → 1차 패턴 → 2차 문맥 판별) → 결과 서버 → 대시보드·조치 연동(DRM 암호화)
- 외부 연동: DRM(암호화 조치), 인사·조직도, DB 접근 계정
- AI 자동 개발 적용점:
  - 파서: 파일 형식 명세 → 텍스트 추출 파서 + 손상 파일 퍼징 테스트
  - 데이터: 합성 개인정보 테스트 셋(진짜 개인정보 없이) 자동 생성
  - 판별: 오탐 사례 → 패턴·예외 규칙 개선 제안

## 구현 단계 (MVP → 확장)

1. MVP: 기존 엔진에 문맥 판별 2차 필터와 합성 테스트 셋 추가, 오탐률 측정.
2. 이미지 OCR 검색, 파서 자동 생성 도구.
3. DB·클라우드 저장소(SharePoint, S3) 검색, 개인정보 흐름 지도.

## 열린 질문 / 리스크

- 단말 성능 영향(검색 시간, CPU) → 유휴 시간 검색·증분 검색.
- 판별 모델의 한국어 비정형 개인정보 정확도.
- 검색 결과 자체가 개인정보이므로 결과 저장 시 마스킹 필요.
