# DRM 문서보안

> 한 줄 요약: 사내 문서를 생성 시점에 암호화하고 열람·편집·인쇄 권한을 통제하는 DRM 솔루션을, 응용프로그램 연동 모듈과 호환성 테스트를 AI로 자동 개발해 유지보수 부담을 줄인다.

- 카테고리: security-solution
- 영역: DATA (정보 자체를 보호)
- 사내 개발 경험: 있음 (현업에서 직접 개발한 영역)
- 상태: 아이디어
- 작성일: 2026-11-12
- 구현 리포지터리: -

## 배경 / 문제

- 오피스·한글·PDF·CAD 등 응용프로그램 버전이 바뀔 때마다 후킹·플러그인 연동이 깨져 장애 문의가 몰린다.
- 지원 응용프로그램을 추가하는 데 리버스 엔지니어링과 테스트에 시간이 많이 든다.
- 협력사 반출·클라우드 협업 도구와의 호환 요구가 커지고 있다.

## 목표

- 응용프로그램 업데이트를 감지하면 자동으로 호환성 테스트(열기·저장·인쇄·복사 차단)를 돌려 깨진 기능을 먼저 찾는다.
- 연동 모듈(플러그인·후킹)의 반복 코드를 AI로 생성하고, 응용프로그램별 테스트 스크립트를 자동 생성한다.
- 권한 정책을 자연어로 정의하면 정책 설정으로 변환한다.

## 범위 밖 (Non-goals)

- 전사 문서중앙화(문서 저장소) 제품 자체.
- 모바일 문서 뷰어 1단계 제외.

## 사용자 / 사용 시나리오

1. 직원이 문서를 저장하면 자동 암호화되고, 소속·등급에 따라 권한이 붙는다.
2. 외부 반출이 필요하면 반출 신청 → 승인 → 기간 제한 문서로 내보낸다.
3. 응용프로그램 신규 버전이 배포되면 테스트 팜이 자동으로 호환성 테스트를 돌리고 결과를 개발팀에 알린다.
4. 개발자는 실패 항목의 로그·화면을 보고 AI가 제안한 수정안을 검토한다.

## 핵심 기능

- [ ] 문서 자동 암호화와 권한(열람·편집·인쇄·복사·화면캡처) 통제
- [ ] 응용프로그램 연동 모듈(오피스, 한글, PDF, CAD)
- [ ] 반출 승인과 기간·횟수 제한 문서
- [ ] 응용프로그램 버전별 호환성 자동 테스트 팜
- [ ] 사용 이력 로그와 감사 보고서

## 기술 구상

- 기술 스택: C/C++(Windows 후킹·미니필터), C#(관리 도구), Java/Go(정책 서버), 키 관리(HSM 또는 KMS)
- 아키텍처: 클라이언트 에이전트(암복호화·권한 집행) ↔ 정책·키 서버 ↔ 관리 콘솔 / 별도 테스트 팜(VM 이미지 × 응용프로그램 버전)
- 외부 연동: 인사·조직도, 그룹웨어 결재(반출 승인), SIEM
- AI 자동 개발 적용점:
  - 테스트: 응용프로그램별 UI 자동화 스크립트(열기·저장·인쇄) 생성
  - 장애 분석: 실패 로그·덤프 → 원인 후보와 수정안
  - 정책: 자연어 권한 규칙 → 정책 설정 변환과 충돌 검사

## 구현 단계 (MVP → 확장)

1. MVP: 기존 사내 DRM 대상 호환성 자동 테스트 팜 + 실패 분석 보조.
2. 연동 모듈 코드 생성 도구, 자연어 정책 변환.
3. 클라우드 협업 도구·웹 뷰어 연동, 개인정보 검색 결과와 연계한 자동 등급 부여.

## 열린 질문 / 리스크

- 상용 응용프로그램 리버스 엔지니어링의 라이선스·법적 범위.
- 테스트 팜의 응용프로그램 라이선스 비용.
- 키 관리 실수 시 문서 복구 불가 위험 → 키 복구 절차 필수.
